# 组合反应视觉审查（2026-10-17）

本轮只审查现行正式效果，没有修改正式特效或资源。判断标准是用户最新确认的像素艺术方向：轮廓清晰、少量连续大色块拼接，碎点和细线只作辅助。使用像素图集、最近邻采样，并不自动等于符合这个美术方向。

## 完整清单

现行元素规则包含 10 类有画面表现的反应，加上无独立动画的光暗抵消，共 11 类。冻结与解冻作为同一反应的两个阶段；闪电链与电火花落雷复用同类导电、雷火效果。连续反应复用这些表现，不重复计数。

| 组合反应 | 当前表现与判断 | 建议 |
| --- | --- | --- |
| 水＋火：蒸汽 | 正式图集中的小烟团主要靠细描边识别，内部填色很淡，实机看起来接近几个空心圈；与水流的新连片水体差别明显。 | **优先调整**：几个相连的实心阶梯烟块，深浅灰白分面。 |
| 火＋电：雷火 | 闪电链、落雷都走旧 `explosion_burst`，主体是向外分散的暖黄色小方粒子；有方块轮廓，但没有连续爆炸体积。周围可见的橙色火舌属于原有燃烧，不应误当成雷火的新爆炸主体。 | **优先调整**：连片爆燃色块负责主体，少量碎点负责收尾。 |
| 风＋水：湿润传播 | 仍是单层 2px 短水线，最高透明度约 42%，终点仅 2×2 小点；在怪群和草地上很难辨认。大块风刃是已批准的单附魔表现，不是传播水线。 | **优先调整**：保留指向目标的传播功能，改为有宽窄变化的小段水体。 |
| 风＋冰：冰场扩张 | 正式前沿图集由细分枝、断续弧线和尖细冰片构成；地面冰场本身也是雪花细枝结构。扩张后仍以线条和细碎装饰为主。 | **优先调整**：用相连的大冰面和少量晶体块承担扩张体积；基础冰场应一起协调。 |
| 水＋电：导电／传导 | 正式图集是一条约 32px 长的单色蓝电弧，3px 网格轮廓清楚。它不是模糊特效，但缺少大色块的层次，表现偏小。 | **可优化**：保留必要的连通电弧，局部加宽，并增加深浅分色；不必把所有线条删掉。 |
| 光＋冻结：光折射 | 主体是连续的多层直光束，像素边缘清楚；外围还有星芒和若干小碎光。没有雷火那种满屏散点问题，但更像平直激光条。 | **可优化**：保留连续光束，增加棱面和宽窄变化，收敛外围碎光。这里指组合光折射，不是用户要求回退的光辉剑。 |
| 水＋冰：冻结／解冻 | 持续冰壳有完整轮廓与连片蓝色分面，主体基本符合；冻结、解冻短动画仍有尖细冰屑，属于辅助部分。解冻是冻结计时结束，不是火冰组合。 | **主体可保留**；解冻碎屑可作为次要细节调整为较少、较完整的冰块。 |
| 风＋火：火场扩张 | 扩大现有火场，继续使用分色像素火舌。实机已有连续的大块火焰主体。 | **基本符合**。若以后进一步扩大范围，再观察火舌之间的空隙。 |
| 光＋火：神圣火焰 | 原有像素火舌换为浅黄边缘、白色主体；实机和状态数据都确认色板切换。 | **基本符合**。 |
| 暗＋火：暗焰 | 原有像素火舌换为黑色主体、紫色边缘。球体是黑洞本体，不属于暗焰；暗焰靠火舌色板表现。 | **基本符合**。暗背景下识别度可另评，不属于色块破碎问题。 |
| 光＋暗：抵消 | 清除相应状态，无独立抵消粒子动画；光辉剑与黑洞自身的画面仍正常播放。 | **无独立美术需要调整**。 |

用户已批准黑洞的独立细吸入线；本审查不把“细线”本身当成错误。问题在于需要表达体积的主体是否仍由细描边或散点承担。分裂、弹射、多投等属于攻击机制或数量修改，复用武器表现，没有新增的通用元素反应美术。

## 实机证据与范围

- 新审查场景：`scenes/tests/reaction_style_audit.tscn`，派生自现有组合反应审阅工具。
- 正式 `GameRoot` 主战斗，1920×1080 基准，6 只高血量怪物，使用现行正式附魔与反应入口。
- 脚本按时序调用 `CombatEffectWorld.trigger_weapon_impact`，不是实际武器投射物碰撞；本轮用于隔离审查组合反应画面。
- 覆盖 14 个案例：两种电触发路径各自的导电和雷火、圣焰、暗焰、抵消、光折射、湿润传播、暗焰遇水、蒸汽、冻结及解冻、冰场扩张、火场扩张。全部完成并满足配置的反应观察条件；这不是全套战斗数值回归测试。
- Headless 审查场景通过；GPU 记录无 Parse/Compile/SCRIPT ERROR，退出码 0。
- GPU 实际运行在私有 Windows 桌面；实际桌面核验一致，`foreground_samples=0`，没有抢焦点。
- 所有截图均为当前效果。展示局部使用整数倍最近邻放大，没有重绘、平滑或替换画面中的特效。
