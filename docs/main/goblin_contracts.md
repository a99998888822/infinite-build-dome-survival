常客折扣从当前货架起生效，在其他折扣基础上乘0.85。所有成功付费购买的商店商品（含升级）付款后扣2理智；刷新、免费奖励、出售、银行与独立附魔操作不收费。降到70理智以下仍继续履约。永久合同不可重复接受，其余三项可在后续符合条件时再次接受。

本金减伤单价为5。先处理无敌、普通护盾、护甲，再按生命伤害减免30%；本金不足时只抵消可支付部分。生命伤害和本金费用的小数分别累计，避免每次小伤害独立舍入；波末不足1本金的费用向上结算。归零状态在破产重组等遗物回调前锁定，同波恢复本金不重新开启减伤。本金变化正常更新本金关联属性；上限下降不作为另一笔伤害收费。

多做一点奖励为100＋10×下一波波数，不乘掉落加成。下一波普通怪、精英、小boss生命均乘1.3，不改攻击、护甲和掉落。存活进入波末结算即领取一次，不要求清空怪物。

讨债目标从钢甲骑士、幽焰冥狼中随机选一个模板。叠加下一波正常难度、侵蚀、适应性属性后，额外生命×3，近战/远程/元素伤害×2，护甲×2，身体与碰撞体型×1.1；基础0护甲仍为0。保留模板攻击范围及对应预警，战场上用合同图标和血条识别指定目标。开波额外生成一只，不占普通刷怪数量上限和小boss替换名额。

两处动态欠款金额都等于展示时的应还总额D，绑定同一贷款与选定模板。击杀指定目标立即减债D，无须再存活到波末；其他敌人死亡不触发。清剿阶段倒计时结束仍未击杀，先加债D，再处理原有自动还款或展期复利。已成功不再处罚；清场删除不算击杀；已还清后原提案失效，不重新抽取。减债最低到0，不生成现金。

自动回归及GPU审阅场景：`scenes/tests/goblin_contracts_test.tscn`。审阅只设置起始资产、压力观测与候选池，实际展示、购买、伤害、刷怪、借款与结算均走正式流程。
