# 局外营地与成长模块详细设计方案

本文档定义“局外营地与成长模块”的数据结构、界面流程、建筑升级逻辑、局外成长接口和存档联动方式。它只负责“从启动页进入营地、购买局外成长、把成长结果作为全局加成带入后续战斗”，不负责战斗中的实时逻辑，也不负责自由摆放、生产链、居民管理或资源采集。

营地表现采用最简双态显示：仅对“需要解锁的建筑”使用废墟 / 正式建筑双态；初始自带建筑初始等级为 1，直接显示正式建筑，不需要废墟图。营地场景本身可以由草地、河流、树木、石头、花草等分层素材拼成，不要求单张大底图。

## 1. 模块目标

1. 提供一个从启动页进入的固定局外营地入口。
2. 提供建筑等级与建筑升级选项两套成长路径。
3. 提供武器、遗物、召唤、伤害、防御、掉落等方向的局外成长入口。
4. 提供存档读写接口，把营地成长稳定保存到本地。
5. 为后续新增建筑、新增成长项、新增解锁门槛和局外货币解锁保留扩展口。
6. 支持同一营地场景中按建筑解锁状态切换“废墟/建筑”两种表现。

## 2. 模块边界

### 2.1 本模块负责

1. 营地主界面与建筑入口。
2. 建筑等级状态读取与保存。
3. 建筑等级效果的结算与注入。
4. 建筑升级选项的展示、购买、等级上限和花费结算。
5. 局外内容开放状态派生。
6. 死亡或通关最终结算后，局外货币 `camp_currency` 回流到营地。

### 2.2 本模块不负责

1. 战斗中的敌人 AI。
2. 武器自动攻击。
3. 遗物战斗期效果的具体计算。
4. 经验球、金币、掉落物的场景表现。
5. 营地自由建造、拖拽摆放、路径经营。
6. 角色技能树的独立树状养成。

## 3. 核心流程

### 3.1 主流程

营地是独立的局外成长流程，不夹在角色选择与战斗之间：

1. 局外成长流程：`启动页面 -> 选择购买天赋 / 营地成长 -> 进入营地页面 -> 购买建筑或升级选项 -> 全游戏生效`。
2. 战斗入口流程：`启动页面 -> 选择角色 -> 进入战斗（第一波）`。
3. 战斗准备阶段只读取营地存档中的成长结果，不保存本局选择。

### 3.2 战斗结束后的回流流程

1. 玩家死亡或通关后，战斗 / 奖励模块输出最终结算结果。
2. 营地模块只接收最终结算回流的 `camp_currency_gain`。
3. 存档模块把 `camp_currency_gain` 增加到 `camp_currency`。
4. 不回流局内金币、理财本金、商店状态、本局武器等级、本局遗物或波次状态。
5. 玩家可返回启动页，也可进入营地消费局外货币购买建筑或升级选项。

### 3.3 战斗开始前的出战流程

该流程由战斗入口 / 出战准备逻辑发起，营地只提供只读成长数据：

1. 角色选择页确定本局角色。
2. 初始武器 ID 列表由玩家与武器模块在开战前写入。
3. 读取营地建筑等级与升级项等级，生成永久属性加成和内容开放状态。
4. 组装本局初始属性、初始武器、初始遗物可见池和起始参数。
5. 整个流程只读取局外存档，不保存本局角色、初始武器或战斗状态。

## 4. 营地数据模型

### 4.1 存档中的营地状态

建议营地存档至少包含以下字段：

| 字段 | 说明 |
| ---- | ---- |
| `currencies.camp_currency` | 局外营地可用货币 |
| `building_levels` | 建筑当前等级，key 为建筑 ID |
| `upgrade_levels` | 升级选项当前等级，key 为升级项 ID |

不保存 `unlocks`、`records`、`selected_character_id`、`selected_start_weapons`。开放内容由建筑等级与升级项等级派生；本局选择只存在于运行态。

### 4.2 营地运行时状态

建议运行时只维护三类状态：

1. 当前正在显示的建筑 ID。
2. 当前建筑下可购买的升级项列表。
3. 当前营地资源余额和派生开放内容快照。

### 4.3 配置文件依赖

本模块直接依赖：

1. `data_config/camp_buildings.json`
2. `data_config/weapons.json`
3. `data_config/relics.json`
4. `data_config/characters.json`
5. `data_config/bonds.json`
6. `data_config/waves.json`
7. `data_config/drop_tables.json`

## 5. 设计原则

1. 固定营地，不做自由摆放。
2. 建筑等级与升级选项分开管理。
3. 新增成长内容优先走配置，不优先改代码。
4. 成长效果统一转成 `Modifier` 或解锁标记，不在 UI 层直接改数值。
5. 营地模块只负责“能看见、能买、能存、能恢复”，不直接耦合局内具体战斗表现。

## 6. 建筑系统

### 6.0 表现规则

1. 需要解锁的建筑只维护两种显示资源：废墟素材和正式建筑素材。
2. 未解锁时显示废墟素材。
3. 解锁后显示正式建筑素材。
4. 初始自带建筑初始等级为 1，只维护正式建筑素材，不需要废墟图。
5. 之后如果有建筑升级，也只在正式建筑素材基础上继续扩展，不改变这套切换规则。

当前营地共 7 个建筑，分为两类：军械工坊、遗物档案馆初始解锁为 Lv.1，其余建筑通过一次性营地币解锁，解锁后从 Lv.1 开始升级。

### 6.1 建筑等级型

这类建筑的主要作用是“建筑本身升级后直接生效”。

1. `camp_armory_workshop` 军械工坊
   - 初始自带，初始等级 1。
   - 作用：武器图鉴解锁、武器基础强化。
   - Lv.1：解锁全部基础、精良武器。
   - Lv.2：解锁全部稀有武器库、解锁属性购买升级。
   - Lv.3：解锁全部史诗武器，通用伤害 +4%。
   - Lv.4：解锁全部传说武器，攻击速度 +10%。
   - Lv.5：解锁全部珍奇武器。
   - 建筑升级费用：Lv.2/3/4/5 分别为 200/400/700/1200 营地币。
   - 升级项：Lv.2 解锁后开放武器伤害、武器攻速、武器暴击率、武器暴击伤害、负载上限。

2. `camp_relic_archive` 遗物档案馆
   - 初始自带，初始等级 1。
   - 作用：遗物图鉴解锁、遗物套装预览。
   - Lv.1：解锁全部普通、精良遗物库。
   - Lv.2：解锁全部稀有遗物、解锁属性购买升级。
   - Lv.3：解锁全部史诗遗物，掉落率 +5%。
   - Lv.4：解锁全部传说、虚空遗物，幸运 +20。
   - Lv.5：解锁全部珍奇遗物。
   - 建筑升级费用：Lv.2/3/4/5 分别为 200/400/700/1200 营地币。
   - 升级项：Lv.2 解锁后开放遗物鉴定（幸运）、遗物搜寻（掉落率）。

### 6.2 升级选项型

这类建筑主要负责“解锁一批可购买升级项”，本身升级后通常不会直接给大量数值，而是开放新的成长入口。

3. `camp_blade_arena` 利刃演武场
   - 需要 120 营地币一次性解锁，解锁后进入 1 级。
   - 参考初始解锁价：120。
   - 近战专属营地建筑。
   - Lv.1 解锁属性购买升级。

4. `camp_farstar_range` 远星射靶台
   - 需要 140 营地币一次性解锁，解锁后进入 1 级。
   - 参考初始解锁价：140。
   - 远程专属营地建筑。
   - Lv.1 解锁属性购买升级。
   - 说明：攻击距离使用 `area_size`；范围伤害大小使用独立的 `damage_area_size`，两者不可混用。

5. `camp_kin_nursery` 眷族培育栏
   - 需要 160 营地币一次性解锁，解锁后进入 1 级。
   - 参考初始解锁价：160。
   - 召唤体系强化建筑。
   - Lv.1 解锁属性购买升级；Lv.2 开局额外获得一个随机眷族。
   - 作为召唤流的局外入口。

6. `camp_dome_shelter` 穹顶庇护所
   - 需要 180 营地币一次性解锁，解锁后进入 1 级。
   - 生存防御类平衡建筑。
   - Lv.1 解锁属性购买升级；Lv.2 开局额外获得一件随机遗物。
   - 用于补足脆皮流和前期开荒容错。

7. `camp_council_hall` 议事大厅
   - 需要 100 营地币一次性解锁，解锁后进入 1 级。
   - 参考初始解锁价：100。
   - 通用成长与套装强化建筑。
   - Lv.1 解锁属性购买升级；Lv.2 开局连升两级。
   - 用于提升整体经济与局外收益。
   - 新增 `camp_upgrade_shop_offer_count`“商店选项扩容”：最多购买 2 级，每级提供 `shop_offer_count_bonus +1`。它会将升级奖励和局内商店的基础 3 项候选同步扩展为 4 项、5 项，最终候选目标数仍至少为 2。

## 7. 建筑数据结构

### 7.1 建筑基础字段

建议 `camp_buildings.json` 中每个建筑至少包含：

| 字段 | 说明 |
| ---- | ---- |
| `id` | 建筑唯一 ID |
| `name` | 建筑显示名 |
| `initial_unlocked` | 是否初始自带 |
| `type` | 建筑类型，例如 `human`、`mixed`、`void` |
| `role` | 建筑核心定位 |
| `description` | 建筑描述 |
| `unlock_condition` | 建筑解锁条件，可选，支持前置建筑或局外货币解锁 |
| `building_upgrade_costs` | 建筑升到目标等级所需的营地币，键为目标等级 |
| `levels` | 建筑等级效果 |
| `upgrade_options` | 建筑开放的升级选项 |

### 7.2 建筑等级效果

`levels` 适用于“建筑本体升级”。支持三种效果：

1. `unlock`：解锁武器库、遗物库、特殊槽位、系统权限等。
2. `stat/value`：直接提供全局属性加成。
3. `stage`：标记阶段状态，例如虚空侵蚀阶段。

### 7.3 升级选项

`upgrade_options` 适用于“可重复购买的局外成长项”。建议字段：

| 字段 | 说明 |
| ---- | ---- |
| `id` | 升级项 ID |
| `name` | 升级项显示名 |
| `stat` | 对应属性 ID |
| `currency` | 消耗货币类型 |
| `cost` | 升级项基础花费；实际购买费用按目标等级递增 |
| `max_level` | 最大购买等级 |
| `value_per_level` | 每级增量 |

规则：

1. 每级花费递增，实际费用为 `cost * 目标等级`。
2. 达到 `max_level` 后不再可买。
3. 玩家当前等级只记录在存档，不写死在配置里。
4. 只允许使用 `StatDefinitions` 中已存在的属性 ID。

建筑解锁与升级规则：

1. 军械工坊、遗物档案馆初始解锁为 Lv.1。
2. 其余建筑通过 `unlock_condition.cost` 一次性解锁，解锁后为 Lv.1。
3. 建筑本体升级费用由 `building_upgrade_costs` 配置，并按目标等级逐级提高。
4. “重置属性升级”只清空 `upgrade_levels` 并返还属性升级费用，不影响建筑解锁和建筑等级。

## 8. 局外成长接口

### 8.1 属性类成长

由建筑升级项直接提供，统一转成 `Modifier` 或百分比修正。

### 8.2 解锁类成长

用于开放武器池、遗物池、特殊槽位、图鉴、难度层、后续营地功能。

### 8.3 经济类成长

用于提升局内/结算货币获取、经验收益、掉落收益和理财收益。

### 8.4 选择类成长

用于扩大可选武器、遗物、开局道具、免费升级次数等决策空间。

## 9. 存档与恢复

### 9.1 保存时机

1. 玩家死亡或通关后的最终战斗结算完成后。
2. 营地建筑升级购买成功后。
3. 营地升级选项购买成功后。

禁止在战斗进行中、波次结束、共享奖励/商店页、局内商店和理财页面写入正式存档。

### 9.2 恢复时机

1. 游戏启动时。
2. 进入营地时。
3. 进入战斗前只读取当前局外状态来组装本局初始属性，不保存本局选择。

### 9.3 恢复内容

1. 建筑等级。
2. 升级项等级。
3. 营地货币余额。
4. 音量等本地设置由存档模块恢复。

武器、遗物和槽位的开放状态优先由建筑等级和升级项等级派生，不单独保存解锁 ID 列表。

## 10. 与其他模块的接口

### 10.1 与玩家与角色模块

1. 角色选择页决定本局角色，初始武器由玩家与武器模块在开战前写入。
2. 营地只提供角色外部成长修正和内容开放状态。
3. 战斗准备阶段组合角色基础属性、营地 `Modifier` 和初始武器列表；营地不保存本局选择。

### 10.2 与局内武器模块

1. 军械工坊决定武器池开放范围。
2. 升级项影响武器关键属性，但不直接写死到武器配置。

### 10.3 与局内遗物与羁绊模块

1. 遗物档案馆决定遗物池开放范围。
2. 局内遗物、羁绊层数和本局遗物搜集结果不直接写入营地存档。
3. 若死亡或通关后产生局外货币奖励，则由最终结算统一回流。

### 10.4 与敌人与波次模块

1. 波次结算结果只服务于局内升级、商店和理财流程，不进入营地存档。
2. 只有死亡或通关后的最终结算结果进入营地。
3. 局内金币、经验和掉落统计可展示在结算界面，但不作为营地持久化字段。

## 11. MVP 范围

MVP 阶段建议只做：

1. 固定营地主界面。
2. 7 个建筑的静态展示。
3. 建筑等级读取与显示。
4. 升级选项列表展示。
5. 购买升级项和保存存档。
6. 为战斗准备阶段提供营地成长快照。

暂不做：

1. 自由建造。
2. 居民经营。
3. 资源采集链。
4. 复杂交互动画。
5. 多页面经营大地图。

## 12. 扩展原则

1. 新建筑优先加配置，不优先改流程代码。
2. 新升级项只要对应 stat 已存在，就能直接接入。
3. 新增存档字段必须可兼容旧版本。
4. 新增建筑效果优先通过 `ModifierStack` 结算。
5. 营地功能永远保持“局外入口”定位，不向战斗内侵蚀复杂逻辑。

## 13. 结项判断

本模块可视为完成的条件：

1. 能从启动页进入营地。
2. 能读取并显示建筑等级与升级项等级。
3. 能展示并购买建筑升级项。
4. 能在购买成功后保存局外进度。
5. 能让成长结果在下一次从启动页进入战斗时生效。
