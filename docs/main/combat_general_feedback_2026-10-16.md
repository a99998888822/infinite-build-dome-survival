# 通用受击反馈设计（2026-10-16）

已接入正式主战斗场景。第二版按用户确认改为同次攻击的局部连续累计，并降低震屏幅度；每次卡肉的目标持续时间统一为 0.05 秒。

| 项目 | 当前参数与行为 |
| --- | --- |
| 普通怪物闪白 | 当前贴图轮廓的 RGB 完全变白，保留透明边缘及死亡透明度；纯白保持 70 ms，再用 50 ms 恢复 |
| 小 Boss | 钢甲骑士、幽焰冥狼震动但不闪白；按配置 `enemy_type=elite/boss` 判断 |
| 怪物震动 | 初始最大单轴 14 世界像素，180 ms 衰减；方向每秒切换 60 次，像素对齐 |
| 1–2 只局部受击 | 只播放怪物自身反馈，屏幕不震动、不定格 |
| 累计达到 3 只 | 第一档：最大单轴 1 逻辑画布像素，140 ms 衰减；卡肉 50 ms |
| 累计达到 6 只 | 第二档：2 像素，220 ms 衰减；卡肉 50 ms |
| 累计达到 12 只 | 第三档：6 像素，320 ms 衰减；卡肉 50 ms |
| 累计达到 15、18、21……只 | 每增加 3 个新目标，重复第三档震屏与 50 ms 卡肉，幅度不再升高 |

每次施放使用独立攻击编号，同次攻击的多段命中、投射物、分裂、弹射与附魔伤害共享编号。按物理帧收集伤害，再加入同编号的局部群：半径为 240 世界像素，新群以当前批次最密集的受击位置为固定圆心，后续目标归入最近的有效群。圆心不会随相邻怪物接力移动，远处怪群不会合并。

同一群内的同一怪物只计一次，重复命中不延长累计窗口。连续 0.2 秒有效游戏时间没有命中新目标后，该群累计清零；卡肉与菜单暂停不消耗这段时间。统计使用受伤位置快照，致死命中也计入。达到 3、6、12、15、18……只时触发，9 只不额外触发。若同一瞬间直接命中 18 只，只播放一次第三档反馈，不排队补播前面的五次卡肉；在数帧内逐段跨过阈值则可以多次触发。

原生武器与携带攻击上下文的附魔反应，通过 `take_attack_damage` 在成功结算伤害后登记。燃烧跳伤等没有攻击编号的直接伤害仅保留怪物自身反馈；无效伤害不触发。并行命中取最高反馈请求，不叠加幅度，较轻档位不会盖掉仍在播放的重档位。持续受击会重新触发自身震动；没有额外命中击退，也不恢复旧分类接触粒子。

怪物震动只改贴图的绘制偏移，不改身体位置、碰撞体、动画帧、缩放或跳跃高度。霸体轮廓会跟随这个偏移；霸体计时、抗控规则和显式技能击退保持原逻辑。反馈不用额外的全局随机数，保留历史随机采样，避免改变后续伤害和掉落序列。

震屏作用于战斗画面和远景，HUD 保持稳定。世界画面使用呈现材质移动采样，并在边缘延展像素；相机、鼠标瞄准换算和瞬移跟随不受影响。卡肉暂停 SceneTree 的战斗进程，并让世界 SubViewport 绘制命中帧一次后停止更新，使 GPU 粒子也随画面定格。暂停由常驻节点按真实时间释放，不改 `Engine.time_scale`；实际结束时间会向下一次渲染更新取整。卡肉期间震屏保持第一下偏移，恢复后继续衰减。

键盘、鼠标和触屏的松开事件在卡肉期间继续处理，避免恢复后卡住移动。菜单、换波、战斗退出会清理反馈，恢复场景暂停状态、视口更新模式和呈现材质；菜单原有的 `battle_runtime_paused` 状态不会被解除。第一帧闪白不会消耗命中之前积累的长帧时间。

- [真实武器审阅场景](D:/project/useless/resources/infinite-build-dome-survival/scripts/tests/weapon_hit_feedback_review.gd) 加载正式 `game_root.tscn`，通过主动施放入口使用短刀、榴弹、战锤，伤害由真实武器碰撞产生。固定目标位置与高血量仅用于审阅；榴弹使用审阅装备属性 `area_size=200`、`damage_area_size=200`，以便目标分散展示。战锤使用默认地裂范围与间隔。每段只施放一次，无直接扣血、无手动播放反馈。
- 六段无界面预检与后台 GPU 实机均通过：短刀普通怪／小 Boss 各 1 次伤害、0 次震屏；榴弹分别命中 3／6／12 只，各 1 次反馈；战锤一次挥击命中 18 只，反馈计数依次为 3、6、12、15、18。以真实时间约 60 FPS 录制，不使用固定模拟步进；动图按原始帧时间播放。代码目标定格 50 ms，实际解除发生在期限后的首个渲染更新，存在帧边界取整；本次截图采样的暂停区间约 67–70 ms。
- 后台运行 `private_desktop` 与 `verified_desktop` 一致，`foreground_samples=0`，退出码 0。完整帧、武器伤害回执、反馈时间和后台桌面证明位于 [第二版审阅目录](D:/project/useless/review-archives/weapon-hit-feedback-v2-20261016)。
- 扩展旧测试并非全部通过：短刀测试 18 项、元素反应测试 4 项现有断言失败，涉及武器数值、负重和碰撞／伤害预期。独立项目副本将新增伤害入口改回直接结算、不登记攻击反馈后，重现相同失败；未改变正式配置来迎合旧断言。首次并行元素测试另有 1 项雷火时序断言失败，复跑通过。日志与对照在同一审阅目录。
