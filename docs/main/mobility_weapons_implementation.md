# 位移武器

四种位移武器接入正式装备、升级、商店、附魔与施放流程。基础数值和范围读取 [weapons.json](../../data_config/weapons.json)，自动辅助规则见[逐技能自动释放](per_skill_auto_cast.md)。

| 武器 | 当前行为 |
| --- | --- |
| 突进短刃 | 向选定落点短冲，抵达时圆斩。路径无伤害，动画结束后的残留不追加伤害。 |
| 巨型手持火炮 | 朝前方扇面发射独立散弹，同时后退。散弹沿飞行路径检测，支持既有穿透、分裂与附魔顺序。 |
| 移星秘典 | 闪现落点震击。手动施放留下起点印记，冷却期间可再次触发返回；自动施放不生成印记。返回无伤害。 |
| 斩马刀 | 在起点播放半段跳跃后闪现，斩击沿途敌人，在终点播放剩余半段跳跃。 |

位移动画统一先在起点起跳，再位移，最后在终点落下。当前角色的前后半段各为 3 帧、0.36 秒。短刃和火炮在起跳后分别按原有 0.22 秒、0.28 秒移动，途中保持腾空姿势，到达后才继续后半段；火炮开火与后退同时开始。秘典首次闪现与返回均在起跳半程发生。起跳、移动和落下期间锁定位移与跳跃姿势，其他武器攻击不覆盖跳跃；暂停冻结整个过程，卸下武器或死亡会清理锁定。

短刃和秘典的射程属性影响位移落点范围，伤害范围影响圆斩或震击；额外投射物转为落点伤害段数，不追加玩家位移，不接受穿透、分裂。火炮的射程影响散弹距离，伤害范围影响弹体及碰撞体，不改变后退距离。

位移使用玩家实际碰撞形状检查地形，敌人不直接阻挡移动，途中仍可受伤。回程受地形阻挡时保留印记。命中以敌人身体相交为准，同一敌人的多个碰撞形状去重，并保留墙体遮挡。

原生伤害命中后才进入附魔序列：短刃在落点圆斩、秘典在首次落点震击、火炮在各弹丸接触时触发。空挥、单纯移动和秘典返回不触发；弹跳不重复玩家位移或创建新印记。

秘典首次施放（起跳开始）即开始冷却，落下结束后可返回。可返回时显示返回图标和剩余秒数；提前返回后显示剩余冷却，到期清除印记，玩家不会自动回传。冷却在跳跃期间结束不会中止已开始的动作，也不会重新生成印记；动作结束后恢复就绪。回程起跳期间若出现障碍，则在原地落下并保留尚未过期的印记。暂停冻结计时；死亡、卸下武器、波末及离开战斗清理印记。

正式动画位于 `assets/sprites/weapons/mobility/`，普通帧动画复用预加载图集。世界中不显示这三把武器的悬浮本体。维护时结合[命中规则](weapon_contact_rules_2026-10-19.md)与 [mobility_weapon_integration_test.tscn](../../scenes/tests/mobility_weapon_integration_test.tscn)检查行为。

跳跃时序回归见 [mobility_jump_timing_test.tscn](../../scenes/tests/mobility_jump_timing_test.tscn)，覆盖起跳位置、空中姿势、终点落下、秘典往返、自动施放、障碍、冷却过期和中断清理。
