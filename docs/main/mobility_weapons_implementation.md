# 位移武器实现与绘制审计

2026-10-10范围更新：突进短刃基础圆斩半径由64提高至96像素，既有动画图集按原尺寸放大10%。计入所有帧最外侧火花的像素边界，视觉最大半径约90.23像素，小于96像素伤害半径，留出约5.77像素余量；伤害范围属性使两者按同一比例成长。瞄准伤害圈使用实际96像素半径，位移距离、伤害段数、动画时长以及秘典的64像素震击半径保持原值。

2026-10-10命中修正：突进短刃的落点圆斩与移星秘典的落点震击改为伤害圆和敌人实际物理碰撞体相交判定，支持碰撞体大小、缩放、偏移和禁用状态；同一敌人的多个碰撞形状去重，保留墙体遮挡。此前只判断敌人节点坐标是否进入半径，会漏掉已被刀光擦中的边缘敌人，也会误伤坐标在圈内但碰撞体已移出或禁用的目标。例：半径64的圆斩与半径19.36的小怪碰撞圆相距76时，原实现不命中，修正后命中。

附魔触发规则：短刃在抵达后的圆斩命中、秘典在首次闪现落点的震击命中、火炮在每颗散弹接触敌人时，进入统一的附魔序列并在命中位置触发效果；单纯移动或空挥不触发。短刃路径无伤害，秘典返回无伤害且不再次触发附魔。瞄准时的大椭圆表示位移落点范围，小圆表示落点伤害范围；圆斩动画持续约0.21秒，原生伤害在抵达时一次结算，并非持续接触伤害。投射物数量仍转为落点伤害段数。

2026-10-08 更新：三种位移默认手动，可点击 Esc 武器方框下方的图标，分别开启低频、顺应移动意图的自动辅助；战斗栏同步显示自动／手动图标。自动秘典不创建返回印记，手动秘典保留原返回；所有位移均保留当前按键与右键目的地。详见[逐技能自动释放与位移辅助](per_skill_auto_cast.md)，下文“位移始终手动”为首次接入时的历史规则。

2026-10-07。三把武器已接入正式主动战斗、装备、商店、升级、附魔兼容校验与武器详情。素材由当前模型设计并用本地脚本离线绘制，没有调用图片 API。世界中不显示这三把武器的悬浮本体。

|---|---|---|

- 短刃与秘典：攻击距离只影响位移椭圆，伤害范围只影响圆斩／震击半径；沿用项目属性效率，即属性 +100 对应半径 ×1.5。椭圆限制玩家落点中心，伤害圈可越过椭圆边界。
- 火炮：攻击距离增加散弹射程，伤害范围增大弹体，均不改变后退距离。短刃与火炮对速度曲线 10 → 4 → 0 积分并归一化，精确停到目标点。
- 位移扫掠玩家实际胶囊形状，只针对地形碰撞层；敌人不阻挡位移，途中仍可受伤。闪现也检查地形，避免进入障碍。回程遇阻则保留印记，需回到可通行位置后重试。
- 秘典的冷却与返回窗口共用一个计时器，从首次闪现起算。可返回时使用带返回标记的 PNG 图标，右上角显示剩余秒数，不显示灰色冷却遮罩；提前返回则恢复原图标，灰色遮罩显示剩余冷却比例。冷却到期移除印记与返回标记，恢复原图标并就绪，不自动移动玩家。暂停冻结计时与动画；死亡、卸下武器、波次结束与离开战斗清理印记。按原技能数字键、点击战斗栏返回图标，或键盘移动模式下再次左键施放，均可返回。
- 三把位移武器由玩家手动决定方向；轮椅模式继续自动使用原武器，位移武器保留数字键与战斗栏操作入口。
- 短刃／秘典的投射物数量加成转为落点伤害段数，不追加玩家位移；不接受穿透、分裂。火炮支持原有穿透、分裂和附魔顺序。弹跳只重放本体伤害，不移动玩家、不创建第二个返回印记。
- 火炮分裂每次原始施放最多触发 3 批，命中 PNG 最多生成 12 个；伤害与穿透继续结算，限制的是分裂批次和视觉节点。

## 绘制方式

| 内容 | 正式实现 | 每帧工作 |
|---|---|---|
| 3 把武器图标＋秘典返回图标 | 4 张预制 PNG，正常 Godot 导入 | 状态变化时切换纹理 |
| 短刃拖尾、圆斩 | 预制 PNG 图集 | 单个 Sprite2D 换帧；拖尾跟随位移 |
| 火炮炮口、散弹、命中、尘土 | 预制 PNG 图集 | 纹理区域换帧与平移／旋转 |
| 秘典出发、抵达、返回、震击、印记 | 预制 PNG 图集 | 单个 Sprite2D 换帧；印记 12fps 循环 |
| 瞄准椭圆／圆圈、炮口扇形、箭头、虚线 | 少量动态多边形／折线 | 圈和扇形缓存几何，仅瞄准、属性、玩家位置或返回状态改变时重绘；远距离返回虚线最多 48 段 |
| 既有附魔：黑洞、冰、光剑、水波等 | 复用现有预烘焙素材 | 沿用现有实现 |
| 既有附魔：闪电、风刃、通用粒子等 | 复用现有网格／几何／MultiMesh 粒子系统 | 闪电路径创建时生成不可变像素网格；风刃保留动态几何，通用粒子保留既有预算 |

三把武器原生效果共使用 **11 张动画 PNG 图集、88 帧**，不生成运行时像素粒子，不逐帧创建图片，不在施放时读取磁盘图片。图集共享预加载资源，普通特效仅在动画帧号变化时更新 Sprite2D；世界中没有武器本体节点。散弹复用经过验证的扫掠碰撞、穿透和分裂流程，并用物理空间的范围筛选缩小候选敌人集合。

正式游戏资源位于 `assets/sprites/weapons/mobility/` 和 `assets/ui/icons/weapons/`。2026-10-10 按用户要求删除 10 月 7 日旧试稿、旧生成器及专用美术预演场景；后续编辑以正式 PNG 和已安装的 R01 审阅包为依据。
