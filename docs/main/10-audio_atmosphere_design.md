# 音频与氛围表现模块详细设计方案

本文档定义本项目的 BGM、武器命中音效和基础音量管理。整体音频设计以简洁为主，不配置非必要的拾取、升级、波次、UI、环境或稀有度提示音效。

## 1. 模块目标

1. 建立统一的 BGM 与武器命中音效播放入口。
2. 允许不同武器绑定独立的命中音效。
3. 正确处理近战、范围和远程武器的音效播放次数。
4. 没有正式音频素材时静默降级，不影响战斗逻辑。

## 2. 模块边界

### 2.1 本模块负责

1. 菜单、营地和战斗 BGM 的播放与切换。
2. 武器命中音效的加载与播放。
3. 高频远程命中音效的轻量节流。
4. `master`、`bgm`、`sfx` 音量分组管理。

### 2.2 本模块不负责

1. 玩家攻击启动音效。
2. 敌人死亡音效。
3. 经验球、血包等拾取音效。
4. 角色升级、波次开始和波次结束音效。
5. UI 确认、取消和错误音效。
6. 环境氛围音、低语音和稀有度提示音。
7. 战斗伤害、命中和投射物规则本身。

## 3. 设计原则

1. 音效绑定武器，不绑定敌人。
2. 武器只提供音频资源路径，实际播放统一交给音频管理器。
3. 没有配置或资源不存在时静默处理。
4. 音效播放失败不能中断伤害结算。
5. 同一 BGM 重复请求时不重新开始播放。

## 4. 工程结构

### 4.1 建议脚本

1. `autoloads/audio_manager.gd`：管理 BGM、武器命中音效和音量。

### 4.2 建议场景

音频管理器由 Autoload 动态创建 BGM / SFX 播放器节点，不新增独立音频场景。
不新增环境氛围控制器、稀有度音效管理器或复杂事件注册器。

## 5. 音频分组

1. `master`：总音量。
2. `bgm`：背景音乐。
3. `sfx`：武器命中音效。

建议默认值：

| 配置项 | 默认值 |
|---|---:|
| `master_volume` | 100 |
| `bgm_volume` | 80 |
| `sfx_volume` | 90 |

配置和存档使用 0~100 整数，运行时再转换为 Godot 音频总线增益。

## 6. BGM 设计

MVP 只保留三类循环 BGM：

| BGM ID | 使用场景 |
|---|---|
| `menu` | 角色选择和通用菜单 |
| `camp` | 营地主场景 |
| `battle` | 局内战斗场景 |

场景切换时请求对应 BGM。未配置素材时保持静音并允许输出调试日志。

## 7. 武器命中音效配置

敌人受击音效绑定到具体武器，而不是统一绑定到敌人。

建议在 `weapons.json` 增加：

```json
{
  "hit_sfx": "res://assets/audio/sfx/weapons/sfx_weapon_void_blade_hit.ogg"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `hit_sfx` | String | 否 | 武器命中音效资源路径；缺失或为空时静默处理 |

该字段只影响音频表现，不参与伤害、范围、投射物数量或攻击间隔计算。

## 8. 播放次数规则

### 8.1 近战武器

1. 一次攻击命中至少一个敌人时播放一次。
2. 同一次攻击命中多个敌人仍只播放一次。
3. 未命中敌人时不播放。

### 8.2 范围武器

1. 一次范围攻击命中至少一个敌人时播放一次。
2. 范围内命中多个敌人仍只播放一次。
3. 未命中敌人时不播放。

### 8.3 远程武器

1. 每个投射物拥有独立的命中音效播放状态。
2. 每个投射物第一次命中敌人时播放一次。
3. 同一投射物的后续命中不再重复播放该投射物的命中音效。
4. 多投射物武器按投射物分别播放，因此一次攻击最多播放“投射物数量”次。
5. 同一帧命中音效过多时，音频管理器允许限制并发播放数量，避免声音堆叠。

## 9. 推荐接口

```gdscript
play_bgm(bgm_id: String) -> bool
stop_bgm() -> void
play_weapon_hit_sfx(weapon_id: String) -> bool
set_bus_volume(bus_id: String, volume_percent: int) -> void
```

近战和范围攻击的调用方负责确保每次攻击只请求一次；远程投射物负责确保每个投射物只请求一次。

## 10. MVP 实施范围

MVP 只实现：

1. 菜单、营地、战斗 BGM 切换。
2. 武器配置中的 `hit_sfx` 字段。
3. 近战和范围攻击一次命中只播放一次。
4. 远程攻击每个投射物只播放一次。
5. `master/bgm/sfx` 音量管理。
6. 缺少素材时静默降级。

## 11. 验收标准

1. 三类 BGM 可以通过统一接口切换。
2. 武器能读取自身 `hit_sfx`。
3. 近战和范围攻击命中多个敌人时只播放一次。
4. 多投射物远程攻击按投射物分别播放一次。
5. 同一投射物后续命中不会重复播放。
6. 没有音频素材时游戏仍能正常启动和战斗。

## 12. 后续扩展原则

当前不设计其他音效。后续确有需要时，再按具体玩法单独增加，不提前建立环境音、稀有度音效或复杂混音系统。
