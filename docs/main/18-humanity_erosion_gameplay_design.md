# 理智议价与侵蚀压力改造方案

日期：2026-09-23  
状态：部分实现。小 Boss 场景、波次和侵蚀决定的数量期望、波初一次抽取并固定总量、仅前半段生成、30% 红色矩形冲刺、遗物选择掉落物及升级弹窗复用已接入。遗物基础概率为 100%，按本波已落地份数衰减；生命为同波普通怪的 20 倍、护甲 2 倍。交易议价、侵蚀增加普通怪数量及幸运掉落概率乘区仍待接入。奖励选择列表的稀有度已复用升级奖励的幸运权重。

## 1. 设计结论

建议采用两条独立、可以通过遗物联动的规则：

- **理智决定准备阶段的交易条件**：高理智买得便宜、卖得更好；低理智承担有限的议价损失。
- **侵蚀度决定下一波的额外战斗压力**：侵蚀越高，普通怪密度越大，精英出现的机会越高；击败精英获得更好的掉落。

这里将“理财时的议价”具体落在目前理财准备界面里的商店购买和库存出售。银行本金、利率、结息次数、存取款机会仍由各自规则和遗物决定。这样玩家能明确区分“议价”“利息”“幸运”和“掉落率”的作用。

原始理智和侵蚀度继续允许超过常规范围；只限制它们在新增系统中的换算结果。内部 ID 保留 `humanity`、`divinity`，玩家界面统一使用“理智”“侵蚀度”。

## 3. 理智：交易议价

### 3.1 数值公式

令 `H` 为最终理智，`B` 为议价修正，单位为百分比：

```text
B = clamp((H - 100) × 0.2, -20, +20)
购买乘数 = 1 - B / 100
出售乘数 = 1 + B / 200
```

100 为标准价基准；每增加 10 理智，购买乘数减少 0.02，出售乘数增加 0.01。换算在理智 0～200 之间线性变化，超出后维持边界效果。

| 理智 | 议价修正 | 购买价格乘数 | 普通回收价值乘数 |
|---:|---:|---:|---:|
| -50 | -20% | ×1.20 | ×0.90 |
| 0 | -20% | ×1.20 | ×0.90 |
| 50 | -10% | ×1.10 | ×0.95 |
| 80 | -4% | ×1.04 | ×0.98 |
| 100 | 0% | ×1.00 | ×1.00 |
| 110 | +2% | ×0.98 | ×1.01 |
| 150 | +10% | ×0.90 | ×1.05 |
| 200 | +20% | ×0.80 | ×1.10 |
| 300 | +20% | ×0.80 | ×1.10 |

低理智的惩罚最多是商品涨价 20%、普通回收价值降低 10%，不会造成无法交易、无法存款或结息失效。阶段标签只负责解释状态，不在 80、50、30 阈值处追加隐藏惩罚。

### 3.2 生效范围

| 操作 | 是否议价 | 规则 |
|---|---|---|
| 金币购买武器、武器升级、遗物 | 是 | 所有现有折扣之后，乘理智购买乘数 |
| 出售武器本体、升级价值、未装备附魔 | 是 | 普通回收价值乘出售乘数 |
| 武器战斗称号的出售奖金 | 否 | 战斗取得的奖励按原值相加 |
| 免费升级奖励/免费选择 | 否 | 价格仍为 0 |
| 商店刷新 | 否 | 使用现有递增刷新费用 |
| 存款、取款 | 否 | 1 金币与 1 本金按原规则交换，不增设手续费 |
| 利率、结息与结息门槛 | 否 | 沿用理财与遗物规则 |
| 怪物金币、经验和掉落概率 | 否 | 沿用金币获取、经验获取和掉落率属性 |
| 商品稀有度 | 否 | 沿用幸运及现有区域规则 |

本期也不增加需要玩家反复点击或随机成功的“讲价”按钮。理智持续影响明示报价，避免准备阶段多一套重复操作。

### 3.3 折扣叠加和取整

```text
商店价格乘区 Mshop = 现有商店价格属性及遗物折扣的乘积
理智乘区 Mhumanity = 1 - B / 100
最终买价 = max(1, ceil(基础价 × Mshop × Mhumanity))
综合优惠 = 1 - Mshop × Mhumanity
```

仅对付费商品使用最低 1 金币。免费奖励走独立免费分支。全部乘数计算完成后只向上取整一次。理智和“商店价格加成”是相互独立的乘区，属性栏中的商店价格加成只显示本乘区效果；综合价格另行显示，禁止把理智写回该属性或将两个百分比直接相加。商店价格乘区沿用现有购买范围，不额外应用于出售。

例如基础价 100、两张传单广告、理智 150：

```text
100 × 0.92 × 0.92 × 0.90 = 76.176 → 支付 77 金币
连续值综合优惠 = 23.824%
```

价格主文本显示 `77(85-8)`：85 为同一商品在商店价格乘区生效、理智中性时的整数报价，77 为应用理智后的最终报价。详细提示仍可显示“商店优惠 15.36%”“理智再优惠 10%”；连续值综合优惠为 23.824%，不是两个百分比相加。

商品单价是整数，小幅理智变化可能暂时不改变便宜商品的实付价。只有两个整数报价不相等才显示括号；相等时只显示最终数字。属性提示仍显示准确的议价百分比，不引入跨交易补差或随机舍入。

括号统一显示“最终价(不计理智的报价±理智价差)”：购买优惠可显示 `20(25-5)`，购买涨价可显示 `30(25+5)`；出售增益可显示 `22(20+2)`，出售损失可显示 `18(20-2)`。基准价是使用同一完整报价函数、仅将理智换算设为中性的反事实结果；称号奖金等非理智因素保持一致。最终报价仍从未取整的购买基数计算，不能先对基准报价取整再乘理智。

### 3.4 出售价值与成本记录

先保留现有的本体、每级升级折算规则，得到普通回收价值 `S0`：

```text
各付费部分回收值 = floor(min(该部分参考价, 该部分实付价) × 对应回收比例)
S0 = 本体回收值 + 各级升级回收值
最终卖价 = floor(S0 × 理智出售乘数) + 战斗称号奖金
```

当前回收比例为 50%，最大议价提升后普通回收值不超过实付基础的 55%。理智变化、折扣或多次买卖不会使原样商品凭空增值；称号奖金是另行获得的战斗收益。

附魔当前没有对应的金币购买入口。首期可继续使用参考价作为其回收基准；成本字段需预留，未来一旦加入购买入口就必须写入实付价格后再开放出售。

掉落、初始装备、免费奖励的成本来源标为对应来源，按参考价回收；必须区分“免费来源”和“付费 0 金币”，不能拿缺省数值混用。升级、附魔装卸不清除已有成本记录，卖武器返还附魔的现有行为保持有效。

### 3.5 报价时机

1. 商品生成时固定本轮基础价和商品身份；本轮已持有遗物数量造成的基础价变化仍在下次生成商品时更新。
2. 交易相关属性变化后，立即重算当前货架上未购买商品的折扣价和库存卖价；不更换商品、不消耗刷新次数。
3. 本次购买按点击时已展示且仍有效的报价扣款，再发放遗物，再统一重算剩余商品。新买到的理智或折扣不能反向优惠本次购买。
4. 报价中包含 `offer_id / generation / price_revision / price`；出售报价也包含议价快照。若提交时已过期，更新界面并返回“报价已更新”，不按玩家没看到的价格扣款。
5. 同一交易事务内的多次 `stats_changed` 合并为一次报价更新，防止出现临时中间价。
6. 预览使用同一报价服务和现有隔离模拟：先模拟支付当前价，再获取遗物，再计算交易变化，不能更改真实余额、随机状态和报价版本。

## 4. 侵蚀度：下一波压力

### 4.1 生效时机

侵蚀造成的战斗压力在每波开始时固定：

```text
准备阶段决策完成
→ 执行理财和玩家的波次开始遗物效果
→ 完成派生属性刷新
→ 读取最终侵蚀度，建立本波压力快照
→ 开始计时和刷怪
```

神性融合在波次开始增加的侵蚀计入本波。战斗中复活、护盾破裂或拾取遗物导致侵蚀变化，影响下一波刷怪；不会立即提升当前敌人属性或突然改变本波精英判定。

侵蚀对护甲、理智、利率等已有遗物派生效果仍按现有规则实时生效。界面同时表达“当前属性值”和“本波使用的侵蚀值”，避免玩家误以为属性没有生效。

波末增加的侵蚀会在下一次准备界面显示。准备界面的下一波预测还要包含确定会触发的波初增量，例如当前侵蚀 19、持有一件神性融合时，预测按 20 计算。

### 4.2 普通怪密度

```text
E = clamp(本波侵蚀快照, 0, 150)
侵蚀刷怪乘数 = 1 + 0.003 × E
```

每 10 侵蚀增加 3% 的计划刷怪数量，上限 +45%。侵蚀为负时，新增压力按 0 处理，原始属性和已有遗物计算不变。

不再额外缩短刷怪间隔，也不给所有普通怪追加生命、攻击、护甲或移速。波次和区域已有的成长继续承担这些职责。

数量增幅在原有波次、连战与怪物数量增幅计算结束后相乘。例如原机制预计 1,000 只，侵蚀 50 时约为 1,150 只。

采用每个刷怪组独立的小数累计：

```text
N0 = 当前机制算出的本次基础生成数量
额外额度 += N0 × (侵蚀刷怪乘数 - 1)
本次额外数量 = floor(额外额度)
额外额度 -= 本次额外数量
本次计划数量 = N0 + 本次额外数量
```

首期保留现有基础数量计算中的取整方式，保证侵蚀为 0 时计划生成序列不变。只对新增侵蚀部分累计小数；避免 `1 × 1.003` 向上取整成 2。每波开始清空该额度。实现时处理浮点边界误差，例如取整使用小容差，并将误差范围内的负余量归零。

### 4.3 小 Boss 总量与前半段生成

小 Boss 已改为按期望在波初抽取一次总量，不再按每 3 秒的事件概率抽取。读取波初遗物触发后的侵蚀，抽取后固定本波时间表：

```text
第 1 波：0 只
第 2 波起：
  基础期望 = 波数 / 10
  侵蚀乘数 = 1 + clamp(波初侵蚀, 0, 100) / 200
  本波数量期望 E = min(基础期望 × 侵蚀乘数, 3)
  本波计划总量 = floor(E) + Bernoulli(E - floor(E))

每波最多 3 只，小数部分只决定是否多生成 1 只。
```

| 波次 | 侵蚀 0 的期望 | 侵蚀 50 的期望 | 侵蚀 100 的期望 |
|---|---:|---:|---:|
| 第 1 波 | 0 | 0 | 0 |
| 第 5 波 | 0.5 | 0.625 | 0.75 |
| 第 10 波 | 1 | 1.25 | 1.5 |
| 第 15 波 | 1.5 | 1.875 | 2.25 |
| 第 20 波 | 2 | 2.5 | 3 |

期望为 0.5 时，本波有 50% 概率生成 1 只，否则为 0；期望为 1.5 时，1 只和 2 只各占 50%。整数期望直接生成对应数量，减少波动。侵蚀在战斗中变化只影响下一波，不临时追加。小数抽取使用独立 RNG；普通怪的侵蚀数量增幅仍是另一个待接入系统。

### 4.4 时间表、替换与截止规则

- 首个生成点默认在第 5 秒，其余均匀分布在前半段。生成前的 0.75 秒提示也计入限制：小 Boss 开始出场提示的截止时间为半波时间减去 0.75 秒，确保正常帧率下提示能在前半段结束。
- 例如 60 秒、计划 2 只时，计划开始提示的时间为 5、17.125 秒；不等待前一只死亡。
- 达到时间点后，替换下一次普通刷怪中的一个名额，总怪数不重复增加。普通配置通过 `elite_replacement_id` 指定替换目标。
- 计划总量本身不超过原同屏上限，不再因为前一只未击杀而把后续小 Boss 推迟到后半段。
- 到达截止时间后，尚未生成的计划直接失效，后半段不补生成。极端卡顿或没有合适普通刷怪名额时，实际数量可能低于计划；快照分别记录计划数、实际数和波初侵蚀。
- 暂停同时冻结波次时钟；清场取消剩余时间表。Boss、召唤物等未配置替换目标的敌人不参与替换。

当前普通怪理论流量较高，还需独立加入可配置的性能保护。建议以同屏存活总数 400、每物理帧最多新建 32 个敌人、待生成队列最多 64 个且过期时间 0.5 秒作为压测起点。超额丢弃，不把未生成怪物累积到下一波或突然集中补发。

这些性能值需要目标设备实测后确定；它们对低侵蚀与高侵蚀一视同仁，可能影响现有后期难度，必须单独比对基线。达到性能上限或精英同屏上限时，实际压力会饱和，不能宣称仍严格按理论数量增加，也不以隐藏伤害补偿。

## 5. 精英实体和收益

### 5.1 首期精英规格

首期新增“裂甲奔袭者”，采用完全重绘的大体型像素精灵和小冲刺技能，克苏鲁元素约占 10%。已接入独立精英场景，复用通用受击、状态、死亡与掉落接口。素材规格见 [冲刺精英资源制作规格](../asset/elite_rusher_assets.md)。

| 项目 | 相对于同波、同区域普通怪的建议值 |
|---|---|
| 最大生命 | ×20，按用户要求在原 ×2 方案上再乘 10；同波普通生命取整后乘算 |
| 接触伤害 | ×1.15，最后一次统一取整 |
| 护甲 | ×2，包含波次和区域加成后的护甲；0 护甲翻倍仍为 0 |
| 常规移速 | 相同 |
| 控制抗性 | 沿用普通怪，首期不增加控制免疫 |
| 生成预警 | 地面标记 0.75 秒，期间不可伤害玩家，尚未成为可攻击实体 |
| 冲刺技能 | 蓄力 0.8 秒并显示红色 30% 不透明度直角矩形路径，无箭头、无圆角，随后沿锁定方向短距离冲刺 |
| 外观 | 独立轮廓、头顶精英符号、短血条；不只依赖颜色 |
| 尺寸 | 已绘制素材可见范围约为普通怪的 2 倍（含角与触须），独立碰撞体随实际主体校准；宽大装饰不扩张伤害范围 |

倍率以同波普通怪最终结果为基准应用一次，避免把波次/区域增幅重复计算。冲刺是首期必需技能：追踪→蓄力并锁定方向→冲刺→收招→追踪。建议冲刺 240 像素、用时 0.4 秒，收招 0.5 秒，结束后冷却 6 秒，生成后至少 2 秒才可蓄力。路径在蓄力开始时固定，不能跟随玩家转向；采用无箭头、无圆角的直角矩形显示实际技能区域，不透明度始终为 30%，不把预警同时画在 sprite 与地面上造成叠色。后续碰撞实现需与矩形对齐，不能仍按带圆头的胶囊范围造成提示外伤害。

建议冲刺伤害为当前接触伤害 ×1.2，同次冲刺最多命中同一玩家一次；冲刺期间由技能伤害接管，避免接触伤害重复结算。撞墙停止，死亡、波末清场或眩晕/冻结立即取消技能和预警；暂停冻结状态。技能参数与路径几何均由同一份配置驱动。多个精英的蓄力起始时刻至少错开 0.35 秒。具体数值需要试玩调节。

不在当前 `DataRegistry` 返回的共享字典上直接修改 `enemy_type` 或 `drop_table_id`。实例保存自己的 `enemy_rank / elite_profile_id / effective_drop_table_id`，掉落查询读取实例覆盖值，避免一只精英导致后续普通怪都变成精英掉落。

### 5.2 掉落建议

| 奖励 | 首期方案 |
|---|---|
| 基础经验球 | 精英由当前表中的 2 调整为 3，拾取同时获得 3 基础金币 |
| 遗物 | 基础 100%；生成遗物掉落物；本波每落地 1 件精英遗物，后续精英遗物概率再乘 50%，不等待拾取 |
| 血包 | 保留基础 20% |
| 附魔卷轴 | 保留当前精英表各项配置，首期不额外提升品质 |
| 掉落率修正 | 保留现有掉落率乘区；精英的随机遗物、附魔与血包另乘幸运修正；侵蚀不直接乘掉落概率 |

以上经验球由 2 改为 3 是本方案提出的新调整，尚未写入配置。基础经验/金币奖励应保证发放；随机条目再应用掉落率修正。不能把精英奖励叠加普通怪掉落表发两遍。

幸运继续影响商店/升级奖励中遗物刷新的稀有度，并新增对精英随机奖励出现概率的提升。建议使用收益递减的独立幸运乘区，避免无限幸运轻易使所有精英奖励必掉：

```text
L = max(幸运, 0)
精英奖励幸运乘数 = 1 + 2 × L / (L + 100)
精英随机条目衰减前概率 P0 = clamp(基础概率 × 现有掉落率乘数 × 精英奖励幸运乘数, 0%, 100%)
精英遗物最终概率 = P0 × 0.5^n
其他精英随机奖励最终概率 = P0
n = 本波已经成功生成的精英遗物掉落物数量
```

幸运 0、50、100、300 时，该乘数分别为 1、约 1.667、2、2.5。此幸运曲线仍待接入。遗物基础概率已改为 100%，在没有负向掉落率修正时 P0 已封顶，未来正向幸运不会继续提高这一条目的概率；幸运仍可提升未封顶的血包和附魔概率。保持先封顶、后衰减，不能用幸运抵消本波衰减。基础经验/金币保底不重复乘幸运，普通怪随机掉落暂不增加该乘区。

本波遗物衰减已接入现有 `DropRewardSystem`。当前实际概率仍为基础概率乘现有 `drop_rate_percent` 乘区，限制在 0%～100% 后，再乘衰减；未来接入幸运时先计入 `P0`，最后统一衰减，避免超高加成抵消衰减。掉落表配置 `elite_relic_decay_percent: 50` 表示每落地一件后保留上一档概率的 50%，遵循工程的整数百分比配置规范。

| 本波已落地精英遗物 n | P0=100% 时后续遗物概率 |
|---:|---:|
| 0 | 100% |
| 1 | 50% |
| 2 | 25% |
| 3 | 12.5% |
| 4 | 6.25% |

只在遗物选择掉落物成功生成后增加计数；概率未中或未能生成掉落物时不增加。掉落物表示一次遗物选择机会，可靠近吸取，波末自动收取；拾取后复用升级奖励弹窗，候选仅为遗物，选定一件后效果才生效。候选数量、幸运稀有度、属性预览、付费刷新和跳过沿用升级奖励规则；跳过消耗该次选择。生成候选时过滤已达叠加上限的遗物，不提前指定地上的遗物身份。商店、升级及其他来源不计入精英衰减；经验、金币、血包和附魔不受这项衰减影响。

同帧击杀多只精英时，在生成掉落物环节逐只读取最新计数并判定。每次判定仅可结算一次；波末先处理本帧排队掉落，再自动拾取，最后进入结算。新波次、新一局清零计数并使旧的延迟动作失效；失败退出/重开不会把未拾取遗物发给新一局。此方案不设硬性件数上限。验证记录见 [精英奖励衰减检查清单](checklist/elite_relic_decay_2026-09-23.md)。

选择列表复用当前升级奖励候选池中的遗物及幸运稀有度权重。拾取多个掉落物与同时升级时，按队列依次显示，不覆盖当前选项。每次选择与每次刷新都有独立卡片 ID，旧卡片不能领取下一份奖励。波末先吸收掉落物和经验，再处理奖励队列，最后进入准备阶段；最后一波也先完成选择再显示胜利。遗物属性在选定后生效，不追溯已经完成的波末结息。

原基础 5% 的遗物期望估算已作废。当前 100% 基础掉落配合逐件减半，保证无负向掉落修正时首件奖励；后续收益递减。生命提高到普通怪的 20 倍后，精英接近小 Boss，需要实测每波击杀数、击杀耗时、同屏上限占用时间和遗物收入，不能只由出现次数推算实际收益。

波末清场不是击杀，不触发精英掉落、击杀回血或小费。波次维持计时通关，不因存活精英延长；小 Boss 只在前半段生成，后半段留给玩家处理存活敌人和拾取奖励。

### 5.3 高侵蚀的收益边界

侵蚀增加普通怪数量，本来就增加潜在经验、金币、击杀回血和掉落机会；它是一条“有能力击杀时收益更高”的路线。不要再额外给侵蚀叠加通用经验/金币倍率。

后期如果出现“多刷的怪只提供免费资源、完全没有压力”，优先检查波次基础强度、同屏上限与强势构筑击杀效率，再调整密度曲线或精英耐久。不能仅凭理论敌人数认定风险已经充分。

## 6. 遗物联动与原有语义

| 遗物/组合 | 新增影响 | 处理原则 |
|---|---|---|
| 人性护符 | 理智 100→110 时，购买乘数 1→0.98，出售乘数 1→1.01 | 与幸运 -5 构成交易收益和品质机会之间的选择；效果有上限 |
| 黄铜怀表、刺鼻香包、真银护甲 | 原有少量理智加成开始提供累积交易收益 | 不为追求整数单价变化放大原始数值 |
| 守心铜鉴 | 波末理智恢复逐渐改善议价；金币获取加成仍作用于原有来源 | 报价在波末效果结算后刷新 |
| 理智扣减遗物 | 战斗收益伴随未来购买涨价、回收价降低 | 不再额外触发通用侵蚀加速，避免两重隐性惩罚 |
| 守魂人面石雕 | 侵蚀可通过遗物变成理智，改善交易条件 | 不能消除侵蚀刷怪压力；议价输出有上限 |
| 轮回业火之烛 | 维持现有禁止后续理智增长的约束，长期议价更难恢复 | 不能在报价或预览层另外补理智；保留已经存在的理智加成 |
| 石雕与蜡烛 | 使用已修复的派生属性和禁增规则 | 依赖获取顺序的已修复问题不能重现 |
| 神性融合 | 侵蚀同时提供现有利率收益和下一波压力 | 波初 +1 先结算再固定本波压力；议价不再额外增加利率 |
| 苦难前行之枷锁 | 侵蚀换取护甲，同时引来更多普通怪和精英 | 新增敌人压力不额外堆护甲，保留构筑应对空间 |
| 代价生命之种 | 复活 +20 侵蚀，可能跨过每 50 侵蚀一个小 Boss 的数量档位；普通怪数量增幅仍待接入 | 达到本波总量上限后不再增加；本波计划保持不变 |
| 虚空触手 | 护盾破裂积累侵蚀，影响下波压力，现有派生收益即时刷新 | 防止本波“破盾→立即加压→继续破盾”的突变 |
| 生命力药瓶、屏障结晶、密教圣盾等 | 防御能力附带后续遭遇压力 | 使用现有侵蚀增量，不增加未写明的积累来源 |
| 传单广告与薪酬调整方案 | 原折扣/涨价乘数再与议价乘算 | 综合价格和预览使用同一计算结果 |
| 高利契约、复利宝典、永续年金卷轴 | 保持已确认的结息语义 | 议价不更改契约门槛、结息次数或宝典成长 |

生命之种在刷新遗物后补回复活次数仍按已确认设计执行；当前远程武器不读取近战增伤也维持现状。

原始理智/侵蚀无上限而新增议价/压力有上限，意味着极端侵蚀构筑仍可能从枷锁、神性融合继续获益。这是可控难度所采用的取舍，不等于已经证明无限叠加的平衡性；需要单列极端构筑测试，不在本次方案中悄悄修改遗物效果。

本期不增加自然理智衰减、自然侵蚀增长、自动侵蚀净化或付费清洗服务。玩家通过遗物取舍管理这两项属性；后续若需要更强的回退手段，再单独设计净化的成本和使用次数。

## 7. 界面、预览与说明文本

### 7.1 准备/理财界面

在交易区显示简短摘要：

```text
理智 150 · 买入优惠 10% · 普通回收价值 +5%
遗物优惠 15.36% · 综合优惠 23.82%
```

购买卡片、购买按钮、出售预览/确认与成交反馈共享价格格式化函数，显示 `20(25-5)` 或 `22(20+2)`；理智造成的整数差为 0 时仅显示 `25`。括号中的基准已经计入所有其他适用因素。详细提示说明独立乘区和取整；出售明细保留称号奖金。利息摘要继续显示真实有效利率，不把议价混入利率。

增加下一波压力摘要，例如下一波为第 10 波：

```text
当前侵蚀 49 → 下波计入 50（神性融合 +1）
侵蚀额外刷怪 +15%
下一波小 Boss：3 只 · 仅前半段生成
当前波次小 Boss 总量上限：3 只
```

这里显示计划总量；实际数可因极端卡顿或缺少可替换名额而减少，但不会补到后半段。第一波明确显示不生成小 Boss。

### 7.2 战斗 HUD

- 属性栏显示实际理智、侵蚀度；鼠标停在“理智”名称上，显示 100 为标准价、当前购买/出售修正、与商店价格独立乘算以及整数价格不变时省略括号的说明。
- 鼠标停在“幸运”名称上，显示“提高遗物刷新时出现高稀有度的机会；提高精英怪随机奖励的掉落概率”，并列出当前精英奖励幸运乘数。不能将未来规则提前标记为已生效。
- “商店价格加成”属性只显示自身乘区，提示与理智独立；交易详细报价才显示综合结果。
- 侵蚀提示区分“本波压力按 30 计算”和“当前 50，下波生效”。下一波不存在时不显示下波预测。
- 精英进场有地面预警、简短音效和身份标记；多个精英不会用重复全屏提示阻断操作。
- 阶段名称作为主题表达；精确效果读公式，不在阶段边界额外跳变。

### 7.3 遗物预览

涉及理智、侵蚀、它们的派生属性或折扣时，增加相关行：

```text

买入优惠：0% → 2%
普通回收价值修正：0% → +1%

下波计入侵蚀：40 → 50
侵蚀额外刷怪：+12% → +15%
下波小 Boss 期望：1.2 → 1.25 只（示例为第 10 波；实际抽取 1 或 2 只）
```

蜡烛阻止理智增长时，显示“本次理智增长被阻止”，不展示不存在的折扣收益。战斗中升级界面的侵蚀预览也明确作用于下一波。

### 7.4 文案统一

建议属性说明：

- 理智：“影响准备阶段的交易议价。100 为标准价，越高购买越便宜、普通回收价值越高；实际修正见详情。理智本身不自动改变侵蚀增长。”
- 侵蚀度：“提高下一波的小 Boss 计划数量，每波开始结算遗物效果后固定，只在前半段生成；战斗中变化于下波生效。”普通怪数量增幅接入后再补充说明。
- 幸运：“提高遗物刷新时出现高稀有度的机会；提高精英随机奖励的掉落概率。基础经验和金币数量不受该奖励概率修正影响。”

具体百分比从配置生成到详情提示，避免在多处写死。同步更新基础属性、敌人波次、UI 流程、掉落文档。`augmentations_list.md` 中的遗物效果沿用用户基准，只在批准对应平衡修改时调整。

## 11. 调参与观测

每波记录：波数、理智、实际侵蚀和压力快照、理论/实际刷怪数、性能丢弃数、精英机会/成功/受限次数、精英生成/击杀数、伤害来源、经验金币收入、遗物掉落数、最低生命和死亡原因。

每次交易记录：原价、遗物乘数、理智乘数、实付/到账、交易来源；用于验证议价收益，而不是在玩家界面展示技术日志。

首轮目标是验证以下趋势，不把它们当作已经成立的结论：

1. 同样商品序列下，高理智能稳定节省资源，低理智仍能完成必要构筑。
2. 同波同构筑下，增加侵蚀能明显提高遭遇压力；只有成功击杀更多敌人时才兑现额外收益。
3. 精英在战斗中可辨认、可处理，后期不会因基础刷怪量增长而自动变成精英海。
4. 石雕提供的交易收益不能抹掉侵蚀遭遇压力；防御遗物提供有效应对方式。
5. 性能保护不是每波长期饱和。若大量生成被丢弃，应先校准当前波次流量和目标设备预算，再提高侵蚀上限。

建议调参顺序：先稳定当前普通怪基线和生成性能，再调侵蚀密度，随后调小 Boss 总量、生成时间与耐久，最后调奖励和理智议价斜率。每次只改变一类因素，保留同种子对照。
