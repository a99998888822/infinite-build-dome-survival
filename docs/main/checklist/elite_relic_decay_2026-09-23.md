# 精英战斗与遗物掉落物检查清单

日期：2026-09-23，更新：2026-09-24。最新规则为按期望在波初抽取一次数量、前半段生成的小 Boss，以及遗物选择掉落物；侵蚀数量加成已翻倍，所有怪物新增侵蚀属性加成。

## 设计结论与实际规则

高强度精英配合高奖励成立，但当前生命更接近小 Boss，仍需试玩评估击杀时间。生命从原方案的普通怪 2 倍再乘 10，成为同波、同区域普通怪的 **20 倍**；护甲为普通怪经过波次和区域修正后的 **2 倍**。基础 0 护甲翻倍仍为 0，后续波次的护甲成长会被翻倍，且真正进入减伤计算。

遗物选择机会的基础掉落率为 **100%**，计算规则：

```text
P0 = clamp(基础遗物概率 × 当前掉落率乘数, 0%, 100%)
后续遗物概率 = P0 × 0.5^n
n = 本波已成功落地的精英遗物件数
```

无负向掉落率修正时依次为 100%、50%、25%、12.5%、6.25%。概率未中不会继续衰减；每次生成新的选择掉落物才增加计数。遗物效果在弹窗选定后生效。候选列表已复用升级奖励的幸运稀有度权重；幸运对掉落概率的乘区仍待接入，不能放在衰减之后抵消限制。

可调整配置：`data_config/drop_tables.json` 的 `elite_relic_decay_percent: 50` 表示每落地一件后保留上一档的 50%；`data_config/enemies.json` 的 `elite_profile` 配置生命、护甲、冲刺、配额和前半段生成节奏。

## 奖励检查

- [x] 地上显示三块符牌与金色底座，代表一次选择机会，不提前指定遗物。
- [x] 可靠近吸取，也可通过身体接触拾取；暂停和玩家死亡时不自动领取。
- [x] 波末自动收取剩余选择机会；与升级奖励排队，选择完后进入准备阶段；最后一波先选完再显示胜利。
- [x] 最后一帧排队的死亡奖励先生成，再收取；不会被清场漏掉。
- [x] 落地即计入衰减；放在地上不捡不能绕过衰减，拾取也不会重复衰减。
- [x] 同帧击杀逐只读取最新概率；重复动作不可重复掉落或重抽。
- [x] 新波次、新一局清零计数；旧波排队动作无效；重开不领取旧局地上遗物。
- [x] 候选仅包含未达叠加上限的遗物，默认三选一；数量、稀有度、预览、付费刷新与跳过复用升级奖励。
- [x] 拾取不自动授予遗物、不伪造升级、不附赠升级回血；选择后发奖，跳过消耗本次选择。
- [x] 每份奖励和每次刷新使用独立卡片 ID；旧卡片不能重复领取后续奖励。
- [x] Boss、商店和其他获取来源不参与精英衰减；精英经验、金币、血包及附魔概率不受遗物衰减影响。
- [x] 波次快照分别统计 `elite_relics_dropped`、`spawned_relics`、`collected_relics`、`selected_relics`。

## 精英战斗检查

- [x] 独立 `EliteRusher` 场景使用原创帧表；生命 20 倍、护甲 2 倍；普通怪配置不被污染。
- [x] 0.75 秒出场提示；0.8 秒蓄力、0.4 秒冲刺 240 像素、0.5 秒收招；冷却 6 秒。
- [x] 蓄力时锁定方向，路径为红色 30% 不透明度直角矩形，无箭头、无圆角；游戏绘制参数与矩形扫掠判定一致。
- [x] 一次冲刺最多命中一次，冲刺和收招阶段不额外执行普通接触攻击。
- [x] 撞墙停止；冻结/眩晕中断；暂停冻结技能时钟；死亡和波末清场移除路径。
- [x] 真实死亡生成奖励，波末清场不发击杀奖励。
- [x] 第一波 0；其余波次期望为 `min(波数/10 × (1 + clamp(侵蚀,0,100)/100), 3)`。侵蚀 0 时，第 10 波期望 1，第 20 波期望 2。
- [x] 波初抽取 `floor(E) + Bernoulli(E-floor(E))` 并固定数量；单波最多 3 只。侵蚀使用波初快照，不等待前一只死亡。
- [x] 期望和快照读取不消耗数量 RNG；整数期望无数量波动，小数期望只能落在相邻整数。
- [x] 默认从第 5 秒开始，均匀分布在前半段，预留 0.75 秒出场提示；截止后未执行计划失效，不补到后半段。
- [x] 复用普通生成名额，记录计划数与实际数；卡顿越过截止时间、暂停、重开和清场处理已验证。
