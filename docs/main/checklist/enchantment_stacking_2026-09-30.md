# 重复附魔、燃烧归属与属性预览

> 历史实验记录：下列抽样比例、参数与检查计数对应当时输入，不代表当前主动战斗版本；当前配置与多投射物审阅见 [2026-10-04 记录](../../asset/multi_projectile_review_2026-10-04.md)。

日期：2026-09-30。承接附魔掉落与强度调整，按用户最新确认实施。

## 重复装填

- 同一武器的每份元素／状态附魔独立触发：两份电火花产生两条连锁，两份结霜产生两个领域，两份落雷产生两个延迟落点。
- 各份附魔读取自己的参数和随机值，不再把后一份参数覆盖到前一份；同类另一份的局部修饰不重复放大本份效果。武器基础、遗物与明确的跨效果修饰仍正常生效。
- 多份弹跳在本轮第一次命中时立即分别追加攻击；之后的命中不再触发，追加攻击不可递归弹跳。
- 属性附魔仍按当前武器累加。分裂、穿透沿用已有逐份计算；榴弹的每轮子榴弹总上限保留。
- 状态效果按份数触发，但已有敌人状态遵循自身规则：重复冰不会把冻结时长相加；同一武器的多份火焰不会叠加燃烧伤害，遵循下一节的来源规则。

## 燃烧

- 按武器来源记录伤害贡献与小数余量。A 每跳 10、B 每跳 20 时，合计每跳 30，伤害统计分别归入 A、B。
- 燃烧尚未结束时，A 或 B 再次施加只刷新整组燃烧的持续时间，不增加、替换或降低已有贡献。C 首次加入时才新增 C 的伤害。
- 同一武器的普通攻击、火池、分裂及弹跳共享该武器来源，不会靠连续命中无限叠加。
- 每份贡献独立保留小数伤害；圣火对各来源伤害增幅一次。自然结束、被水清除或被电引爆时一并清空来源；下一次燃烧重新取值。

## 武器属性预览

- 武器栏与理财界面复用同一份实时武器详情，主伤害显示实际加成后的非暴击数值，并保留基础伤害组成。
- 巨力／智慧后的元素附魔基数单独显示；暴击率、暴伤、攻击间隔、投射物／连续攻击数量沿用实际武器属性。
- 炉灯展示扩大的实际扇面角度；短刀、触手、长枪、战锤、摆锤及榴弹展示对应的伤害宽度或半径。
- 显示弹跳追加次数。装填、卸下、转移后从当前武器重新读取数值；预览不消耗暴击随机数，也不修改战斗状态。

## 领域边界

- 只扩大伤害区域，包括本体接触区域、结霜、水流、光辉剑、黑洞、火池、落雷、风刃宽度和光冰反射的伤害扇面。
- 不扩大攻击距离、搜敌距离、连锁距离、传播距离、风刃飞行距离或击退距离。
- 电火花连锁没有额外伤害区域，领域不改变其连锁距离。纯控制震荡同样不受领域影响；这覆盖此前“领域扩大震荡”的旧规则，震荡保持半径 55.2、击退 450/0.3 秒。
- 风刃路径的击退参数与首次命中统一按配置读取，修正旧路径仍使用 900/0.34 的差异。
