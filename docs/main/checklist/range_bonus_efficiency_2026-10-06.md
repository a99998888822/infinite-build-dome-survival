# 攻击距离与伤害范围：50%加成效率正式接入

用户确认四档实机动图后接入正式项目。实际倍率统一为 `1 + 属性 / 200`：例如属性+100实际增加50%。基础距离、基础伤害半径、装备/遗物属性值、单次伤害和施放节奏保持原样；正负属性均按50%效率换算。

## 实现

- `StatDefinitions` 提供统一的攻击距离与伤害范围倍率。原始属性、派生属性和施放快照不预先折半，避免重复换算。
- 武器射程、榴弹爆炸半径、适用的伤害宽度、投射物显示大小、瞄准指示器、附魔参数及元素反应快照共用对应倍率。
- 保留现有适用规则，包括短刀、炉灯、摆锤的双属性相加，以及纯控制震荡等既有例外。
- 面板显示原始属性点，领域仍提供30点伤害范围，武器升级的属性数值保持原样。后续按用户要求移除界面中的换算补充说明，包括领域附魔括号、武器详情中的“每点增加0.5%”和属性定义中的换算示例；实际倍率仍为 `1 + 属性 / 200`。
- 更新旧公式的范围断言和边界目标位置，新增四档生产快照、附魔倍率、反弹快照和装备变化隔离验证。

## 扩展回归中的已有失败

7套旧武器测试仍有77项既有失败，涉及旧基础伤害、升级、负载或旧接触节奏基准，例如榴弹旧测试期望基础伤害16，而当前正式配置为36。

为排除本次引入的问题，在独立控制项目中保留当前配置/运行时，恢复100%范围加成效率及这7套测试原先的范围断言；控制运行与最终50%效率运行的失败列表完全一致，没有新增失败。没有为通过这些旧断言而改回正式伤害、负载或攻击节奏。因此“1307项通过”是上述9套专项回归结果，不代表仓库所有历史测试全部通过。
