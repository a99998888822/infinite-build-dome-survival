# 本金经济修订：分段利息、战力消费与主动风险契约

日期：2026-10-11。状态：历史提案，尚未修改正式玩法。用户最新要求已明确取消分段计息，新增本金消费服务仅保留战斗专精；以 `principal_services_design_2026-10-11.md` 为当前方案。本文的定向升级、定向附魔和冒险存款均不纳入当前范围。

## 1. 普通存款规则

普通存款和钱包余额不改变怪物属性。怪物继续使用当前波数、难度、侵蚀与已有秒怪适应等规则，本提案不新增隐藏的财富难度修正。

分段只作用于银行本金，每次结息统一使用：

| 本金部分 | 按属性利率的比例计息 | 属性利率为 10% 时的实际分段利率 |
| --- | ---: | ---: |
| 前 3000 | 100% | 10% |
| 3000—6000 之间的部分 | 50% | 5% |
| 6000—10000 之间的部分 | 20% | 2% |
| 超过 10000 的部分 | 0% | 0% |

始终按各段分别求和，超过门槛不会降低之前那一段的收益。全局使用固定门槛，不随波数或玩家表现变化，便于玩家理解和计划。

```text
P = 当前银行本金，R = 属性利率（百分数）
有效计息本金 = min(P, 3000)
             + 0.5 × clamp(P - 3000, 0, 3000)
             + 0.2 × clamp(P - 6000, 0, 4000)
基础分段利息 = ceil(有效计息本金 × R / 100)
```

先合计再统一向上取整；之后沿用现有分红倍率、理智折损和小数余量流程。普通波末、额外结息和周期结息共用该计算入口，不各自另开全额计息的通道。直接赠送本金/金币的遗物不属于利息，本提案不调整它们。

| 本金 | 原利息，利率 10% | 新利息，利率 10% | 新利息，利率 13% |
| ---: | ---: | ---: | ---: |
| 1000 | 100 | 100 | 130 |
| 3000 | 300 | 300 | 390 |
| 5000 | 500 | 400 | 520 |
| 6000 | 600 | 450 | 585 |
| 10000 | 1000 | 530 | 689 |
| 20000 | 2000 | 530 | 689 |

表格假设理智 100，无分红翻倍等额外效果，仅展示一次基础结息。

本金遗物的主要属性收益在 2000—3000 已封顶，因此保留 3000 全额计息可以保住经济构筑的核心；继续存钱仍然增加利息，但边际收益快速减小，最终不再奖励额外囤积。

例：本金 20000、利率 10%，取出并花掉 10000 后，每次基础利息仍为 530。若进一步花到剩 6000，基础利息也只从 530 降至 450。玩家可以看见强化自己的实际机会成本。

钱包不计息，也不承担财富加怪惩罚。把钱取到钱包仍不消费不会受罚，但不会让多余资金继续复利。此设计鼓励消费，不强制玩家把钱清空。

## 2. 每波固定提供的本金消费服务

从完成第 3 波后的准备阶段开始提供独立入口。可选钱包或本金支付，同价；本金直付适用于资本家，不能要求其先手动取款。不要求先低血量，也不与普通哥布林随机建议竞争唯一名额。

| 服务 | 首轮建议价格 | 提供内容 | 数量限制 |
| --- | --- | --- | --- |
| 定向武器升级 | 同一升级当前普通商店最终报价的 2 倍 | 自选一把符合条件的已装备武器，升 1 级 | 每波最多 2 次，遵守现有等级及稀有度资格 |
| 定向基础附魔 | 蓝色基础价 120；紫色基础价 240 | 从当前适配武器的基础增益附魔列表中自选 1 个 | 每波最多 1 次，沿用现有装备和叠加限制 |
| 战斗专精 | 本局第 1/2/3 次基础价 300/600/1200 | 每次三选一：最大生命 +8、护甲 +5、通用伤害 +10 个百分点；本局永久 | 每波最多 1 次，三种选择共用每局 3 次上限 |

定向武器升级使用完整实际报价，再乘 2，不重复施加折扣；满级或不满足获取条件时不给出购买按钮，也不扣费。

其余服务按基础价依次应用当前商店折扣、理智价格倍率并统一向上取整；不额外叠加普通货架的波数、历史购买次数和收入附加。页面必须展示实际支付金额，而非只显示基础价。表中所有价格是历史建议。

“基础增益附魔”仅开放当前蓝色巨力、领域、精准、致命、迅捷和紫色多投等与武器匹配的条目；首版不提供任意法术附魔定向购买，避免一步买齐关键法术组合。没有符合条件的物品时隐藏该服务，不代换成不适配商品。

战斗专精的上限是全局共 3 次，不是每个属性各 3 次。全选同一项时，本局最多获得生命 +24、护甲 +15 或通用伤害 +30 个百分点；增加生命上限本身不回血。三次总基础成本 2100，提供明确的大额长期投资出口，同时阻止无限购买属性。

专精不可转售；定向升级和附魔沿用现有交易估值规则，报价应避免折扣与转售组合产生套利。

## 3. 自选“冒险存款”契约

另起名称，避免与已有遗物“高利契约”混淆。作为主动风险选项，可在完成第 3 波后的准备阶段选择，要求本金至少 1000。默认关闭，每波最多一次，不自动续约，不按连续接受次数暗中加码。

固定风险：下一波所有怪物生命 ×1.20，伤害 ×1.05，持续一波。

固定奖励规则：存活完成下一波后，额外获得该波基础分段利息的 50%，上限 200 金币；普通利息照常领取。

为避免临时存入后抽走本金仍锁定高奖励，计算采用波初和波末较低的中性基础分段利息，再应用两时点较低的理智利息倍率。奖励向下取整，额外分红翻倍和额外结息次数不放大这笔契约奖励；它不触发额外的“收到利息”遗物事件。波内本金或理智下降时奖励可能下降，接受前明确提示。

```text
契约奖励 = floor(min(200, 0.5 × min(波初基础分段利息, 波末基础分段利息))
               × min(波初理智利息倍率, 波末理智利息倍率))
```

“基础分段利息”包含当时的属性利率，但不包含理智折损、分红翻倍或本契约奖励。正常波初自动遗物事件执行后记录波初值，波末在波末金融结算与奖励发放前记录波末值。准备阶段必须预览这些可预测的波初变化；随机收益只显示有依据的保证值或区间。

| 本金/利率（理智 100，波内条件不变） | 普通基础利息 | 契约额外奖励 |
| --- | ---: | ---: |
| 1000 / 10% | 100 | 50 |
| 3000 / 10% | 300 | 150 |
| 6000 / 10% | 450 | 200 |
| 10000 / 10% | 530 | 200 |

不接受契约就没有本契约的怪物强化；失败或死亡不发契约奖励。该选项与“有偿加班”等主动战斗加压挑战共用当波风险名额，不能重复叠加；已有侵蚀和秒怪适应仍照常计算。

示例显示：

> 冒险存款：下波怪物生命 +20%、伤害 +5%。存活后预计额外获得 150 金币；波内本金或理智下降会减少奖励。仅持续一波，不自动续约。

## 4. 如何避免“后台改数值”的感受

- 银行固定展示各段金额、各段利率、理智影响以及本次预计利息。例如 5000 本金、10% 利率：前 3000 得 300，后 2000 得 100，合计 400。
- 消费确认展示实际扣款、消费后本金、预计利息和获得的具体效果。
- 怪物强化仅来自玩家主动选择的本契约，接受前展示固定数值，战斗中保留契约标记，波末明确结束。普通持有资金不会产生新增难度修正。
- 分段规则与专精次数在开局即可查看，固定阈值不会随玩家财富、输出或表现临时调整。

## 5. 与旧分析的差异及验证范围

撤回自动闲置财富加怪曲线。此前引用的 10—40 金币是普通货架的基础价，实际新武器/遗物还会增加每波 2、每次历史付费购买 1，以及有上限的收入附加，再施加折扣和理智因素。不能用基础价直接推导实际消费能力，本版定向升级明确复用完整报价。

本版限制的是本金数量带来的复利回报；复利宝典、额外结息、分红翻倍及直接本金赠送仍可能形成强经济组合。它不是总收入硬上限，也不保证消除所有极端经济构筑。应在基本方案验证后再评估这些组合，不在本次提案里一并修改其他遗物。

已核对分段利息的单调性、门槛连续性、10000 后固定有效计息本金 5300，以及文中计算例子。未验证新服务和契约的实战价值，价格与战斗收益均为首轮建议。

建议先实现分段利息及本金直付服务，再测试主动契约。正式落地需要覆盖多次结息、预览一致性、交易失败回滚、本金耗尽触发破产重组、价格折扣、保存恢复、次数上限和契约互斥。
