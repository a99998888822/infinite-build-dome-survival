# 武器属性附魔（2026-09-30）

七种附魔已加入正式配置、三类敌人的掉落池、物品栏、装填、转移、卸下、出售与武器详情。每件占一个现有附魔槽，只强化承载它的武器。角色全局属性和其他武器不变。

## 计算规则

- `weapon_bonuses` 随物品实例保存，在武器装卸时汇总；独立于角色属性及武器永久升级数据，避免卸下残留或升级重复累计。
- 巨力对本体、附魔、燃烧和该武器触发的元素反应生效；智慧仅对元素伤害生效。两者分别为1.3倍率，同时装填时元素伤害为1.69倍。零伤害控制效果（震荡）仍然没有伤害。
- 本体伤害在事件创建时应用对应倍率。`original_damage` 保留属性附魔增幅之前的基数，全部元素基数（含固定元素加值）的增幅记录在 `elemental_damage_scale`；后续附魔、反应、持续伤害与分裂沿用这份快照，避免本体放大后再二次放大。
- 同种属性按数值相加，例如两个巨力为+60%，而非1.3平方。不同伤害类型倍率分别结算。附魔槽规则继续沿用武器品质，最多两槽。
- 多投使用各武器已有规则：箭／榴弹／电浆／金币增加弹体；短刀、长枪、摆锤、触手增加攻击次数；炉灯增加火流；秘仪书增加本轮目标；战锤增加地裂节点，保留8节点上限。
- 领域沿用已有 `damage_area_size` 规则。震荡作用半径可增大，但推开速度和持续时间保持450／0.3秒；攻击距离也不受此属性改变。
- 迅捷通过武器局部 `attack_speed` 生效，无其他攻速时，1秒间隔变0.8秒。共鸣仍由领头武器提供冷却，跟随武器不会获得领头武器的属性。
- 已经发出的伤害事件保留发射时倍率；卸下、转移后创建的新攻击立即使用新的属性。弹跳复制当前武器的属性，副本独立。

## 图标与掉落

图标沿用现有32×32透明像素符号规格，位于 `assets/ui/icons/augmentations/scroll_<id>.png`，并保存可编辑 `.pxg`。由 `scripts/tools/build_attribute_enchantment_icons.py` 使用整数图形绘制，四种实色、二值透明度，无图片模型调用。

七种新附魔各以权重1加入三类掉落表。附魔总掉率继续为小怪1.5%、小Boss12%、Boss60%，品质权重继续为白2／绿70／蓝20／紫8；增加种类只改变各品质内部的种类分布。
