# 赤铜炉灯、异化触手、裂地战锤正式接入（2026-09-29）

三把武器使用用户确认的R02像素源及R03动作时序，已接入正式武器配置、装备、升级、商店候选、附魔、伤害归属与面板。实现沿用 `WeaponInstance` / `WeaponLoadout`，不依赖设计预览脚本。

2026-09-30更新：分裂后的附魔现在由子攻击命中点承接，含战锤短侧枝；炉灯每个命中的火流在300ms触发窗口内各处理一次对应顺序。以下为首次接入记录，最新规则见 `enchantment_order_performance_2026-09-30.md`。

| 武器 | 一级参数 | 正式行为 |
| --- | --- | --- |

三者均为5级，升级分别增加1元素／5近战／4近战基础伤害。炉灯和触手初始1槽、升至稀有后2槽；战锤初始2槽。射程受范围属性影响，接触宽度受伤害范围属性影响。地形遮挡有效。

## 附魔与节点

- 战锤每100ms推进一个主节点，基础5点，间距64，首点40、末点296。额外投射物增加主节点，最多8点（基础末距488）。裂缝细且低对比；原生地裂每轮每敌人只伤害一次。
- 主节点各分发一次附魔，原生敌人命中不再重复分发。水波、光剑、黑洞、火种、爆炸、落雷、冰域和风刃复用既有正式效果；落雷仍有500ms预警。基础64间距使基础黄色提示框互不重叠；提高附魔伤害范围后提示框也会相应变大。
- 电火花（`lightning`）从当前节点搜索有效范围内真实敌人，无目标不释放；落雷（`electric_spark`）可在空地触发。
- 战锤分裂为短侧枝，不递归生成主波、不复制附魔链；穿透不生效，并在安装前提示不兼容，避免浪费槽位。
- 炉灯附魔每300ms最多一次，采用30%元素基数；分裂为短侧火流。触手额外投射物变为一轮内连续拍击；分裂为一代弱化侧拍。两者元素附魔仍要求命中真实敌人，穿透同样不适用。

## 正式资源与维护

图标在 `assets/ui/icons/weapons/weapon_{copper_lamp,mutant_tentacle,earth_hammer}.*`。动画在 `assets/sprites/weapons/` 对应目录，全部保留可编辑PXG：火流128×128×6、触手128×128×19、战锤64×64×9、裂缝64×64×4。PNG是横向图集，源帧最多16色、二值透明、带透明边界；运行时最近邻采样，显隐使用调制透明度。

```powershell
python scripts/tools/build_weapon_trio_art.py
python scripts/tools/build_weapon_trio_art.py --write
```

默认只检查，`--write` 才重建正式PNG；不依赖artifacts。图标复用批准稿；触手／战锤命中音效使用现有流星锤音效，炉灯使用现有等离子命中音效。
