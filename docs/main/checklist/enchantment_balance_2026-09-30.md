## 掉落与收取

- [x] 普通怪基础 1.5%，精英 15%，预留 Boss 表 60%。Boss 表当前不参与常规波次。
- [x] 幸运数量倍率为 `1 + 0.6 × L/(L+200)`，幸运按非负数计算，倍率上界 1.6。
- [x] 正掉落加成倍率为 `1 + 0.4 × D/(D+100)`，上界 1.4；负加成保留惩罚，倍率最低 0.25。仅附魔使用此曲线。
- [x] 本波每成功生成一个附魔，普通怪后续概率乘 0.45。精英不受该指数递减，但共享总额度。
- [x] 第 1～5 波最多 3 个，第 6 波开始最多 4 个；直接多数量生成也受额度限制。
- [x] 同帧延迟奖励在实际生成时应用当前递减与上限。失败判定不可重放，旧波次事件不可在新波次兑现。

- [x] 少于 30 击杀的零掉落波次不推进、不清空保底；正常生成即清空空手计数；死亡不结算保底，新一局重置。
- [x] 已生成但未拾取的附魔同样占额度并重置空手计数；波末自动收取，避免靠不拾取重复领取保底。
- [x] 记录本波生成数、收取数、保底数、额度及空手波次，便于后续实测。

有效击杀由正式波次中的敌人死亡回调计数，沿用击杀去重。标记 `exclude_reward_progress` 的调试目标及 `summoned` 标签敌人不推进保底。
