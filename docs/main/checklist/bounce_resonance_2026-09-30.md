# 弹跳与共鸣正式接入（2026-09-30）

## 已确认行为

- 弹跳 `scroll_bounce` / `bounce`：每轮武器攻击首次命中时，当帧在该命中位置追加原武器攻击，不设置额外延迟。追加攻击跳过起手等待，复用原生判定、像素动画、伤害属性和来源统计；保留另一槽附魔，不再弹跳，也不加入共鸣调度。
- 同轮多投射物、贯穿、分裂子攻击、持续喷射的伤害跳数、战锤后续节点共享一次触发资格。旧弹体持有自己的攻击记录，不会因为下一轮发射而重新获得弹跳资格。
- 近战追加动作把有效打击部位放在捕获的命中点，原地展开；不移动玩家，也不随之后的玩家移动而漂移。榴弹追加原生爆炸，秘仪书追加原地点名，金币保持放射弹道，炉灯追加有限时长喷射，战锤从首个命中点立即展开另一条完整裂地波。
- 战锤空地节点属于有效命中点，第一节点可触发弹跳。其他武器仍需产生原本支持的接触事件。
- 共鸣 `scroll_resonance` / `resonance`：按装备栏从左到右取所有共鸣武器。第一把负责自动发动，后续只接受前一把结束后的唤醒，忽略自己的冷却；非共鸣武器继续独立攻击，只有一把共鸣武器时也正常独立攻击。
- 共鸣共享首把武器当前攻速修正后的冷却，从首把开始攻击时计时；必须同时满足冷却结束和整轮接力结束才发动下一轮，接力较长时不重叠开启下一轮。
- 炉灯作首把时保留完整喷射＋过热冷却周期；作后续时，自己的过热锁不会阻止下一次被唤醒。没有可达目标就停止喷射，并将接力交给下一把。

## 接力完成边界

| 武器类型 | 唤醒下一把的时点 |
| --- | --- |
| 弓箭、等离子球、金币、榴弹 | 本轮投射物发射完成；不等待弹体飞行和附魔消退 |
| 秘仪书 | 本轮点名完成 |
| 短刀、长枪、流星锤、触手 | 本轮原生动作结束；包括武器自身的连击 |
| 炉灯 | 本轮喷射过热或失去可达目标 |
| 战锤 | 动作结束且最后一个节点生成；被地形挡住时结束剩余节点 |

后续武器无合法目标时，本轮跳过；首把没有合法攻击时不启动整条链。暂停冻结冷却、动作和接力，恢复后继续。出售、拆卸或装备顺序变化时重新确定首把，清除旧链中的待唤醒引用。出售与战局清理同时取消原弹体和追加攻击。

## 配置与界面

- 两种卷轴均为史诗品质，占用一个现有附魔槽，不增加槽数。
- 小怪、小Boss、Boss三种掉落表均已加入；同品质内与分裂等权。附魔总掉率及绿70／蓝20／紫8／橙2的品质分布不变。
- 正式图标位于 `assets/ui/icons/augmentations/scroll_bounce.svg`、`scroll_resonance.svg`，采用整数像素网格图形，Godot生成对应导入文件。
- 背包、拾取、附魔槽、拆卸与出售沿用正式流程；附魔界面标出共鸣顺位与首把／后续身份。
- 额外修复粒子世界释放时遗漏的已脱离场景树的缓存发射器，防止重复追加攻击与退出场景遗留对象。
