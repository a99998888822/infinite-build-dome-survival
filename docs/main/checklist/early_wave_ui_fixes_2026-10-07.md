# 前两波武器保底与界面修正

## 正式修改

- 第1、2波分别记录一次新武器展示保底。该波首次升级奖励若能生成合法新武器，必定包含一把；没有升级奖励时由该波结束后的首次商店承担。出现即计入，无需购买；升级奖励、排队奖励和商店共用记录，刷新不额外发放保底。第3波起恢复普通概率，新一局清空记录。
- 保底仍遵守未持有、解锁、稀有度和负载限制，没有可装备候选时保留待展示状态；不生成无法装备的选项。保留商店价格、唯一商品编号，以及每屏最多一把新武器。小Boss的遗物专属奖励不占用保底。
- 血条更新先取消旧动画，再判断当前显示值是否相同；满血时立即填满。修复同一帧扣血后回血，旧扣血动画继续把红条拉低的问题。
- ESC遗物图标由32像素增至40像素，保持48像素格子，加入灰框、稀有度颜色的背景渐变与柔和边缘辉光。
- 小Boss身体碰撞半径从33.6减至22.4，角色图像尺寸不变。接触伤害使用该碰撞体；冲刺伤害与预警继续共用原有范围。
- 利息结算小弹窗中的遗物图标由64像素减至32像素。

## 验证

Godot无界面编辑器检查通过。新武器保底1674项检查通过，覆盖两种入口、两波独立记录、负载限制、专属遗物奖励、普通概率和付费商品身份。理财准备与利息结算回归通过，小Boss遗物奖励25项检查通过。

血条新增4项回归通过。HUD旧回归仍有2项性能信息栏间距断言失败；原版测试的失败列表相同，原因是既有布局间距为6像素，断言要求8像素，本次未修改该布局。小Boss遗物奖励旧测试退出时仍报告音频资源未释放。

实机验证使用正式游戏场景、临时进度和私有Windows桌面。验证了首次升级奖励可领取新武器、48/48红条填满、两种窗口尺寸下的遗物图标和辉光、利息遗物图标尺寸、身体接触与冲刺边界。`foreground_samples=0`，未抢占前台。

## 后续调整：胶囊碰撞体与结算行对齐

- 小Boss改为36×76的竖直胶囊，中心位于角色原点上方46像素。贴图尺寸不变，18帧动画的可见边界均能容纳胶囊并留出至少1像素余量。
- 使用实体碰撞的自动攻击及分裂投射物改为瞄准身体中心，短刀、长枪的正面判定同步使用身体位置。榴弹、法阵、火灯和流星锤仍使用原有地面位置。
- 利息图标从32像素进一步缩为20像素；没有图标的行也保留同宽图标列。描述首字左右对齐，每行上下各6像素留白，首行上留白从横线开始计算。
- 弹窗高度按完整行高计算；小窗口压缩标题和页脚区域，640×360下常见三行结算完整显示，较长明细仍按原逻辑滚动。
- 无界面编辑器检查通过；胶囊和自动瞄准40项、结算40项、战斗集成115项检查通过。正式场景GPU截图在私有桌面完成，退出码0，`foreground_samples=0`。
