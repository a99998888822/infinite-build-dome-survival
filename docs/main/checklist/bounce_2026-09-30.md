# 弹跳接入与验收

`scroll_bounce` / `bounce` 为史诗附魔，占用现有附魔槽。武器本轮首次命中时，在命中位置立即追加一次原武器攻击；复用原生动画、判定、伤害归属及另一槽附魔，不再次弹跳。

- 同轮多投射物、贯穿、分裂子攻击、持续伤害与战锤节点共享一次触发资格；旧弹体保留自己的攻击记录。
- 近战追加动作以捕获的命中点为基准，不移动玩家，也不随之后玩家移动漂移。
- 榴弹追加爆炸，秘仪书追加点名，钱袋按相邻 10° 追加定向扇状金币，炉灯追加有限时长喷射；战锤从命中点展开完整裂地波。
- 战锤空地节点属于有效触发点。出售、死亡与战局清理取消相应原攻击和追加攻击；暂停冻结运行。
- 图标使用 `assets/ui/icons/augmentations/scroll_bounce.png`。普通怪、精英和 Boss 掉落表均含此项，同品质候选按表内权重抽取。

逻辑回归入口：`scenes/tests/bounce_test.tscn`，覆盖全部 11 种武器的即时追加、固定落点、去重、分裂／水流组合、地面落雷、喷射、暂停和出售清理。

实机入口：`scenes/tests/bounce_live_capture.tscn`，参数 `--mode=bounce|shockwave --capture-dir=<目录>`。使用真实 GameRoot、装备、伤害与特效；固定敌人位置及生命便于审阅。通过 `run_godot_background.py` 在私有 Windows 桌面录制，检查实际桌面一致与 `foreground_samples=0`。

以上为功能验证；整局强度仍需结合主动施放、掉落及经济重新平衡。
