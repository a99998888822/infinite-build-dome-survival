# 流星摆锤实现与电浆炮刷新修复

## 实现清单

- [x] 复用已审阅图标、锤头、锁链、握柄透明素材，新增短促金属命中音效。
- [x] 正式武器配置：负载18、3个附魔槽、1.5秒间隔、近战伤害22＋角色近战伤害×1.2，最高5级，每级基础伤害＋5。
- [x] 最近敌人方向在蓄力时锁定；前方140°交替挥击；仅攻击期间出现武器。
- [x] 锤头伸展144、半径16；80%外圈命中提高至150%；实际敌人碰撞体接触判定，锁链无伤害。
- [x] 弧线分段检测，避免低帧率漏判；每次挥击对同一敌人命中一次，墙体阻挡命中。
- [x] 分裂首次主命中追加2次60%追击；只触发一代；追击可命中原目标。
- [x] 每个受击目标触发实际元素附魔；元素伤害基数完整缩放，避免重复加成／提前取整。
- [x] 攻速、近战加成、通用伤害、暴击、范围、额外投射物接入；投射物增加转为额外主挥击。
- [x] 商店与奖励池、装备、升级、出售、附魔槽和详细属性文本接入；穿透拒绝装填并提示。
- [x] 暂停、死亡、卸下、波末清理；装饰方粒不阻塞下一轮攻击。
- [x] 电浆炮初始品质由史诗改为稀有，修复低幸运时权重为零导致刷不出的情况；既有负载限制仍生效。
- [x] 测试启动参数 `--transient-session` 在自动加载阶段即隔离存档，防止验证进程在进入测试场景前读写玩家存档。
