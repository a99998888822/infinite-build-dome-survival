# 武器体积与命中判定

适用范围：当前主战斗的全部 14 把玩家武器。

伤害范围加成（`damage_area_size`）放大投射物实体外观时，对应伤害碰撞体按同一倍率放大。

## 当前规则

- 主动战斗中的投射物半径与外观使用相同的伤害范围倍率；电浆球直接读取已经缩放的物理半径，避免再次乘倍率。瞄准指示器的投射物宽度同步增长。
- 分裂金币与手炮弹丸分别按外观的 0.75、0.65 倍缩小碰撞半径。施放后继续使用该次施放的属性快照。
- 射程和飞行距离仍由射程属性决定。实体变大可以在路径边缘接触敌人；地裂节点间距与生成时刻不随体积加成改变，节点伤害段的尺寸随外观增长。
- 接触判断使用敌人的实际 `CollisionShape2D`，包含其偏移与缩放。敌人位置点在范围外、身体已经进入范围时也能命中。
- 伤害几何对应实体与有效作用区。拖尾、光晕和攻击结束后的残留特效继续作为装饰；触手回收阶段、秘典标记节奏等原有伤害时序保留。

## 各武器的行为

| 武器或流程 | 当前行为 |
| --- | --- |
| 裂地战锤 | 锤子落地接触姿态按实体轮廓检测；地裂在接触窗口内重复检查进入的敌人，同一射线的锤头与地裂共用命中记录，避免重复扣血。基础接触窗口为 40 毫秒，仍按原有攻速规则调整。 |
| 裂地战锤遇墙 | 裁切到第一堵墙，保留墙前有效伤害段；节点中心在墙后时不再丢弃整段墙前判定，分支同样处理。 |
| 流星摆锤 | 检查锤头和链条扫过的实体区域，包含采样间玩家移动；取消以敌人位置点必须位于名义扇面内为前提的过滤。 |
| 赤铜炉灯 | 按火焰的喷口、投影扇面与敌人碰撞体检测边缘接触，保留墙体遮挡与伤害节奏。 |
| 铸铁榴弹炮、坤舆秘仪书 | 爆炸与法阵范围改为椭圆和敌人碰撞体的重叠判定，保留原有爆炸与标记触发时序。 |
| 自动选敌 | 身体进入可攻击区域即可被选中，避免伤害能够触及但自动攻击不启动。 |
| 弓箭、电浆球 | 对每帧飞行路径进行扫掠检测；弓箭按接触先后处理穿透，电浆球在首次接触处进入原有连续伤害流程，避免大步长跨过敌人。 |
