# 幸运、高负载武器获取与小 Boss 生命调整（2026-10-09）

本轮修订将幸运遗物收益和高负载新武器类型权重限定为首次调整前的2倍，两种小 Boss 基础生命保留原来的3倍。以下规则取代先前过高的幸运与固定武器权重方案。

## 高负载新武器

当前负载达到50，且候选池存在未持有、已解锁并能装入剩余负载的新武器时，先按首次调整前的规则计算已持有数量折减、剩余负载折减并向上取整，随后将新武器类型权重乘2。付费商店和免费升级奖励均使用该规则；此前的固定最低权重30／12已移除。

例如70/100负载、持有3把武器时，付费权重3→6、免费权重1→2。因为其他候选也参与归一化，权重翻倍不等于整页出现概率严格翻倍。每批仍最多一件新武器，负载装不下的武器不进入候选池；强力刷新与前两波武器保底继续沿用现有规则。

## 小 Boss

钢甲骑士基础生命200→600；幽焰冥狼240→720。正常刷怪、挑战追加精英、讨债目标均读取正式模板，继承新的基础生命，之后照常应用波次、难度、侵蚀和挑战倍率。整数生命的最终取整可能产生1点差异。

第2波起的每波出现保底、常规配额最多3只及前半波生成规则继续生效。

## 验证

`reward_access_balance_test.tscn` 覆盖七件遗物真实获取、跨品质幸运组合、50负载边界、满载候选过滤、两种奖励模式的每批武器限制，以及三档难度／第2、5、20波／0和100侵蚀下的Boss生命。

概率测量使用真实抽取器：70/100负载、已持有3把武器、3栏、0幸运；付费与免费模式各对原始权重和当前2倍权重抽取2500批。本次结果与回归摘要保存在 `artifacts/reviews/reward_access_double_20261009/`；`reward_access_20261009/` 是修订前的历史记录，不代表当前概率。测量使用有充足候选的初始货架，不是所有负载、栏位数和候选池下的统一概率。

本次每批至少出现一把新武器的实测概率：付费商店12.80%→23.08%，免费奖励4.52%→8.80%。

标准难度、零侵蚀的实际生命：第2波钢甲骑士198→595、幽焰冥狼238→714；第5波378→1135、454→1362；第20波9531→28593、11437→34311。
