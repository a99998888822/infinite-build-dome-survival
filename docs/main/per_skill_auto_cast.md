# 逐技能自动释放与位移辅助

每把武器独立选择自动或手动。攻击默认自动，三种位移默认手动。Esc 武器栏和奖励页可切换模式，战斗栏同步显示；循环箭头表示自动，手形表示手动。

选择按稳定武器类型 ID 保存在 `user://combat_settings.cfg` 的 `weapon_auto_cast` 节。升级、换位、重新装备和重启保留选择。旧版总开关仅用于配置迁移，当前界面没有总开关。

## 手动与自动的配合

数字键、武器方框和快捷施法遵守当前输入模式；WASD 模式的滚轮跳过自动攻击。自动位移仍允许手动施放，手动瞄准和近期手动操作会让自动决策退让。炉灯、秘仪书也服从逐技能设置。

自动位移读取实际按键组合或有效右键目的地。角色惯性、击退、最后朝向及鼠标悬停不作为移动意图。

| 场景 | 行为 |
| --- | --- |
| 持续朝敌群追击 | 短刃／秘典选择近侧、能命中且安全的落点；火炮不用于朝前追击。 |
| 有明显压力并远离敌群 | 短刃／秘典顺移动意图脱离；火炮朝追兵开火并向目标方向后退。 |

停步、频繁改向、横向绕行、低压力撤退、暂停、死亡和非战斗阶段不触发。没有合格落点则保留技能。安全检查使用玩家实际碰撞体、敌人身体、地形及已出现的危险区域；它不保证无伤，也不预测未出现的攻击。

## 返回与输入连续性

自动移星秘典不创建返回印记；手动施放保留返回。规则按该次施放来源决定，切换设置不补发返回入口。位移和返回保留当前移动指令，期间可以松键、改向或修改目的地，结束后不恢复过时的输入快照。

## 调度与维护

决策最多每 0.25 秒一次，方向稳定至少 0.35 秒才参与；成功施放后自动位移共用 2 秒间隔，手动操作至少让其退让 0.8 秒。一次只启动一把位移武器；没有可用技能时不查敌群。近处敌人超过 128 个时放弃判断，每次最多检查 6 个目标或候选。

设置维护于 [combat_settings.gd](../../autoloads/combat_settings.gd)，决策维护于 [auto_mobility_planner.gd](../../scripts/weapons/auto_mobility_planner.gd)。回归入口为 [auto_mobility_test.tscn](../../scenes/tests/auto_mobility_test.tscn)，具体阈值和空间尺寸以代码为准。
