# HUD 设计坐标约定

所有 HUD 统一在 1920×1080 逻辑画布上布局。控件坐标、尺寸、间距、字号直接使用该画布的单位；窗口分辨率由 Godot 的画布拉伸统一适配。不要再增加 1152 基准的父控件缩放或在公共字体样式函数里乘以 5/3。

战斗 HUD、设置、天赋面板、角色选择均使用原生坐标。角色背景保留原图比例；天赋树缩放、按钮反馈和弹窗过渡仍属于交互动画。

奖励使用四列、两行可见区域。1920×1080 下，面板为 `(64, 144, 1312, 896)`，每格 `298×343`，横纵间距为 `24×20`。不足四张时保留固定格宽，不按奖励数量拉伸；超过八张时使用滚动区域。

原素材、图标和像素字体不必与逻辑坐标使用同一源像素尺寸。`assets/font/native_hud/` 保存原生字形度量；新增文本时按该目录 README 重新生成字库。运行时直接请求原生字号。`NativeHudBox` 和原生 StyleBox 用于保留分数坐标，避免嵌套容器重复取整改变已确认的外观。

回归入口：

- `scenes/tests/hud_native_layout_test.tscn`：不同实际窗口尺寸下的原生布局和坐标点击。
- `scenes/tests/reward_popup_layout_test.tscn`：奖励 4×2、滚动范围、刷新和选择。
- `scenes/tests/hud_native_visual_review.tscn`：固定状态的修改前后截图；GPU 验证使用 `scripts/tools/run_godot_background.py`。

本次截图和差异数据位于 `artifacts/reviews/hud_native_1920/`。奖励面板区域逐像素一致；其他 HUD 尚有字体栅格化和分数坐标取整差异，不能将当前静态对照视为全界面、全动画的零差异证明。
