# 首次战斗操作指引

首次进入桌面端战斗时，先处理营地提供的开局升级奖励，再显示三步静态指引。首波在玩家完成或跳过指引后才开始；引导期间不刷怪、不推进波次计时。

1. 灰色遮罩突出角色附近的地面，固定的鼠标右键、路径和落点图示说明右键移动与 S 停止。
2. 展示正式 Esc 武器栏与当前装备，说明框体下沿的循环箭头和手指图标。无论当前装备类型如何，说明区都显示自动与手动两种图例。
3. 展示正式设置界面的战斗设置页，突出鼠标右键与方向键 / WASD 两个移动选项。

只接受指引的上一步、下一步、跳过和完成按钮。高亮区域仍拦截鼠标事件，键盘快捷键不穿透，不要求玩家实际移动、施法或修改设置。右键移动始终作为静态示例；如果玩家已选择 WASD，会说明保留当前配置。

攻击技能默认自动、位移技能默认手动；每个技能的设置独立生效，轮椅模式总开关已移除。指引只解释逐技能规则，不覆盖已有偏好。

## 生命周期与持久化

- `MainFlowCoordinator.STATE_COMBAT_GUIDE` 负责暂停、首波启动以及重看后的返回状态。
- `CombatGuideOverlay` 使用正式 Esc 场景和 `GameSettingsPanel` 的独立展示实例，上层遮罩负责拦截交互。实例按需创建，退出后释放。
- 完成与跳过均记录到 `user://combat_settings.cfg` 的 `[onboarding] combat_guide_seen`，与“显示操作提示”开关独立。
- 战斗设置底部提供“重看操作指引”按钮。重看结束返回战斗设置，再退出设置时回到原先的战斗、Esc 或奖励页面；已有奖励选项和波次计时保持不变。
- 移动端不展示这套鼠标键盘指引。无界面验证和 `--transient-session` 不自动触发；测试可用 `--show-combat-guide` 显式启用，仍不写入用户配置。
- 960×540 下，第一步将说明框放在地面示意左侧，避免覆盖角色；其余页面使用底部说明框。

## 验证入口

`scenes/tests/combat_guide_test.tscn` 覆盖首次触发、首波拦截、实际输入穿透、前进后退、完成与跳过、配置往返、三种嵌套重看来源、开局两次奖励的先后顺序，以及紧凑窗口布局。

实机截图通过 `scripts/tools/run_godot_background.py` 在私有 Windows 桌面运行同一测试场景，附加 `--transient-session --show-combat-guide --locale=zh_CN --capture-dir=<输出目录>`。审核运行不切换输入桌面，不抢占当前窗口焦点。
