## 后台规则

- **扩大生意**：上一波从容，至少还剩两波，可在后续理财重复接受。2026-10-10起，每次给玩家的`enemy_spawn_rate_percent`（怪物数量增幅）增加20，和营地等来源相加，沿用属性0～300范围；该加成持续本局。文案按用户指定保留“怪物频率 +20%”，实际增加普通刷怪批次的数量，不缩短间隔。难度和波次决定基础批次数量，再乘属性倍率和波初侵蚀倍率`(1 + 非负侵蚀度 / 100)`；两项百分比相乘后，小数以整数万分之一为单位在本波各批次间累计，满1只生成1只，新波及新局清零。例如基础每批1只、属性20、侵蚀0，五批合计6只；侵蚀100则五批合计12只。沿用场上人数上限，超额整只不积欠；数量增幅不改变独立精英和Boss配额，侵蚀的精英加成仍单独计算。每笔成功完成对应下一波后奖励一次150本金，结息后发放。
- **限时金币**：上一波压力大、清剿倒计时结束仍有怪物未消灭，且本波全部生成怪物平均存活时间≥10秒。已击杀怪物从生成计到死亡，幸存怪物计到清剿结束，普通与精英均统计；暂停、升级弹窗不计时，提前清空怪物或手动结束波次不算清剿超时。仅下一波新生成的金币价值乘1.5，生成后2秒失效；升级选择、暂停等不计时。期限内开始吸附的金币锁定价值。金币过期后保留经验，视觉变暗且倒计时环消失。波末自动回收仅兑现尚未过期金币，已过期金币不会复活。
- **本金托管**：上一波压力大、本金至少2000。扣除10%本金，上限1000；额外奖励为扣除额的30%，限制在100～300。报价展示即锁定，接受时检查余额，不占用手动存取次数。下一波开始，在玩家附近可达位置放置保险箱，快照扣款及开波效果后的玩家最大生命×3、同等护甲。箱子不可移动、不可攻击，使用独立血条；每三只可近战的普通怪物中一只主动攻击箱子，其他仍追击玩家。存活完成该波且箱子未毁，结息后返还扣款与奖励；箱毁后不返还。中途复活后存活通关仍符合存活条件。销毁场景时不算保险箱被击毁。

高压力沿用原有挑战指标：末段拥挤、反复跌破半血或累计半血以下至少5秒。从容沿用观测至少5秒、最低生命比例65%、没有跌破半血、末段敌人积压低的条件。新挑战不把“本轮购买提升不大”当成高压力。

2026-10-09规则调整：额外精英与风浪越大也只看高压力，不再因本轮战力提升不大而触发。全额存入的哥布林台词改为「请放心交给我理财吧」，描述与结算不变。此次回归记录位于`artifacts/previews/goblin_rules_revision_20261009/`，下文较早的检查数量属于初次接入记录。

## 金币精度

所有通过金币获取加成计算的战斗掉落统一按两位小数计算，以整数分累计。限时金币倍率与获取加成相乘后一次保留两位小数。

钱包的整数部分随拾取立即到账，小数部分在HUD中显示并累计，成功波末统一向上补整最多1金币；重复结算无效，失败退出不领取向上补整。银行、商店、贷款仍使用整数交易；利息继续使用原有独立的小数结转规则。经验的累计规则保持原样。

例如1金币×1.5×1.2345=1.85175，计为1.85金币；两枚合计3.70，成功波末结算为4金币。普通1金币×1.2345同样计为1.23。
