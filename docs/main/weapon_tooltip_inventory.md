# 武器提示文本清单

核对日期：2026-10-06。以下记录当前实现的实际文本，不是拟修改文案。完整属性文本由 Godot 无界面运行直接调用 `WeaponInstance.build_full_stats_text()` 导出，共 11 把武器。

## 三个页面目前是否一致

| 入口 | 当前文本来源 | 是否共用完整武器详情 |
|---|---|---|
| Esc 武器栏悬停 | `WeaponInstance.build_full_stats_text()` | 是 |
| 理财页面已装备武器栏悬停 | `WeaponInstance.build_full_stats_text()` | 是，同一实例、同一属性状态时与 Esc 一致 |
| 选人页面初始武器悬停 | `weapons.json` 的 `description` | 否，仅显示静态介绍 |
| 理财商店的新武器卡片正文 | `weapons.json` 的 `shop_description` | 否，是卡片内的短介绍；当前没有完整武器悬浮详情 |

当前选人页面只有初心者的木质弓箭与资本家的食利者钱袋。下面仍列出全部武器的 `description`，其中其余 9 把是该入口会读取的配置原文，并不表示当前选人页面可以查看全部 11 把。

## 导出口径与动态内容

- 全部使用一级、正式主动战斗范围规则、无额外角色／遗物／附魔加成、本金为 0 的状态；保留武器自带的暴击率和其他基础属性。实战提示会随升级、角色属性、附魔与本金变化。
- 仅去除富文本颜色标记；附魔栏的空槽图标以 `【空槽】` 代替。游戏中显示图标，不显示这四个字。
- `伤害：（12+0）` 是武器基础伤害与角色对应伤害贡献的分解，钱袋再加本金贡献；这一行不是包含巨力、通用增伤和暴击等乘区的最终命中伤害。
- 伤害范围加成不为 0 时，会额外显示 `伤害范围 +X%`；装填分裂时会追加 `分裂 N个 · 伤害Y%`，装填弹跳时追加 `弹跳 首次命中立即追加N次攻击`。附魔图标行随槽位和装填内容变化。
- 当前完整详情没有统一显示“类型／稀有度／战斗标签”行。

## 当前不一致或未充分展示的内容

1. Esc 与理财已装备武器详情共用同一函数，选人介绍与商店短介绍各自独立维护；因此三页尚未形成一套共用文案。
2. 电浆炮的静态介绍写出“每次灼击以 20% 元素伤害基数触发附魔”，完整详情只写灼击间隔和次数，缺少这一条。
3. 短刀、触手的完整详情没有攻击距离、攻击次数等行；摆锤显示锤头伤害半径，但没有显示扇面最远距离。相应规则在静态介绍中更完整。
4. 炉灯和秘仪书的完整详情及静态介绍仍固定写“按数字键”，未涵盖 WASD 模式下鼠标施放、快捷施法与轮椅模式。
5. 秘仪书完整详情的“每次点名 3”实际用于展示一次法阵的点名总次数，标签容易被理解为每次同时点名 3 个目标。
6. 裂地战锤的静态介绍还包含“保留原色、加粗主线并增加细小分叉”等美术修改记录，属于开发说明。

建议后续统一武器详情的基本结构与机制介绍；选人页展示基础状态，Esc 与理财展示当前状态。上面的清单保留当前原文，本次整理未修改正式界面或战斗数值。
