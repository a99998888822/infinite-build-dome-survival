# 武器提示文本清单

核对日期：2026-10-07。以下原清单记录 11 把武器的实际文本。当前新增 3 把位移武器，总数为 14；新增武器的完整详情与理财短文案由实际运行导出，见 [位移武器文案审阅](mobility_weapon_copy_review.md)。原有 11 把武器的记录保留在下方。

## 三个页面目前是否一致

| 入口 | 当前文本来源 | 是否共用完整武器详情 |
|---|---|---|
| Esc 武器栏悬停 | `WeaponInstance.build_full_stats_text()` | 是 |
| 理财「附魔」页已装备武器栏悬停 | `WeaponInstance.build_full_stats_text()` | 是，同一实例、同一属性状态时与 Esc 一致 |
| 选人页面初始武器悬停 | `weapons.json` 的 `description` | 否，仅显示静态介绍 |
| 理财商店的新武器卡片正文 | `weapons.json` 的 `shop_description`，缺省回退 `description` | 简短介绍；当前没有完整武器悬浮详情 |
| 理财商店的武器升级卡片标题悬停 | 武器名＋目标等级＋`level_upgrades[目标等级].description` | 否，仅显示本次升级内容，见文末升级清单 |

因此，按页面可分为选人、Esc、理财三组；文案来源为完整详情函数、选人静态 `description`、理财 `shop_description`、升级 `description`。原有 11 把武器的两种静态介绍保持原文；新增位移武器将理财短文案与详细介绍分别维护。理财的「购买」与「附魔」是切换显示的两个页签，已装备武器栏属于「附魔」页。新武器卡片的标题悬停文本被明确清空，卡片悬停触发的属性预览也不是武器详情弹窗。

武器详情里的附魔图标、选人初始附魔图标以及附魔槽另有附魔说明；价格、出售按钮另有操作提示。这些不属于武器本体文案，附魔原文见 `enchantment_tooltip_inventory.md`。战斗底部快捷武器栏目前也没有独立的武器悬停详情。

当前选人页面只有初心者的木质弓箭与资本家的食利者钱袋。下面仍列出全部武器的 `description`，其中其余 9 把是该入口会读取的配置原文，并不表示当前选人页面可以查看全部 11 把。

## 导出口径与动态内容

- 全部使用一级、正式主动战斗范围规则、无额外角色／遗物／附魔加成、本金为 0 的状态；保留武器自带的暴击率和其他基础属性。实战提示会随升级、角色属性、附魔与本金变化。
- 仅去除富文本颜色标记；附魔栏的空槽图标以 `【空槽】` 代替。游戏中显示图标，不显示这四个字。
- `伤害：（12+0）` 是武器基础伤害与角色对应伤害贡献的分解，钱袋再加本金贡献；这一行不是包含巨力、通用增伤和暴击等乘区的最终命中伤害。
- 伤害范围加成不为 0 时，会额外显示 `伤害范围 +X`（当前原文不带百分号）；装填分裂时会追加 `分裂 N个 · 伤害Y%`，装填弹跳时追加 `弹跳 首次命中立即追加N次攻击`。附魔图标行随槽位和装填内容变化。
- 当前完整详情没有统一显示“类型／稀有度／战斗标签”行。

## 本轮文案调整口径

1. 全部完整详情移除相邻夹角行，冷却标签统一为“冷却”；武器实际夹角和冷却数值保留。
2. 11 把武器的静态介绍与新武器卡片正文采用本轮指定的同一文案。
3. 炉灯去掉喷射时长倍率和指定的三行补充说明，保留喷射距离及“按数字键喷射…，每…灼烧。”这一行。
4. 战锤去掉地裂方向、每路节点、末节点距离、节点伤害半径与旧机制说明；长枪和摆锤去掉指定的次数、距离、宽度及半径行。
5. 秘仪书、钱袋、短刀、长枪、摆锤的完整详情描述替换为本轮指定文案；秘仪书保留“每次点名”和“领域半径”参数。

以上仅调整界面显示文本；攻击、伤害、冷却、投射物与附魔行为，以及商店升级效果均不变。

## 实现位置

- 完整属性与机制详情：`scripts/weapons/weapon_instance.gd` → `build_full_stats_text()`。
- Esc 入口：`scripts/ui/weapon_strip.gd` → `_show_weapon_tooltip()`。
- 理财已装备入口：`scripts/ui/enchantment_workbench.gd` → `refresh()`。
- 选人入口：`scripts/ui/character_select_view.gd` → `_build_starting_weapon()`。
- 理财商店卡片：`scripts/ui/preparation_offer_card.gd` → `configure()`。
- 共用静态介绍：`data_config/weapons.json` → `description`；`shop_description` 同步保存相同文本。
- 商店升级内容：`scripts/ui/shop_offer_generator.gd` → 升级候选构建；`scripts/ui/preparation_offer_card.gd` → `configure()` 的标题提示。
- 理财页签与详情弹窗：`scripts/ui/finance_popup.gd` → `_select_tab()`、`_show_tooltip()`。
