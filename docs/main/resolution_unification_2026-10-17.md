# 1920×1080 分辨率统一修复

确认存在问题。世界视口已固定为 1920×1080，但 `project.godot` 根画布仍为 1152×648，世界容器因此在 UI 画布内缩至 0.6 倍。怪物场景同时撤掉了原有缩放，而初心者后来从 128 像素改成 96 像素素材；武器范围数值没有随视野迁移。这是画布、实体体型和游戏距离三处不一致叠加的结果。

## 修复

- 项目逻辑画布、世界视口和 UI 统一为 1920×1080。保持根视口 `canvas_items / keep`，窗口尺寸只改变最终输出比例，不再改变视野或瞄准坐标。
- 新窗口偏好默认 1920×1080；桌面容不下时选择可用的小窗口。已有用户保存的尺寸和全屏选择继续有效。
- 小怪与蝙蝠调整到原图 0.6 倍，骑士到 0.75 倍；冥狼逐帧注册的基础倍率从 2 改为 1.5。碰撞体、偏移与对应绘制尺寸同步，挑战倍率仍独立且重复应用不会累乘。
- 14 把武器的射程、近战宽度、领域短轴、爆炸半径、位移距离及相关弹速按 5/3 迁移。配置遵守整数要求，范围指示与实际命中继续通过同一组武器数据计算。地锤射程采用取整后的节点终点 67 + 4×107 = 495，避免配置和实际终点相差 2 像素。
- 主菜单按钮、设置面板、天赋内容、战斗 HUD、武器栏、属性抽屉、背包面板及理财页面适配原生画布。复用组件可保留局部布局单位，通过控件变换呈现；不再使用不同分辨率的 UI 视口。理财背景定位改用 1920×1080 坐标，文字增大后对话气泡按实际文本高度布局。
- 天赋页延迟绑定主流程，修复父场景尚未准备好时绑定失败，导致退出后仍遮挡战斗的问题。

伤害、冷却、攻速、伤害面积百分比公式、玩家素材与基础移速未随分辨率改动。

## 验证

- `resolution_unification_test`：私有桌面 GPU 58 项检查通过，包含 8 张实际页面截图、14 把武器的范围、设置按钮真实鼠标交互、1280×720／1920×1080／2560×1440 输出下的坐标一致性，以及新长枪在 330 像素处命中、450 像素处不命中。
- `native_resolution_review`：27 项通过，覆盖玩家下半身碰撞、怪物接触、地形阻挡与体型倍率。
- `active_combat_integration_test`：146 项通过；领域移动测试使用当前射程外的目标位置，保留原有判定意图。
- `weapon_balance_test`：88 项通过；电浆半径断言更新为新基准 20。
- `finance_scene_regression_test`：58 项通过，在不同输出窗口中维持原生逻辑画布，验证交易、抽屉安全区、放大镜与提示框交互。
- `window_settings_test`：23 项通过，包括默认尺寸、保存的高分辨率、全屏往返与连续调整。
- 编辑器 headless 检查通过；Android build-tools 未配置的环境提示仍存在。
- GPU 验证确认实际引擎运行于工具创建的私有桌面，`foreground_samples=0`。截图及日志位于系统临时目录 `resolution-ui-review-final` 与 `resolution-gpu-final.*`。

正式主入口 `game_root.tscn` 已通过 headless 120 帧运行，配置无错误。分辨率修复时发现的 6 项旧 Bootstrap 断言已在后续更新中修正：初始武器和主流程同步检查改为木质弓箭、突进短刃共 2 把，总负载 42；负载限制使用尚未拥有的营地短刀，验证容量差 1 点时拒绝购买、原装备不变，以及恢复容量后允许添加；神性融合检查固定加成 2 个百分点、12 侵蚀度时总加成 2.4 个百分点，以及波次开始增加 3 侵蚀度后总加成 2.6 个百分点。

更新后的 Bootstrap 已通过 headless 120 帧验证，164 项行为断言全部通过，配置校验警告和错误均为 0，退出码为 0；编辑器 headless 检查也通过。该结果独立于上述 400 项专项检查。拒绝重复购买和超负载购买会产生预期的 `WeaponLoadout` 警告。首次退出另出现 4 个对象、2 个资源未释放的提示，开启 `--verbose` 复跑时未复现，尚未确定其原因；日志保留在系统临时目录 `bootstrap-refresh-runtime.log` 和 `bootstrap-refresh-verbose.log`。
