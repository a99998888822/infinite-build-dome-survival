# 本金依赖遗物、理智反馈与图标审阅

日期：2026-09-24。用户已确认数值审阅的五项要点：无眠账簿、狂热分红、镀金扳机、失控增幅器、清醒誓言已接入正式遗物池，永续年金卷轴、守心铜鉴、梦魇治愈圣壶已调整。第2节的八件本金依赖遗物仍为候选建议。经济提示与结算改动另见本文件末尾。

## 1. 设计原则

保留本金提供护甲、攻速、伤害和负载的既有设计。增加的决策是“这笔钱取出来，哪些保护会消失”，不增加锁定期限、心债条、额外付款页面或区域流程。每件遗物优先只描述一个本金换算关系；属性随当前本金实时变化。

## 2. 本金依赖的新遗物候选

表中的“每100 / 250 / 500本金”均指每满一档生效，沿用现有本金换算的向下取整规则。取款跨过档位时撤销对应属性，存款达到档位时重新获得。

以下值为首轮试调起点，不代表已证明战斗平衡。新增遗物建议单件上限1，以先分辨每种换算的价值；本金成长本身没有额外封顶。

| 候选 | 建议稀有度 | 一句话规则 | 本金500 / 1000时 | 取款时的取舍 |
|---|---|---|---|---|
| 金币心脏 | 稀有 | 每100本金增加1最大生命 | +5 / +10生命 | 降低生命容错；取出再存回不得无成本恢复当前生命 |
| 分红药瓶 | 稀有 | 每100本金增加0.1每秒回血 | +0.5 / +1回血 | 留钱维持持续恢复，或买下一件关键装备 |
| 金线弹簧 | 稀有 | 每100本金增加1暴击率 | +5 / +10暴击率 | 取款降低暴击构筑稳定性，沿用暴击属性自身规则 |
| 镀金屏障 | 史诗 | 每250本金增加0.2每秒护盾 | +0.4 / +0.8每秒护盾 | 取钱后护盾补充变慢，不能用存取刷新开局护盾 |
| 铸金瞄准镜 | 稀有 | 每250本金增加1远程伤害 | +2 / +4远程伤害 | 与恶意收购的百分比伤害区分，适合基础伤害流派 |
| 黄金分岔器 | 史诗 | 本金至少500时，投射物+1且通用伤害−30% | 条件满足 | 取款跨过门槛会失去整组效果；对投射物不适用的武器明确提示 |
| 囤积者戒指 | 史诗 | 每500本金：金币获取+5%，理智−2 | +5%/−2；+10%/−4 | 本金越大，收入越高，管理财富的效率越低；取款会撤销对应动态理智扣减 |
| 黄金棺椁 | 神话 | 本金至少1000时，致死伤害消耗500本金并恢复50%生命，每局一次 | 未满足 / 可触发 | 死亡保护真实消耗本金，可能同时削弱其余本金遗物 |

第一轮最推荐金币心脏、分红药瓶、囤积者戒指。前两件补充生命与恢复方向，戒指让资本增长和理智下降直接关联。黄金棺椁需要明确与既有复活的优先级、防止同次死亡重复触发，适合后续实现。

本金阈值只在卡片上说明，不另开操作。银行金额输入旁直接预览办理后本金、护甲、攻速、通用伤害、负载变化。后续加入新遗物时扩展预览属性列表。

## 3. 五件图标草案的数值审阅

| 遗物 | 上一版 | 建议审阅值 | 稀有度 / 上限 | 判断 |
|---|---|---|---|---|
| 镀金扳机 | 通用伤害+25%，理智−20 | 保留 | 稀有 / 1 | 理智100→80，利息保留83.3%；与疾风轮盘、蚀腐吹管比较，不是同一伤害乘区，需实战对照 |
| 无眠账簿 | 利率+2个百分点，每波理智−3 | 利率+4个百分点，每波理智−3 | 稀有 / 1 | 原值长期收益逊于普通理财经理，诱惑不足；提高即刻收益后仍有持续代价 |
| 失控增幅器 | 通用伤害+35%，每波理智−2，负理智时−5 | 保留 | 史诗 / 1 | 比扳机更强但代价随持有时长增长；晚期获得更划算是该类遗物的时机价值 |
| 狂热分红 | 每次成功结息：伤害+2%，理智−1 | 伤害+1%，理智−2 | 史诗 / 1 | 额外结息会同时放大成长和代价；降低与永续年金叠加时的收益速度 |
| 清醒誓言 | 每波理智+2，通用伤害−8% | 保留 | 稀有 / 1 | 与守心铜鉴区分为更快恢复、牺牲战力；理智100以上主要提供损失缓冲 |

百分比通用伤害按现有 `damage_percent` 加算，不直接解释为最终DPS同倍率提升。五件遗物均按表中建议值接入候选池，均限持1件。狂热分红在利息实际入账大于0时触发，普通、额外、周期和手动结息遵循同一规则；本次扣减的理智从下一次结息开始影响收益。

失控增幅器按波末属性效果触发前的理智决定本次扣减：理智≥0扣2，理智<0扣5。同次触发中的清醒誓言、无眠账簿等不会改变这次分支选择，因此结果不受获得顺序影响；例如理智0先扣2，到下一波末才按负理智扣5。清醒誓言可将理智恢复至100以上作为缓冲，但不会获得额外经济倍率；轮回业火之烛仍会阻止它的理智恢复。

## 4. 可复算的经济对照

计算脚本：`artifacts/capital_dependency_20260924/analyze_balance.py`。完整结果：同目录 `balance_metrics.json`。

统一从500本金、理智100、基础利率5%开始，不追加存款、不计算购买成本、战斗收益或死亡。每次先结息，再应用结息触发效果；波末应用固定理智损失。沿用现有正常利息向上取整，理智削减的小数累积。这里只隔离经济差异，不能当作完整通关模拟。

|---|---:|---:|---:|
| 基础状态 | 819 | 1274 | 100 |
| 一件理财经理 | 944 | 1670 | 100 |
| 两件理财经理 | 1085 | 2175 | 100 |

建议版无眠账簿在10波附近提供接近两件理财经理的经济效果，但长期被两件经理反超，并承担交易损失。实际商店价格与出现时间仍会影响价值。

原狂热分红配合一件永续年金，19波可累计伤害+76%、理智−38；建议版为伤害+38%、理智−76。同一简化模型中对应最终本金2464与2048。这里的伤害是属性增量，不是实际击杀效率。

## 5. 现有遗物是否需要调整

### 已执行调整与继续观察

- **永续年金卷轴**：已将单局持有上限从无限改为1，保留神话稀有度和每波额外结息一次。复利宝典单件19波后本金1760，配一件年金后11956；该差异显示结息次数与利率成长的强耦合，但未模拟获得成本、时间与生存压力。先处理额外结息叠加，不削本金转属性的规则。
- **守心铜鉴**：已将金币获取35%→20%，保留史诗稀有度、幸运+18、每波理智+1和原有叠加规则。理智有实际经济价值后，用这项调整控制综合经济收益。
- **梦魇治愈圣壶**：已将每秒回血0.5→0.8，保留稀有品质、每波理智−1和原有叠加规则；本轮选择增强回血，不同时降低稀有度。
- **定期存单**：优秀、每波数给予50本金，可叠加。第10波直接增加500本金，会同步启动大量本金遗物。建议追加购买时机对照，再决定升为稀有或把系数50降到30；目前证据不足以直接改值。

### 建议先保留

钢铁保险柜、量化操盘、恶意收购、并购重组保留；它们是本轮主题核心。人性护符、守魂人面石雕、神性融合、轮回业火之烛、圣质银杯先保留，观察新经济规则下的组合。

石雕将侵蚀转成理智，可以抵消经济压力，但侵蚀的战斗代价仍存在。是否过强需要实战验证，不能仅凭组合能抵消一项负面就判定为漏洞。怪物侵蚀属性已取消100封顶：每100侵蚀增加生命180%、攻击90%、护甲135%，超过100继续线性增长。侵蚀200时倍率为4.6、2.8、3.7；波初快照规则保留，小 Boss 数量仍沿用原有上限。这里的落地压力仍不能代替完整通关平衡验证。
