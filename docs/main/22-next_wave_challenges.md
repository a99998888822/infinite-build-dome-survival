# 下一波挑战 · 首版实现

配置：`data_config/wave_challenges.json`。实现：`WaveChallengeSystem`、`WaveManager`、`MainFlowCoordinator`、`WaveChallengePopup`。

## 玩家流程

完成一波 → 结息、奖励和银行备战 → 点击「开始下一波」→ 哥布林提出一项符合条件的挑战。

- 「接受并开战」：落实挑战并立即开战。
- 「正常开战」：拒绝本次挑战，按原难度开战。
- 「返回银行」或 Esc / Android 返回：回到本次备战，保留同一项挑战；购物、存取后再次打开也不会重抽。
- 首波直接开始；没有下一波时不出现挑战。没有符合条件的候选时直接正常开战。
- 已有交易「本金增加、直接开战」仍直接开始，不再追加挑战弹窗。
- 挑战不改变整局难度档位，不会未经选择自动提高难度。战斗波次栏显示「挑战」，日志记录接受条款。

## 三种内容

| ID | 哥布林对白 | 效果与时点 | 有效期 |
| --- | --- | --- | --- |
| extra_elites | 多来几个大家伙而已，你不会连这点钱都不敢赚吧？ | 下一波额外 2 个现有钢甲骑士精英，分别在波次时间经过 18%、36% 时生成；沿用原掉落及遗物掉落衰减规则 | 仅下一波 |
| rising_tide | 风浪越大，鱼越贵！ | 接受时立即侵蚀 +20、利率 +1 个百分点、本金 +100、幸运 +10；侵蚀参与即将开始波次的怪物属性快照 | 持续本局，重复接受可累加 |
| all_in | 下一步结束，将全部金币存入本金。<br>额外获得本金 +100，幸运 +10. | 下一波存活结束，先结算全部利息（含遗物追加结息），再将钱包全部金币转入本金，最后本金 +100、幸运 +10 | 转存执行一次；本金与幸运奖励保留本局 |

自动存款以实际结算完成时的钱包余额为准，包含旧金币、战斗收入、利息。接受时不提前扣款或发奖。本次银行存取限制不阻止未来约定的自动存款；自动转存不占下次银行的手动操作次数，也不视作下一波的备战手动存款，不提前满足高利契约。下次进银行仍可手动取出。死亡不转存、不发奖励；最后一波若接受此挑战，存活结算时同样兑现，然后正常胜利。

额外精英独立于原精英替换配额、首个精英波次和配额上限；不会挤占原计划名额。普通生成仍遵守数量上限，挑战精英允许额外超过上限最多 2 只。沿用现有出生预警、战斗行为和美术。未击败的精英随波次结束清场，不发额外奖励。

## 如何触发

战斗吃力满足以下任意一项：

1. 沿用交易系统：最后 3 秒平均存活敌人数 ≥ `max(15, ceil(当前难度敌人上限 × 30%))`。
2. 沿用交易系统：至少 3 次从半血以上掉到半血以下；需先回到 60% 生命才重新计数。
3. 挑战补充：本波累计至少 5 秒处于半血以下，避免一直残血却没有反复跨越阈值的漏判。

上波从容需同时满足：已观测至少 5 秒战斗、没有吃力判定、最低生命比例 ≥65%、没有半血事件、最后 3 秒平均敌人数低于上述敌群阈值的一半。残血后回满不会被算作从容。仅「没有触发吃力」不足以算作从容。

战力提升不大：在本次银行开放时记录基线，点击开始下一波时比较当前装备与属性。输出、生存、移动或控制任一估值提升达到 15%，就视为明显提升；全部未达到才算提升不大。只比较这次备战中的变化，不把之前的免费升级奖励误算成商店购买。

- 输出参考已装备武器的基础伤害、玩家加成、期望暴击、实际攻速、多投射物和已装备附魔数量；钱袋读取实时本金。
- 生存参考最大生命、护盾容量、实际承伤比例和回血；本金遗物生成的属性包含在内。
- 只买背包物品、刷新、经济属性上涨而未带来战斗属性提升，不会因花钱多就判定为显著变强。
- 这是选择对白用的确定性近似，不能预测生死。复杂附魔替换与条件触发遗物仍有估计误差；不会调用伤害随机数，也不会据此暗中调节战斗难度。

候选池：

| 条件组合 | 概率 |
| --- | --- |
| 吃力，或提升不大；不从容 | 两个冒险挑战各 50% |
| 从容且提升明显 | 自动存款 100% |
| 从容且提升不大 | 两个冒险挑战各 25%，自动存款 50% |
| 不吃力、不从容且提升明显 | 无挑战，正常开战 |

因此「吃力 / 提升不大」保留为或条件，没有改成必须同时满足。候选只在本次首次打开时抽取；拒绝、重复点击、返回银行、打开设置都不能重复领收益或重抽。

## 数值判断与美术

首版保留用户给定数值，不附加隐藏惩罚或新的计量条。两只精英是较激进的自选风险，特别是早期；侵蚀奖励即时提供诱惑，但侵蚀持续累加。自动存款提供一次性本金奖励，代价是下一次备战钱包被转空，取钱会消耗一次银行操作，也可能降低本金遗物属性。

复用已确认的哥布林、柜台、金边交易框和打字音效，新增三枚 32×32 像素风 SVG 图标。挑战弹窗位于属性栏上层并居中，条款和按钮立即完整显示；只有对白逐字出现。小窗口保留哥布林，长条款可滚动。结息演出另列「结息后自动存入本金」及「挑战奖励」，不把奖励误算为利息；提示改为「利息已转入本金」。

文案修订：标题统一为「第x波·挑战」，标题与左侧图标垂直居中，横向位置保持原样；移除全部挑战绿色补充说明，卡片高度随白色正文收缩。全额存入对白使用用户指定的两行文本，对话气泡随文本高度调整。

相关回归入口：`goblin_trade_test`、`finance_preparation_test`、`interest_arrival_test`、`economy_flow_test`、`erosion_pressure_test`、`elite_relic_decay_test`、`miniboss_choice_test`、Bootstrap。旧流程测试在新弹窗主动选择「正常开战」。

2026-09-28 验证结果：新增功能 71 项通过；哥布林交易 98 项、结息演出 40 项、经济流程 57 项、侵蚀 64 项、精英掉落 71 项、精英选择 25 项、资本家角色 97 项均通过；银行备战与 Bootstrap 自检通过。1152×768 / 640×360 实机截图已检查，且完成窄屏真实点击验证。

Godot 编辑器检查无脚本解析、编译错误。环境仍提示缺少 Android build-tools；部分既有回归场景退出时输出对象/资源未释放提示，未在此功能中修改这些测试的资源清理。首版战力估算和奖励强度仍应结合玩家实战继续调参，测试通过不等同于数值已充分平衡。
