# 实机审阅反馈修正：攻击动画、雷火与受击震动

## 修正结果

- 上次结霜录像的角色停在攻击姿势，是审阅夹具关闭了 `PlayerController` 的物理更新；角色攻击动画也通过该更新推进。真实施放和伤害仍在发生，但角色姿态没有继续播放。现已恢复正常物理更新，靠清空移动输入让角色站立，并对每段录像检查攻击帧变化和回到待机。
- 雷火候选取消共同的规则星形轮廓。黄白色尖角碎块具有不同宽度、长度、偏转角度与飞散距离，起手重叠，随后分离；继续使用 3px 硬边色块。造型变化依据命中位置生成，不消耗战斗随机数。伤害、范围、持续时间与密集反应预算保持原值。
- 普通怪物及小 Boss 的自身受击震动参数由 14px 改为 `14 / 3`，即约 4.67px；最终按整像素显示，首帧横向位移为 5px。震动时长、普通怪物闪白、小 Boss 不闪白，以及屏幕震动和 0.05 秒卡肉逻辑沿用现有设置。

怪物震动幅度已修改正式实现。雷火造型仍处于组合反应候选审阅状态。
