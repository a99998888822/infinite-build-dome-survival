# 移动端与前期难度调整（2026-11-08）

## 本轮调整

- 移动端快捷附魔台入口移到右侧属性卷轴左侧，避免展开卷轴时覆盖入口。
- 移动端初心者基础移速 140 → 155（约 +10.7%）；仍使用现有平台过滤规则，不发放突进短刃。桌面端初始配置不变。
- 前期精英／Boss 血量倍率：第 1～2 波 0.65，第 3 波 0.75，第 4 波 0.85，第 5 波 0.95，第 6 波起 1.0。此倍率叠加在原有难度、波次成长上。
- 正式流程第 1 波不安排精英，首个精英从第 2 波开始。标准难度、无额外侵蚀／合约加成时，第 2 波冲锋精英约 595 → 387 血，冥狼约 714 → 464 血。
- 夜间新生怪物血量／攻击成长周期 20 → 30 秒；首周期之后每周期增量 0.5 → 0.35。血量从入夜开始增长，攻击从夜间第 20 秒开始增长。
- 夜间追击加速从第 40 秒开始、60 秒达上限，改为第 50 秒开始、80 秒达上限。上限仍为玩家当前移速的 95%。
- 夜间成长只在怪物出生时结算，存活怪物不会随时间回血。刷怪数量、奖励衰减与撤离规则沿用当前配置。
