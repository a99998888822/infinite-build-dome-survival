# 龙卷 R04 正式视觉资源

归档说明：下文审阅场景及输出路径属于历史记录，已不在当前项目中。正式图集、播放组件、许可及离线重建工具保留。

已将审阅通过的 R04 原图集放入 `assets/effects/tornado/`，普通、火、霜三种形态各有前后两层。每层 60 帧，30fps，2 秒循环；单帧 192×184，脚底锚点为 (96,158)。霜形态使用 `frost` 命名，兼容玩法内部的 `ice` 状态 ID。

`scripts/effects/tornado_visual.gd` 预加载正式导入纹理，提供分层绘制、动画帧与 3 秒显隐曲线。支持在敌人绘制前后分别调用两层，保留遮挡关系。静态图集共享，无需运行时绘图或加载审阅目录。

2026-11-16 已作为独立史诗附魔 `scroll_tornado` 正式接入。通过现有商店／奖励候选池及附魔台获得和装备，由 `CombatEffectWorld` 的武器命中入口生成；地面命中同样支持。沿攻击方向以 48px/s 移动，持续 3 秒，地面作用半径 42，随伤害范围属性缩放。每 0.5 秒造成 25% 元素伤害，共六次（0 至 2.5 秒）；伤害不再调用武器附魔入口。独立多投、分裂／弹跳继续遵循已有每攻击单元每附魔三次预算。

普通龙卷接触脚下仍存活的火池或冰场后，固定转换为火／霜形态，沿用现有燃烧／冰冷及元素反应规则，不消耗场地、不重置寿命。同一位置同时覆盖两种场地时火池优先。暂停时移动、寿命、伤害和动画共同暂停。前后层使用既有战斗层级夹住敌人，正式贴图未重绘。卷轴暂时复用风刃图标；独立名称、描述和效果 ID 已配置，不修改现有风刃。

GPU 动图展示三列隔离场景：普通、经过火池、经过冰场；三列均由正式附魔命中入口生成，使用实际敌人、场地和伤害结算。背景为审阅用简化场地。临时录制场景不纳入正式资源；验证日志、场景源和动图随归档保留。正式图集不依赖被导出排除的 `artifacts/`。
