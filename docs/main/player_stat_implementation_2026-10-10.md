# 玩家属性实装补全（2026-10-10）

- 控制强度：所有软控、硬控持续时间乘以 `1 + control_power / 100`，再乘敌人的控制易感系数。覆盖冰减速、湿润减速、冻结、眩晕、致盲、风/冲击波/星移击退、普通命中击退、接触弹开及黑洞牵引。冻结、眩晕、致盲原有上限先限制基础时长，再加成，避免高控制强度被最终上限截断。减速幅度、击退初速、普通投射物寿命、光标记和燃烧时长不因该属性变更。击退持续更久，因此位移距离也会增加。已有雷电连锁目标数加成保留。
- 控制来源：武器伤害事件保存施法时的控制属性；复制事件、分裂以及解冻转湿润保留该值，避免重复乘算。无来源的原生击退使用当前玩家属性。
- 护盾：每波开始读取完整的当前 `shield` 属性，重置当前护盾和护盾容量，并清空恢复余数。角色、营地、遗物和局内修改器均参与。波中属性变化不会直接补盾，到下一波生效。死寂护盾徽章、虚空触手保留静态属性，移除重复的波初发盾事件，防止发放两份。独立的事件发盾能力仍可使用。
- 理财：保持现状，`finance` 仅提供开局初始本金。后续实际余额由理财系统维护。
- 货币获取加成：保持现状，只直接加成拾取金币。固定奖励、利息和营地币总额不重复乘算。
- 侵蚀度：普通刷怪数量乘以 `1 + max(侵蚀度, 0) / 100`，并与怪物数量增幅相乘。每 100 点侵蚀度，普通刷怪供给增加 100%，不封顶；刷新间隔不变。沿用本波侵蚀快照、同屏上限、精英替换配额和额外挑战生成规则。
- 数量小数：合并两个百分比后使用万分之一整数余量，所有刷怪组共享，新波/新局清零。例：侵蚀33、数量增幅1，每个基础槽位产生1.3433只；一万次槽位累计13433只，余数为0。达到同屏上限的超额整只丢弃，不积欠。

专项验证入口：`scenes/tests/player_stat_implementation_test.tscn`、`scenes/tests/erosion_pressure_test.tscn`。另回归护盾恢复、遗物一致性、挑战数量小数、元素反应和基础刷怪密度。
