# Infinite-Build-Dome-Survival 游戏总览设计

本文档只记录当前版本的顶层设计口径，详细字段、场景节点、接口和实现清单以 `docs/main/*.md`、`docs/main/checklist/godot_verification_master_checklist.md` 和 `docs/asset/*.md` 为准。

## 1. 基础信息

- 项目工程名：`infinite-build-dome-survival`
- 引擎版本：Godot 4.7.1
- 游戏类型：2D 俯视角自动战斗 Roguelite
- 单局结构：波次制局内战斗 + 局外营地成长
- 核心特色：武器负载构筑、遗物羁绊、区域连驻与福缘收割、轻克苏鲁氛围

## 2. 当前确认口径

1. 升级奖励和商店购买共用同一套共享奖励/商店页。
2. 共享奖励/商店页只提供三类内容：`new_weapon` 新武器、`weapon_upgrade` 武器升级、`relic` 遗物。
3. 不再提供单独的基础属性升级候选。
4. 升级奖励是共享奖励/商店页里的免费领取入口；付费商店入口使用同一套候选池和刷新规则。
5. 每波结束后只统一吸取场上经验球。金币由经验球结算同步产生；血包等即时拾取物不参与波次收尾吸收。
6. 波次结束后的页面左侧展示奖励/购买选项，右侧展示玩家当前属性。
7. 不单独制作结算横幅，结果标题直接用文本展示。
8. 战斗过程中不写正式存档，只在死亡或通关后的最终结算、营地升级购买、设置变化时保存。

## 3. 主流程

### 3.1 战斗流程

```text
启动页面
→ 选择角色
→ 进入战斗第一波
→ 战斗过程中升级时打开共享奖励/商店页
→ 波次倒计时结束
→ 吸收所有经验球并清理其他奖励拾取物
→ 如果吸收经验后升级，则继续打开共享奖励/商店页
→ 结算上一波理财利息
→ 打开商店页面
→ 完成购买或跳过后打开理财页面
→ 玩家决定是否存入当前剩余局内金币
→ 进入下一波战斗
→ 循环直到死亡或通关
→ 最终结算并回到主入口
```

### 3.2 营地流程

```text
启动页面
→ 进入营地页面
→ 查看营地建筑、升级选项和局外货币
→ 购买建筑等级或营地升级项
→ 保存局外进度
→ 返回主入口或进入下一局战斗
```

## 4. 核心系统

### 4.1 武器负载

玩家不使用固定武器栏，而是通过负载上限管理已装备武器。新武器、已装备武器升级和遗物都来自共享奖励/商店候选池。负载不足时，新武器仍可以出现在候选中，但实际购买或装备必须进行负载校验。

### 4.2 遗物与羁绊

武器与遗物共同提供羁绊标签，局内凑够层数后立即生效。MVP 使用 2/4/6/7 阈值，不做额外解锁、装填、互斥切换；特殊效果先记录不执行，后续模块再实装。

### 4.3 敌人与波次

波次系统负责计时、刷怪、波次结束、经验球收尾吸取和清场。敌人死亡后通过掉落表生成经验球或即时拾取物；波次结束时只有经验球参与统一结算。

### 4.4 掉落与奖励

经验球是局内经验和金币的主要结算载体。拾取经验球时同时获得经验和等额基础局内金币，并分别受到 `exp_gain_percent` 和 `currency_gain_percent` 影响。

共享奖励/商店候选池只包含新武器、武器升级和遗物。免费奖励入口与付费商店入口共用候选池、稀有度权重、类型权重和去重规则。

候选目标数基础为 3，由玩家整数属性 `shop_offer_count_bonus` 加成，统一按 `max(2, 3 + round(shop_offer_count_bonus))` 结算；因此该属性同时影响升级奖励与局内商店，且目标数不会低于 2。

### 4.5 UI 与主流程

主流程由 `MainFlowCoordinator` 或同类协调器管理。它负责启动页、角色选择、战斗准备、波次战斗、共享奖励/商店页、利息结算、商店、理财、战斗结果和营地入口之间的顺序。

UI 只读业务状态，通过信号、快照和弹窗参数刷新，不直接计算掉落、数值或存档。

### 4.6 存档与营地

存档只保留局外进度：`camp_currency`、建筑等级、营地升级项等级和设置。局内金币、理财本金、武器等级、遗物、波次状态和拾取物状态都不写入正式存档。

## 5. MVP 范围

1. 基础数值与数据配置：`DataRegistry`、`ModifierStack`、核心 JSON 表。
2. 玩家与角色：1 名默认角色，移动、受击、拾取范围、摄像机跟随和动画。
3. 局内武器：3 把基础武器，负载、装备、升级和自动攻击。
4. 敌人与波次：1 种普通敌人，基础波次推进，经验球结算。
5. 掉落与奖励：经验球、血包即时拾取、共享奖励/商店候选池。
6. UI：战斗 HUD、共享奖励/商店页、负载替换提示、理财和简单结果页。
7. 营地与存档：固定营地界面、基础建筑升级、最终结算回流。
8. 音频与氛围：基础攻击、命中、拾取、UI 音效和轻量氛围反馈。
