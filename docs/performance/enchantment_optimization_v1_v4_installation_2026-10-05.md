# V1～V4 附魔性能优化正式安装

2026-10-05，按用户确认，将四轮累计性能优化安装到正式工程。共更新 9 个运行脚本、新增 2 个绘制辅助脚本，并同步 1 条旧测试断言。11 个运行脚本与最终审阅工程及各轮最终快照逐字节一致。

## 安装内容

| 范围 | 正式改动 |
|---|---|
| 状态视觉 | 静态状态图形只在状态或身体半径变化时重绘，保留视觉时钟和火焰动画。 |
| 水波 | 共享轮廓计算，缓存短线采样，优化多边形扫描；使用既有 CanvasItem 绘制路径。 |
| 粒子 | 一次提交实例缓冲区；过期粒子按原顺序压缩，保持绘制顺序、运动、寿命与空闲槽回收顺序。 |
| 爆炸 | 缓存可破坏地形的查找结果，包括未找到的结果；场景树变化时失效。 |
| 伤害数字 | 共享最多 8 种样式；每个战斗父节点最多保留 160 个空闲 Label，保留数量预算、动画和叠放顺序。 |
| 受击动画 | 同一批命中复用尚未推进的 Tween；已推进、停止或失效的动画仍按原规则重启。 |
| 冰光反射 | 提前排除远处目标；每束光保留未命中的有序候选，敌人注册变化时刷新；像素方块批量绘制，保留重叠顺序。 |
| 冰场 | 复用查询对象，排除本冰场已命中的物理对象；保留扫描频率、新目标检测及风扩展后的即时查询。 |

新增辅助脚本为 `scripts/effects/pixel_rect_batch.gd` 与 `scripts/effects/reflection_pixel_batch.gd`，对应 UID 由 Godot 自动生成。已弃用的水波 MultiMesh 实验未安装。

`scripts/tests/combat_optimization_test.gd` 中原先要求静态状态图形每秒重绘 12 次的断言已同步为：静态图形保持缓存，视觉时钟仍推进。未改变运行版本来迁就旧断言。

## 验证与已知限制

安装前，9 个既有目标脚本全部与对应优化前快照一致，没有覆盖这些文件中的其他新改动。安装后逐文件核对哈希，Godot 编辑器解析、主场景正常退出，以及四轮对应的一致性测试通过。

核心回归覆盖 7 种粒子的 240 步模拟、地形缓存失效与材料输出、伤害数字预算和复用、受击曲线与随机数、反射边界与注册表变化、冰场移动／新增／死亡目标和范围扩展。

最终 10 组正式战斗组合全部通过，覆盖两种感电、两种雷火爆炸、圣焰、暗焰、光暗抵消、冰光反射、湿润传播和冻结。4 次 GPU 检查全部通过：粒子／水波／状态一致性，以及雷火爆炸、反射、冻结的正式战斗运行。所有 GPU 检查均在私有 Windows 桌面进行，实际桌面核对一致，`foreground_samples=0`。状态缓存 23 项、战斗优化 134 项、爆破 38 项断言通过。

扩展检查保留四条安装前就存在的失败断言：两条 HUD 上下间距断言，以及两条冰场投影范围／范围加成断言。已用当前工程的安装前版本单独复测，安装前后失败文本完全一致；没有把它们计为通过，也没有顺带改动 HUD 或冰场命中范围。

一次固定步长的爆破测试在退出时出现音频资源释放提示；恢复该测试原本的实时计时后，38 项断言及退出检查均通过。战斗组合检查还曾遇到并行设置界面编辑的中间状态，该次记录单独保留；刷新脚本索引后重新验证。

性能数据沿用之前审阅阶段的独立跑分，本次安装验证不重新宣称 FPS 收益。冰场整场收益仍有波动；反射的像素覆盖和透明度保持一致，RGB 通道仍可能存在最多 1/255 的绘制舍入差异。
