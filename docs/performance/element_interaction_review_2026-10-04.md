## 已实现的反应

| 前置条件与触发 | 实际行为 | 视觉表现 |
| --- | --- | --- |
| 燃烧遇水／湿润遇火 | 蒸汽伤害，默认元素基准伤害的 1.5 倍；普通燃烧或湿润被消耗 | 灰青色像素蒸汽向上散开 |
| 湿润遇冰／冰减速遇水 | 冻结；到期恢复湿润 | 冰壳、放射冰晶，随后解冻碎冰 |
| 湿润遇闪电链或电火花落雷 | 消耗湿润，对同一目标追加一次电击 | 蓝青色导电轮廓；追加路径，主雷电为正式 2px |
| 燃烧遇闪电链或电火花落雷 | 清除燃烧并引发独立范围爆炸，默认 1.8 倍基准伤害、72px 半径 | 橙色锯齿环、白色雷枝与中心闪光 |
| 燃烧与光状态相遇 | 圣焰，燃烧持续伤害翻倍 | 黄色旧式三火舌、冠状星光 |
| 燃烧与暗状态相遇 | 暗焰，燃烧时长延长到至少 10 秒 | 紫黑旧式三火舌、螺旋与眼形提示 |
| 暗焰遇水 | 产生蒸汽但保留暗焰 | 蒸汽与紫黑火焰同时出现 |
| 光与暗状态相遇 | 清除已有对立标记，本次不留下新的对立标记 | 黑白弧线合拢、碎散 |
| 冻结 + 光状态，且接触携带伤害事件 | 每轮冻结触发一次冰光反射；默认扫射半径 220px、3.5 倍基准伤害 | 带彩边的像素光束旋转扫过目标 |
| 风命中湿润目标 | 默认向 92px 内最多 4 个目标传播水元素 | 蓝色水带、落点水滴 |
| 风命中火场附近 | 默认半径乘 1.35，最高 96px | 正式三火舌火场变宽，覆盖更多敌人 |
| 风命中冰场附近 | 默认半径乘 1.35，最高初始值两倍；新覆盖目标首次命中 | 冰晶霜纹向外扩展 |

16 个录像分别覆盖：水火两个顺序、冻结/解冻、两种电法术的感电与雷火、圣焰、暗焰、暗焰遇水、光暗抵消、冰光反射、风扩水/火/冰，以及风传播湿润后产生蒸汽。

这些不是所有附魔排列的穷举。同一种反应可以由不同武器、附魔顺序及既存场状态触发；无独立新画面的组合另见下文。

## 容易误解的边界

- 感电是同一目标的追加命中，不是凭空多跳一个目标。普通闪电链仍有自身选取后续目标的逻辑。
- 电命中同时带燃烧和湿润的目标时，当前分支优先雷火爆炸，不继续叠加感电分支。
- 冰光反射要求冻结；单独冰场造成的减速不足以触发。光剑有落地延迟，因此附魔槽位顺序和实际状态生效顺序可能不同。
- 水不会直接删除地面火场。普通燃烧被清除后，仍在火场覆盖内的怪物可能重新燃烧。
- 圣焰／暗焰是独立的燃烧变体状态。普通光／暗标记的清除不等于始终以同一种方式清除变体；连续多种元素的先后顺序会影响最终状态。
- 风传播的是水元素接触，能继续触发蒸汽或冻结；火场扩张本身没有独立风火爆炸。
- 火 + 冰没有专门的融化反应；黑洞 + 水／冰／雷主要通过聚怪影响命中，没有对应的新增专属特效。
- 当前 `explosion` 附魔对应震荡推开，不是雷火爆炸。分裂和弹射改变攻击传播及触发次数，不定义新的元素反应图案。

## 与之前单元素视觉优化的关系

普通火焰使用 `pixel_fire_visual.gd` 的缓存实例和着色器，普通燃烧为一支窄火舌，火场为一中宽加两窄。圣焰、暗焰仍由 `enemy_status_visual.gd` 与 `reaction_pixel_shapes.gd` 生成旧式三火舌，转化瞬间另叠加 `element_reaction_visual.gd` 的提示图案，尚未套用普通火焰的造型与渲染实现。

普通雷电主路径使用 `lightning_pixel_bolt.gd` 的一次生成网格，初始与闪回独立，并采用当前正式 2px 网格。感电轮廓及雷火爆炸里的雷枝仍由 `element_reaction_visual.gd` 调用 `pixel_effect_draw.gd` 逐段绘制，不能认为它们已经获得相同的缓存收益。

水带、冰霜扩展、蒸汽与光暗抵消等提示会随动画重画。反射还同时扫描敌人并结算扫射命中。普通状态绘制约 12fps 刷新；反应提示没有全部采用同样的刷新策略。提示节点总上限为 96，密集时会合并近处同类提示或降低装饰细节。

以上只是下一轮优化的定位依据，当前未针对这些类别做独立大规模性能剖析。

## 录制与计数方法

- 正式战斗场景，1152×648，6 个固定布置的真实怪物，保留原状态计时、碰撞、击退和伤害。通过正式 `CombatEffectWorld.trigger_weapon_impact` 接口按时间顺序触发附魔，避免随机战斗遮住罕见反应；未直接调用绘制提示制造反应画面。
- 每个案例分开运行不录制采样与录制：准备 1 秒，采样约 4.8 秒。关闭垂直同步和帧率上限。审阅场景会观察状态与节点，因此其开销也包含在测量内；这些短样本不代表大量移动怪物下的性能。
- 左上角保留原游戏 FPS、怪物数和粒子数。原“粒子”只统计 `combat_particle_counters`，通常不计入反应网格、火焰着色器和持续状态图案。补充的提示、网格特效、普通火舌计数范围不同，不能相加；普通火舌数不包含圣焰/暗焰旧式绘制。
- 录制帧的实际时间戳用于重采样；MP4 为 20fps，GIF 为 15fps，按实际时间播放。录制中的 GPU 读回会影响左上角 FPS，审阅页另列不录制的采样值。
- GPU 检查使用私有 Windows 桌面，核对实际桌面一致和 `foreground_samples=0`。原始 RGB 帧在编码成功后删除。
- 现有元素反应测试：64 项通过，2 项既有冰场范围断言失败，分别涉及椭圆边界外的排除和范围属性放大覆盖。当前小怪碰撞体及冰场需要后续专门复核，本轮未修改。
