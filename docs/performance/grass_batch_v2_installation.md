# 草丛合批 V2 正式接入

2026-10-04：用户审阅 http://127.0.0.1:8786/v2/ 后确认替换，已将该版本接入正式战斗场景。

## 接入范围

- `scripts/battle/meadow_battle_backdrop.gd`：初始化草场后自动绑定合批器，退出战斗前停止更新。合批器作为草场子节点，随场景暂停、释放。
- `scripts/battle/meadow_grass_rows.gd`、`meadow_grass_bands.gd`、`meadow_grass_batch.gd`：从审阅版依赖链迁入，修正资源路径及节点标记；增加草场/玩家有效性检查。沿用已审阅的 8px 深度带、共享前后绘制缓冲、256px 分块增量登记、约 1.5ms 上传阶段预算和远坐标高度编码。
- `shaders/battle/meadow/grass_bands.gdshader`：正式使用的合批着色器；`grass_rows.gdshader` 保留为基础类依赖。
- `scripts/tests/meadow_grass_batch_test.gd` 与对应测试场景：覆盖正式自动启用、分块切换、固定镜头下移动、两名角色、缩放、退出与重新进入战斗。

原草簇节点继续作为绘制记录与对照回退来源保留，正式运行时隐藏。此次没有移除其分配成本，也没有进一步改变已审阅算法。草簇贴图、地图布局、密度、颜色、接触阴影、地平线和火焰资源保持原样。

## 正式工程验证

- 无窗口编辑器检查通过；主场景启动并正常清理退出检查通过。
- 集成测试：无窗口 164 项、私有桌面 GPU 214 项，均无失败。
- 24 组原版/合批配对截图，覆盖两名角色、1152×648 / 1152×768、跨分块与远坐标（含 -42000 / 33000）。最大颜色通道差为 1/255，没有超过该阈值的像素。另验证小窗口、镜头缩放及世界视口缩放的映射。
- 固定镜头下移动角色不增加缓冲重建或批次节点创建次数；退出战斗后合批器及玩家视觉节点全部释放。
- 120 怪正式火焰实战运行通过，确认实际攻击、伤害产生及退出清理。该短跑仅作接入验证，不作为新的前后性能基准。
- 两次 GPU 运行均验证实际私有桌面一致，`foreground_samples=0`。
- 直接用 `--quit-after 120` 强制终止主场景时出现退出资源占用提示；改用已有主场景 smoke 流程，显式清理场景与音频后正常退出，无报错。编辑器另有本机 Android build-tools 目录提示，不影响桌面检查。

## 性能边界

沿用审阅阶段结论：120 怪平均 59.7 → 69.7 FPS，300 怪 37.7 → 44.3 FPS。120 怪基准 5 轮、候选 3 轮；300 怪各 1 轮。以上来自同一独立项目快照，不能直接与当前正式项目的单次运行比较。

P99 帧时间仍略高于原版；本次正式接入不宣称已解决偶发长帧。后续可继续优化草簇节点分配和分块登记成本。
