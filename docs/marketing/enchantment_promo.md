# 裂地战锤附魔宣传片

专用演示场景复用正式理财附魔页面、Lv.4 裂地战锤与真实装填接口。图标沿途保持背包原生 32×32 尺寸，使用青白色阶梯像素刀锋拖尾。三条曲线分别为左侧上扬、右侧大弧回收、下绕后向上入槽。

第二版开场背包已有三个附魔，从左到右为智慧、落雷、多投；按从右到左顺序飞入第 1、2、3 槽，最终槽位依次为多投、落雷、智慧。后一枚在前一枚入槽前 0.15 秒亮起并起飞，每枚拥有独立飞行与入槽特效。

| 画面 | 时间 |
| --- | --- |
| 战锤、三个空槽和完整附魔背包 | 0–0.5 秒 |
| 多投：亮起飞行 / 入槽反馈 | 0.5–1.05 / 1.05–1.35 秒 |
| 落雷：亮起飞行 / 入槽反馈 | 0.9–1.45 / 1.45–1.75 秒 |
| 智慧：亮起飞行 / 入槽反馈 | 1.3–1.9 / 1.9–2.2 秒 |
| 三槽装满定格 | 2.2–4.2 秒 |

背景音乐 0，音效 100，主音量 100；采用游戏已有风刃与结息短音素材制作飞行、入槽提示，按各素材增益混音。设置只应用于临时录制进程，影片音轨来自 Godot MovieWriter。游戏音效 100 对应现有 SFX 总线 +2 dB，并非重设所有音源的增益。

```powershell
python scripts/tools/record_enchantment_promo.py
```

默认输出到系统临时目录 `enchantment_promo_20261022_v2/`，可用 `--output` 指定其他目录。产物包括 `enchantment_promo.mp4`（1920×1080、60 fps、4.2 秒、AAC）、阶段截图、事件与路径坐标 `report.json`、后台桌面检查 `capture.json`、编码检查 `export.json`。保留原生 `gameplay.avi` 以便重新编码；已有录制使用 `--encode-only`。

入口为 `scenes/debug/enchantment_promo.tscn`，必须带 `--transient-session --capture-dir=<目录>`；GPU 运行必须经 `run_godot_background.py` 的私有桌面。无头检查也可运行完整时序和最终附魔顺序断言。正式游戏入口与战斗特效不因这个演示发生变化。
