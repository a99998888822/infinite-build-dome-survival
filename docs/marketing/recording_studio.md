# 战斗录制台

已接入：2026-10-02。配置指定构筑后，直接进入正式战斗或哥布林银行，供 OBS、系统录屏等工具拍摄。页面本身不输出 MP4。

## 打开

推荐在项目根目录双击 `open_recording_studio.cmd`。启动器会查找 Godot，并在加载存档系统之前启用临时会话。

也可以在 Godot 编辑器打开 `scenes/debug/recording_studio.tscn`，按 F6 运行当前场景。直接启动这个场景同样会在存档加载前识别录制模式。

命令行：

```powershell
python scripts/tools/open_recording_studio.py
# 找不到引擎时可手动指定：
python scripts/tools/open_recording_studio.py --godot "D:/path/to/Godot.exe"
```

主游戏默认入口不变。自动验证只使用无头检查或项目的私有桌面后台工具；双击启动是用户主动打开可操作的录制窗口。

## 配置与规则

| 项目 | 作用 |
| --- | --- |
| 起始波次、难度 | 从当前 20 波中选一波，直接开始；不模拟之前的战斗或补发其收益 |
| 角色、等级 | 使用真实角色被动、自带遗物与等级生命成长；不带正式存档中的营地升级 |
| 随身金币、银行本金 | 独立设置；余额在遗物获得奖励之后覆盖为填写值，再执行真实波初效果 |
| 额外理智、额外侵蚀 | 加到角色与遗物的属性上，允许负数；不是覆盖最终属性 |
| 多把武器 | 每把选择等级；不能重复装备同一种，遵循真实负载容量 |
| 每把武器的附魔 | 最多两个，按品质开放槽位并校验兼容性；以页面的列表为准，替代角色初始武器附魔 |
| 额外遗物 | 可以选择数量；上限包含角色自带遗物 |
| 开场位置 | 直接战斗，或先进入指定波次前的银行备战 |
| 倒计时 | 0–10 秒；倒计时期间不推进战斗，结束后隐藏配置面板 |
| HUD | 可以隐藏战斗界面，银行和奖励等操作界面保持可用 |

配置不会修改正式 JSON 数据。录制过程中仍按当前游戏规则获得奖励、升级、交易、进入下一波或结算。跳关构筑属于机制演示，不代表通过前几波自然获得的配置。

## 三个内置预设

| 预设 | 配置 | 用途 |
| --- | --- | --- |
| 长枪 · 分裂与火焰 | 第5波，初心者 Lv10，守夜长枪 Lv3，分裂＋火焰，200金币，1000本金，一件钢铁保险柜 | 先拍战斗、攻击与附魔表现 |
| 本金依赖 · 银行开场 | 第5波备战，初心者 Lv10，食利者钱袋 Lv3，电火花，0金币，1000本金，一件钢铁保险柜 | 取200本金，演示该遗物的护甲贡献由20变16；之后可购买装备并开战 |
| 理智与侵蚀 · 第8波 | 初心者 Lv18，长枪 Lv3，分裂＋火焰，200金币，1000本金，额外侵蚀30；保险柜、无眠账簿、守魂人面石雕 | 展示更复杂的代价与构筑；需要对照时自行把额外侵蚀改成0 |

这些是方便取景的起始配置，不是通关强度保证。增减武器和遗物后点击“进入场景”，若不符合真实规则，页面会显示具体原因。

## 录制操作

1. 载入一个预设，或自行设置参数。
2. 给常用构筑填写名称，点击“保存为我的方案”。同名保存会覆盖该方案。
3. 开启自己的录屏工具，点击“进入场景”。
4. 倒计时结束后，使用 WASD／方向键操作。

| 快捷键 | 操作 |
| --- | --- |
| F6 | 从同一份起始配置重拍，重新建立战斗；不保留上次已花的钱或拾取的装备 |
| F7 | 暂停／继续战斗；奖励和银行界面沿用正常暂停规则 |
| F8 | 清理本次场景并返回录制台；表单保留，方便调整 |
| F9 | 显示／隐藏战斗 HUD |

重拍恢复配置，不保证相同的随机掉落、怪物位置或战斗过程。正常角色动作、武器攻击、命中、伤害和画面效果均复用正式场景。

自定义方案保存在 Godot 用户目录下的 `recording_studio/presets.json`。这是录制方案文件，与 `saves/profile_01.json` 正式进度分开；录制中的营地币结算不会写入正式存档。
