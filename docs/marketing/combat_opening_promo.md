# ARPG 战斗开场脚本

更新：2026-10-23。当前为第二版，成片 9 秒，1920×1080、60 fps、540 帧。

成片：[combat_opening.mp4](../../artifacts/previews/combat_opening_20261023_v2/combat_opening.mp4)。[录制报告](../../artifacts/previews/combat_opening_20261023_v2/report.json)保留构筑、输入、敌人状态、血量、轮廓间距和音频总线信息。

## 录制要求

- 游戏音效音量：100。
- 游戏背景音乐音量：0，关闭 BGM 总线；后期不添加背景音乐。
- 操作方式：右键点击移动目的地，数字键选择技能，鼠标左键确认释放。移星秘典回返沿用游戏现有的再次按数字键触发规则。
- 结霜特效去掉外侧椭圆轮廓线，保留冰面纹理、地面淡色填充和真实作用范围。
- 冻结冰壳及冻结瞬间的碎冰显示在怪物前景；地面冰霜保持地面层。
- 回返后按可见轮廓留出空隙，不以单纯“没有掉血”作为躲避成功的画面标准。
- 保留实际战斗音效：射击、命中、冰水效果、冥狼攻击、闪现和回返；不添加古筝声音。
- 目标规格：1920×1080、60 fps；9 秒版本为 540 帧。
- 按正常游戏速度呈现，靠减少重复动作压缩时长；闪现到回返保持连续镜头。
- 第一帧直接进入战斗，瞄准指示器可见；本段不加入字幕、标题卡或哥布林开场。

## 9 秒动作安排

| 成片时间 | 动作 | 画面重点 |
| --- | --- | --- |
| 0.0–0.8 秒 | 玩家已在移动，手动指示器转向敌群，释放第一轮五投射物弓箭。 | 第一秒看见箭扇和水流、结霜命中效果。 |
| 0.8–2.7 秒 | 侧移避开一次攻击，在真实冷却结束后转身释放第二轮箭。 | 两轮清晰的瞄准与走位；受控敌人落后，侧面追兵仍有威胁。 |
| 2.7–3.6 秒 | 冥狼锁定扑击落点，玩家在落地前手动闪到侧面空隙，留下起点印记。 | 完整呈现预警、扑击、闪现和攻击落空。 |
| 3.6–6.9 秒 | 闪现后沿外侧移动，第三轮箭控制侧面追兵，再绕行引导冥狼锁定喷吐。 | 保持主动输出，给原位置腾出空间。 |
| 6.9–7.5 秒 | 喷吐即将命中前回返，立刻沿左上方空隙移动，再转身瞄准。 | 回返落点、怪物轮廓与撤离路线保持可见间隔。 |
| 7.5–9.0 秒 | 释放第四轮箭反击，继续走位，以实际命中效果收尾。 | 躲避与输出衔接，不穿过小怪身体。 |

以上时间为动作目标，最终根据真实敌人行为在 8–10 秒内微调。压缩优先减少绕行与重复射击，不删掉关键预警、冥狼恢复过程或回返的空间交代。

## 场景与构筑

- 同一角色同时装备木质弓箭和移星秘典，两把均手动施放；关闭键盘移动与快捷施法，弓箭使用显示瞄准预览的施法方式。
- 木质弓箭装备水流、结霜，配置足够附魔槽和额外投射物来源，使最终投射物数为 5。满级弓箭自身为 3 发，分裂晶石弹头与双腔弹匣各加 1 发。
- 敌群保留可走通的间隙，玩家和敌人攻击预警不被效果遮盖。前两轮箭不要提前消灭承担后续追击的敌人。
- 第一次闪现采用适度侧向位移，保证冥狼仍能继续施压；回返必须发生在印记有效期内，且起点不再被冥狼、其他敌人或攻击范围覆盖。
- 移星秘典首次手动施放留下印记，第二次触发为一次性回返。当前武器仍处于发布锁定状态，对外发布时按开发中内容说明。
- 保留瞄准指示器、必要的武器与回返状态；尽量让两个位置均处于可辨认画面范围。

## 导出验收

- 时长在 8–10 秒内，优先 9 秒；检查视频帧数、尺寸和帧率。
- 录制会话校验音效设置 100、背景音乐设置 0；同时检查实际总线状态。现有音频实现中音效 100 对应 SFX 总线约 +2 dB，BGM 0 对应静音及 -80 dB，应以当次实现和会话报告为准。
- 成片保留可听见的战斗音轨，检查无背景音乐、无古筝声音，音效与命中及位移动作同步。
- 自动录制使用项目私有桌面工具，不抢占前台；确认实际引擎桌面与私有桌面一致，且 `foreground_samples=0`。

## 第二版录制结果

- 弓箭在 0.20、2.37、5.13、7.47 秒释放；首次闪现 3.30 秒，回返 6.93 秒。
- 调整追兵起始方位及闪现后绕行路线，回返后向左上方移动；录制全程没有敌人接触判定、伤害事件或血量下降，保持 19/19。
- 逐帧使用真实碰撞体检查接触；另外按当前动画帧的非透明区域计算世界坐标下的包围框，检查角色与敌人可见轮廓的保守间隔。成片回返后最小碰撞体包围框间隔 24.15 世界单位，可见轮廓包围框间隔 14.70 世界单位，按镜头缩放约为 21 屏幕像素。
- 蝙蝠翅膀超出其小型碰撞体，上一版可出现视觉擦碰而不掉血；本版改为按画面轮廓留空，不修改接触伤害规则。
- 冻结冰壳恢复到怪物的前景状态层，冻结碎冰使用独立前景层；已查看正式录制中的冰壳覆盖画面及回返后的连续采样帧。
- 音效 100、BGM 0；AAC 音轨峰值约 -14.7 dBFS，无削波。导出 540 帧、9 秒，私有桌面核验通过且 `foreground_samples=0`。
- `effect_pixel_alignment_test` 25 项、`water_ice_atlas_test` 29 项通过；无头场景试跑、编辑器导入和正式 GPU 录制通过。录制结束主动释放临时场景，最终日志无脚本或资源退出错误。

## 重录

```powershell
python scripts/tools/record_combat_opening.py
```

默认将原始 AVI、采样帧、报告和 MP4 写入系统临时目录的 `combat_opening_20261023_v2`。可用 `--output <目录>` 指定新版本，`--preview` 仅做后台画面检查，`--encode-only` 使用已有录制数据重新编码。
