# 小红书宣传视频观察与本项目脚本建议

记录日期：2026-10-23。本次为分析与脚本建议，没有改动现有视频。

结论：优先把“钱也是战斗属性”“哥布林的好处都有条件”“附魔会改变实际战斗”拍成具体事件。现有哥布林片段可以承担角色反应，附魔片段可以承担构筑过程；还需要能兑现这两个片段的玩法结果。

## 观察范围与证据

## 从样本中可以提炼什么

1. **先让玩家想象一种经历。** “为死刑犯做最后一餐”“剪报纸糊弄老板”比“烹饪系统”“图像拼接系统”更容易被一句话复述。本项目对应“我想买武器，却不敢动存款”。
2. **角色需要动机和行动。** 雪人与热奶茶的反差让角色有故事；哥布林也需要通过贷款、折扣、收购、减伤等交易显露性格，仅转眼还没有事件。
3. **氛围片有价值，但需要明确定位。** 《暗茧》说明场景本身能够吸引人。哥布林片段可以做氛围物料，但要宣传动作构筑玩法，还应接真实战斗。
4. **没有统一的爆款时长。** 这些样本从约 18 秒到 205 秒都有高互动。下面推荐 12–25 秒是因为本项目目前每条只讲一个机制、素材有限，并非平台算法规定。
5. **看评论内容，不能只看数量。** “怎么玩、什么时候能玩、什么平台、我想试另一种搭配”比单纯争论更接近游戏兴趣。多条笔记都有找不到名字或询问平台的情况，发布信息应清晰。

公开报道提供了背景，但不作为上述单条视频效果的证据：[36氪，2026-07-21](https://36kr.com/p/3905036594628224)讨论生活化内容和转化差异；[蓝鲸新闻，2025-08-19](https://news.qq.com/rain/a/20250819A07Q9C00)记录开发者对爆款不稳定及非目标流量的担忧。

## 现有哥布林片段

当前基准：第四版，7 秒，1920×1080、60 fps，无字幕、无音轨，片尾保留中文标题。

优点是角色、地下城入口、钱币和暗色像素美术统一，适合建立品牌印象。问题在于它尚未表现交易或冲突：约 2.15 秒完成转眼，到 5 秒标题出现之间有约 2.85 秒的低变化停留；对于第一次刷到的人，尚不知道自己要玩什么。

建议保留原母版，另做用途不同的剪辑：

- **信息流开场：约 2–2.5 秒。** 镜头推近、转眼，对视后立刻切到贷款报价、护甲变化或战斗。游戏标题挪到整片结尾。
- **角色反应：约 0.5–0.8 秒。** 玩家取钱、接受条件或未还清欠款后，切一次哥布林对视，让表情因前后事件而产生含义。
- **完整 7 秒版：** 保留作角色氛围展示，或将来配合用户自行录制的旁白；不把完整版本固定放在每条玩法视频前。

遵循用户目前偏好，不建议恢复古筝、轻笑或强制给母版加对白字幕。无字幕版本可通过笔记标题/封面交代情境，例如“我给地下城加了个银行家，结果玩家更不敢花钱了”。手机上转眼动作可能很细微，优先调整剪辑取景，让脸更清楚，不必继续重画眼睛。

## 现有附魔片段

当前基准：第三版，5.05 秒，三个原尺寸图标按右到左飞入，单枚 0.8–0.9 秒并交叠，最后定格 2 秒；背景音乐 0，保留游戏音效。

最值得保留的是连贯的装填节奏和三条不同的像素拖尾。不建议再把飞行加快，用户已经明确偏好当前放慢后的速度。

优先改善以下三点：

1. **把视线集中到武器、槽位和背包。** 当前全屏同时有哥布林、存取款、属性长表和底部日志。1920 宽画面若以 390 宽显示，32 像素图标约只剩 6.5 显示像素。宣传剪辑可整体裁切放大附魔操作区域，保留完整三条路径；不改游戏内图标尺寸，也不把竖版直接裁掉一侧槽位。
2. **缩短尾部定格，接实际效果。** 当前 2 秒约占片长 40%。展示装满约 0.3–0.5 秒后接战锤命中、落雷落下，形成“装配—战斗结果”的对应关系。
3. **让观众理解三个图标。** 现配置中多投为投射物数量 +1，智慧为元素伤害 +30%，落雷为命中后延迟 0.5 秒落下闪电。智慧不应被演成新增闪电或总伤害必增 30%；用相同条件下的元素伤害对照，或在笔记正文解释。无字版也可以通过装前/装后实机切换来说明变化。

## 优先制作的三个脚本

### A：我只是取了点钱，怎么护甲还掉了？

建议 15–18 秒。最优先：最能区分普通刷怪游戏，而且录制台已有“本金依赖·银行开场”预设。

| 时间 | 画面 | 目的 |
| --- | --- | --- |
| 0–2 秒 | 直接给出本金减少、保险柜护甲加成下降的特写 | 先出现反常结果 |
| 2–5 秒 | 回到银行，展示本金 1000，取出 200 的操作 | 交代因果 |
| 5–8 秒 | 本金 1000→800；保险柜贡献 +20→+16 | 让数值代价可见 |
| 8–12 秒 | 用取出的金币买装备，再接一次真实战斗 | 展示花钱的好处，不只惩罚 |
| 12–15 秒 | 切哥布林对视，再停在剩余存款与商品之间 | 留下选择：买装备还是保护甲 |
| 15–18 秒 | 简短游戏名和真实开发/试玩状态 | 让感兴趣的人找得到 |

配置核对：钢铁保险柜每满 50 本金提供 1 护甲，上限 40。因此变化是该遗物的贡献，不是角色总护甲必然从 20 变成 16。封面可用“存款竟然是我的护甲”。

### B：给锤子装上这三个东西之后……

建议 12–15 秒。最省新增素材：使用现有附魔片段，补装前和装后战斗镜头。

| 时间 | 画面 | 目的 |
| --- | --- | --- |
| 0–1.2 秒 | 装好后的一次清楚的命中与落雷 | 先兑现视觉效果 |
| 1.2–2.5 秒 | 同武器、同条件的未附魔攻击 | 建立比较基准 |
| 2.5–约 5.6 秒 | 现有空槽→三枚飞入→装满反馈，整体裁切放大 | 保留当前飞行速度 |
| 约 5.6–10.5 秒 | 接完整命中及延迟落雷；能看清玩家和目标 | 让装配与结果关联 |
| 10.5–13.5 秒 | 回到三槽，或给一次装前/装后对照 | 收束在一种构筑上 |
| 13.5–15 秒 | 游戏名 | 收尾 |

不要用未录到的“全屏秒杀”描述；构筑强度以实际录制为准。第一条只讲这一组，不同时加入十种武器和整页天赋。

### C：他借我 200，下一波让我还 260

建议 18–22 秒。把哥布林从背景角色变成剧情推动者。

| 时间 | 画面 | 目的 |
| --- | --- | --- |
| 0–2 秒 | 哥布林转眼，立即切借款与应还金额 | 角色和条件同时建立 |
| 2–5 秒 | 看中装备、金币不够，出现贷款提案 | 一个容易理解的需求 |
| 5–8 秒 | 接受真实报价，买下装备 | 小满足 |
| 8–13 秒 | 装备派上用场的真实战斗 | 证明借钱确实有价值 |
| 13–18 秒 | 回银行，看应还金额；展示真实还款或余额不足后的欠款状态 | 好处之后的代价 |
| 18–22 秒 | 哥布林短反应、游戏名 | 黑色幽默收尾 |

200→260 是基础报价，高收益遗物可能调整报价，拍摄时必须采用实际显示金额。余额不足不应剪成强行扣成负金币；项目实际规则是不自动部分还款，欠款展期计复利。

## 后续可做的三个脚本

| 选题 | 建议时长与画面顺序 | 对应真实规则 |
| --- | --- | --- |
| “本来可以走，我又贪了一枚金币” | 15–20 秒：安全圈就在旁边→回头捡钱→夜色变深、包围加剧→回到撤离圈/真实失败 | 夜幕不会自动结算，进入地堡光圈才撤离。应使用符合时间条件的真实夜战，不把侧后刷怪伪装成捡一枚钱立即触发。 |
| “哥布林：打赢这个，欠款就算了” | 20–25 秒：欠款→合同→强化小 boss→击杀减债或超时加债 | “讨债目标”对应指定强化目标，击杀立即减去报价欠款；到清剿结束未击杀增加同额欠款。胜利和失败可各做一版。 |
| “这份优惠，你真的会签吗？” | 12–18 秒：商店折扣→接受→买到便宜装备→理智减少→停在下一次购买上 | “常客折扣”本局商店价格 -15%，每次付费购买商品理智 -2。让观众讨论具体取舍，比泛泛问游戏好不好玩更有信息。 |

## 制作顺序与发布观察

优先 A（区别于同类）和 B（复用现有素材），再做 C（角色人格化）。第一轮让每条只证明一个机制。

同一主题可分别尝试“结果先出现”和“哥布林先出现”两种开头，中后段尽量相同；它们是实验假设，不是已验证的爆款公式。不要机械地把 7 秒哥布林与 5.05 秒附魔直接拼接成整片开头——那会在实际战斗前消耗 12.05 秒。

手机端先检查槽位、金币变化、角色和目标是否看得清。可分别试横版局部放大、近方形或竖版重新排布，不能从样本推断必须 9:16；本次高互动样本也包括横版与近方形。

发布时写清游戏名、实际支持平台、开发/试玩状态。代码已锁定 Demo 不等于公开可下载，不提前写“现在可玩”。数据允许时观察前段留存、平均观看、完播，以及收藏、主页访问、找游戏/试玩询问；没有后台数据就只记录可见反馈。不要把五条成功样本当成发布时间、粉丝量和题材影响都已排除的实验。
