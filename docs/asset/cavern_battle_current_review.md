## 修改前与 main 概念图的差别（V09 对照记录）

以已经确认的远景高度、较小的远景遗迹和半尺寸前景为前提，目前仍有明显的美术差距。这些主动调整不需要为追求原图一致而退回。

1. **地貌连续性不足。** 概念图中的裸地、苔地、石地互相穿插，共同组成一片地貌。当前底色较均匀，地块仍能看出独立贴花的范围。仅减少种类或放大贴图不能解决这个问题。
2. **材质之间的颜色与明暗差距不足。** 概念图具有明确的青灰底地、紫灰石块、苔绿区域和紫黑阴影。当前多次调暗、透明混合和边缘渐隐叠加，压低了这些区分，产生灰、闷、平的感觉。之前的融合处理过度，需要重新分配局部对比，而不是把整张画面一起提亮。
3. **战斗平面上的物体缺少体量和组合。** 概念图中岩石、断柱、木桩、箱桶成组出现，形成尺度对比与遮挡。当前随机摆件数量少、个体较小，缺乏这样的视觉重心；此处指可见战斗平面的摆件，不是已经缩小的屏幕角落前景。
4. **像素形状的组织不同。** 概念图依靠较大的色块、明确的折线边缘与少量阴影塑造材质。当前部分保留素材细节密集，低透明度和软化边缘又削弱了形状，细节没有形成同样清楚的大块结构。

## 本轮方向的依据

优先重做地面组织，使用保留的四种素材建立较大的连续苔地区域、裸地区域和局部遗迹区，安排有方向的边界与通行留白。透明度应主要用于接缝，主体块面应保留足够的颜色和形状。

然后统一像素颗粒和局部色板，在主界面与选人界面的紫黑阴影、灰绿石材风格内，恢复概念图的材质区分。最后再设计少量战斗平面上的物体组合，用岩石、断柱、箱桶的大小对比补足空间感。

上述方向已在 V10 实施首版。仍保留与原概念图的主动差异：远景高度更低，近景更小，战斗平面的物体更少。地面是可连续行走的程序化布局，局部构图不会与单张手绘概念图逐一相同。
