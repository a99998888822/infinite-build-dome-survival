# 当前精灵显示与碰撞

正式入口为 `scenes/core/game_root.tscn`。世界与 UI 使用 1920×1080 逻辑画布，正常运行不加载碰撞辅助线。

当前源帧、显示尺寸与倍率统一见根目录的[美术清单](../../art_asset_resolution_and_scale_audit.md)。以下单独维护实体碰撞，不用贴图画布代替碰撞边界。

| 对象 | 实体碰撞体 |
| --- | --- |
| 初心者 | 下半身圆形，半径 18，圆心 (0,22.5) |
| 资本家（锁定开局） | 下半身圆形，半径 12，圆心 (0,15) |
| 天外幼体 | 横胶囊，60×26.4，中心 (-0.6,1.2) |
| 回声蝙蝠 | 圆形，半径 9.6，圆心 (2.4,-4.2) |
| 钢甲骑士 | 竖胶囊，48×102，中心 (0,-61.5) |
| 幽焰冥狼 | 竖胶囊，55.2×91.2，中心 (9.6,-45.6) |

初心者 8 个动作配置共用 7 张图集、47 张独立帧；前后跳共用 6 帧，每帧 0.12 秒。选人页与战斗共用待机及移动图集，所有动作保持确认的时序。地面投影缩放 1.8，武器挂点 (4.5,-1.8)，基础移速 140。

玩家地形扫掠和自动位移避让使用实际碰撞体及圆心；敌人身体、吐息挂点、影子和血条随对应体型配置。挑战的额外体型倍率按运行规则叠加。

## 渲染

- 世界 SubViewport 与根画布均为 1920×1080，摄像机 zoom=1，世界容器 scale=1，最近邻采样。
- 只对齐变换，不同时对齐顶点。摄像机位置取整，角色位置、速度及碰撞运算保留浮点数。
- 1080p 窗口下世界像素与屏幕像素一一对应；其他窗口等比适配，小窗口缩小仍可能丢失细线，整数窗口缩放尚未实现。
- CRT、暗角及弹窗背景模糊沿用各自正式用途。

维护时同时核对场景、动画帧表和[命中规则](../main/weapon_contact_rules_2026-10-19.md)。素材重建使用[当前安装工具](../../scripts/tools/ASSET_INSTALLERS.md)。
