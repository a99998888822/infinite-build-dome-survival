# 战斗精灵清晰度调整

2026-09-22：按原来的战斗体型整理像素贴图。2026-09-29 初心者与怪物更新为[新版 Picxel 素材](../../artifacts/previews/combat_picxel_3838180/README.md)；资本家沿用[上一版确认稿](../../artifacts/previews/player_picxel/README.md)。

## 渲染设置

- 世界视口跟随容器尺寸，`stretch_shrink = 1`，采用最近邻采样。
- 原先 `project.godot` 的 `[rendering]` 段误写了 `rendering/2d/snap/...`，实际设置未生效。现在使用 `2d/snap/snap_2d_transforms_to_pixel`，世界 SubViewport 也明确开启位置对齐。
- 只对齐变换，不同时开启顶点对齐，避免把精灵四角分别取整而改变尺寸。
- 摄像机位置取整；角色位置、速度和碰撞运算继续使用浮点数。
- 调整前实测 1152×648 窗口对应 1152×648 世界视口，原代码的 800×450 只是初始值，不是实际固定渲染分辨率。
- CRT 扫描线、暗角及弹窗背景模糊维持原有用途。

## 战斗专用贴图

战斗场景和玩家动画引用各自 `combat/` 目录里的素材。下表的原尺寸为改造前记录；玩家与怪物使用 Picxel 成品，过期正式图和旧重建输入已删除，用户提供的高清原图与可编辑像素稿保留：

| 素材 | 原画布和缩放 | 战斗画布和缩放 |
|---|---|---|

这些尺寸包含透明留白。玩家现从 64×64 像素稿移除四周透明留白导出，完整保留四肢和持物；碰撞形状、拾取范围和武器锚点保持原值。

- 玩家每角色共用最多 16 色色板；硬透明，无抖色或半透明杂边。
- 玩家待机与行走帧脚底统一在 y=52（不含该行）。
- 玩家和怪物保留审阅稿的材质轮廓；不在安装时重新缩放或描边。
- 每个主体最多 16 色；场景不施加暗绿色染色。
- 怪物受击亮度短暂提升至 1.35，再恢复原色，保留取消染色后的受击反馈。
- 导入使用无损压缩，不生成 mipmap。

## 重新生成

安装 Pillow 后，在仓库根目录运行：

```powershell
python scripts/tools/build_combat_sprites.py
```

该命令从已确认 Picxel 导出安装两角色与怪物，同时重建匹配 Boss 动画的帧表。运行 `python scripts/tools/install_combat_picxel_assets.py --check` 仅校验正式贴图哈希、格式与 Boss 帧表。修改像素稿后先重新导出审阅包，再安装并由 Godot 导入。
