## 渲染设置

- 世界 SubViewport 固定为 1920×1080，摄像机 zoom=1，`stretch_shrink = 1`，采用最近邻采样。HUD 继续使用 1152×648 设计画布；`project.godot` 中该尺寸不代表世界渲染分辨率。
- 原先 `project.godot` 的 `[rendering]` 段误写了 `rendering/2d/snap/...`，实际设置未生效。现在使用 `2d/snap/snap_2d_transforms_to_pixel`，世界 SubViewport 也明确开启位置对齐。
- 只对齐变换，不同时开启顶点对齐，避免把精灵四角分别取整而改变尺寸。
- 摄像机位置取整；角色位置、速度和碰撞运算继续使用浮点数。
- 1920×1080 窗口下，世界像素与屏幕像素一一对应。其他窗口等比适配，保持世界视野；小于 1080p 时仍可能因缩小丢失细线。整数缩放选项尚未实现。
- CRT 扫描线、暗角及弹窗背景模糊维持原有用途。

## 重新生成

安装 Pillow 后，在仓库根目录运行：

```powershell
python scripts/tools/build_combat_sprites.py
```

该命令默认仅校验当前正式贴图的尺寸、色板、透明度与 Boss 帧表。安装新成品需显式传入 `--source <目录>`，输入目录布局与 `assets/` 一致；安装时核对复制前后的哈希。原审阅包已删除，工具不再依赖它。详见[素材安装工具说明](../../scripts/tools/ASSET_INSTALLERS.md)。
