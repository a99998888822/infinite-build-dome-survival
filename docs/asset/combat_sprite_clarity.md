# 战斗精灵清晰度调整

2026-09-22：沿用现有玩家与天外幼体造型，按原来的战斗体型整理像素贴图。

## 渲染设置

- 世界视口跟随容器尺寸，`stretch_shrink = 1`，采用最近邻采样。
- 原先 `project.godot` 的 `[rendering]` 段误写了 `rendering/2d/snap/...`，实际设置未生效。现在使用 `2d/snap/snap_2d_transforms_to_pixel`，世界 SubViewport 也明确开启位置对齐。
- 只对齐变换，不同时开启顶点对齐，避免把精灵四角分别取整而改变尺寸。
- 摄像机位置取整；角色位置、速度和碰撞运算继续使用浮点数。
- 调整前实测 1152×648 窗口对应 1152×648 世界视口，原代码的 800×450 只是初始值，不是实际固定渲染分辨率。
- CRT 扫描线、暗角及弹窗背景模糊维持原有用途。

## 战斗专用贴图

原始高分辨率素材保留。战斗场景和玩家动画改为引用各自 `combat/` 目录里的派生素材：

| 素材 | 原画布和缩放 | 战斗画布和缩放 |
|---|---|---|
| 玩家待机 | 256×256，0.21 倍 | 54×54，1 倍 |
| 玩家行走 | 1024×256，4 帧，0.21 倍 | 216×54，4 帧，1 倍 |
| 天外幼体待机 | 128×128，0.675 倍 | 86×86，1 倍 |
| 天外幼体移动 | 384×128，3 帧，0.675 倍 | 258×86，3 帧，1 倍 |

这些尺寸包含透明留白。主体大小基本保持，仅新增一像素轮廓边；碰撞形状、拾取范围和武器锚点保持原值。

- 玩家全部帧共用 32 色色板，另加轮廓色；硬透明，无抖色或半透明杂边。
- 玩家待机与行走帧的脚底／阴影末行对齐。
- 两类精灵使用同一轮廓色、一像素四邻域外轮廓。
- 怪物保留原来的 20 色，移除场景中的暗绿色染色，提高与湿地背景的区分度。
- 怪物受击亮度短暂提升至 1.35，再恢复原色，保留取消染色后的受击反馈。
- 导入使用无损压缩，不生成 mipmap。

## 重新生成

安装 Pillow 后，在仓库根目录运行：

```powershell
python scripts/tools/build_combat_sprites.py
```

生成过程可重复；源素材的帧数或尺寸改变时会报错，避免静默裁错。随后用 Godot 导入新素材。
