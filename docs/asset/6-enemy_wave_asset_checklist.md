# 敌人与波次模块素材 Checklist

本文档用于记录“敌人与波次模块”需要准备的图片素材、提示词、目标规格、最终放置路径与当前状态。当前阶段只要求满足 MVP：普通敌人能显示、经验球能显示、血包可显示。所有提示词均为中文单提示词，可直接复制到豆包、Ludo.ai 或类似 AI 素材工具中使用。

## 1. 统一美术规范

| 项目 | 约定 |
|---|---|
| 画风 | 清新、干净、轻微可爱、克苏鲁轻幻想、中高精度像素风 |
| 氛围 | 可带黄昏、夜晚、穹顶外迷雾感，但不要肮脏、噪点、腐烂、过度恐怖 |
| 敌人设计 | 轮廓清楚，体型小，怪物感明显但不要恶心血腥 |
| 方向规则 | MVP 敌人可只做右向单帧，左向由 Godot 翻转 |
| 背景要求 | 游戏内精灵必须透明背景 |
| 文件格式 | PNG，透明背景，禁止 JPG 用于正式游戏素材 |

## 5. Godot 导入约定

1. 敌人单帧建议 `128x128` 或 `256x256`，透明背景。
2. 拾取物建议 `64x64` 或 `128x128`，透明背景。
3. 动画帧表必须等宽等高，不混放多个动作。
4. 当前 MVP 允许先用单帧和代码占位，正式素材后续替换。

## 6. 状态字段说明

| 状态 | 含义 |
|---|---|
| 未存在 | 还没有生成或未放入目标路径 |
| 已存在 | 文件已放入目标路径，等待 Godot 导入验证 |
| 已接入 | 已在 Godot 场景或脚本中使用 |
| 可暂空 | 非 MVP 必需，可以后续补 |
| 需重出 | 已有图片但规格不适合工程使用，建议重新生成 |
