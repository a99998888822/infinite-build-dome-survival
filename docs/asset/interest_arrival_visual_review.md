# 利息逐项到账演出

已接入正式理财界面。演出只读取波末已经完成的结算记录，不改变收益公式、遗物触发概率，也不会再次发放金币。

## 展示与操作

- 依次显示基础利息、分红倍率、额外结息、理智折损和利率成长；遗物加成附带实际来源图标。不再显示“小数结转”“小数留存至后续结息”等条目。
- 结算框按整个游戏窗口水平、垂直居中，大小窗口均适配；金币金额显示整数，利率成长显示实际数值，例如“复利宝典 · 利率成长 +0.2%”。同一遗物在本波多次触发时合并增长值，两次各+0.2%显示+0.4%。
- 删除本金与起始/最终利率摘要、利率变化箭头、“应收利息 · 结算中”和“本次到账 0 金币”。基础明细简化为“基础利息 +金额”；结算后正收益只显示“实际到账”。本金、利率详情仍可在银行摘要和日志中查看。
- 条件未满足的预留提示不再进入演出；结算失败统一简化为“本次未结息”。删除摘要后，窗口高度及内容位置同步收紧。
- 实际结算仍保留原有精度与小数累计。展示的整金币折损按应收总额减实际到账额计算，使各项整数与最终到账一致。
- 核算阶段只滚动金额，结束后显示实际到账整数，金币飞向理财界面的余额栏。
- 对比本波战斗金币和利息；到账后提示本波利息可负担的在售商品（存在符合条件的商品时）。
- 普通单笔结息动画约1秒，多项加成约1.8秒；动画结束后保留最终账单，直到点击或按Esc关闭，仍兼容空格、回车。Esc优先关闭账单，当次按键不会打开遗物清单或取消哥布林交易。
- 每次结算按运行实例、本局序号和波次标识，只演出一次。重新打开、刷新商店、调整窗口不会重播；新一局可正常播放。
- 哥布林交易仍与银行界面同时出现，条款完整显示、按钮立即启用；只有哥布林对话逐字播放。居中结算框优先显示，点击框内仅跳过演出，不穿透点击后方控件；框外操作不受拦截。中途关闭理财界面会停止演出并取消未接受的交易。
- 无本金时不播放到账庆祝；折损后实际到账为0时显示0，不播放金币飞入效果。
- 面板按条目数量自适应高度，640×360窗口中的长记录自动滚动到当前条目。

## 音效

新增三段实际存在的PCM素材：`interest_tick.wav`、`interest_bonus.wav`、`interest_arrive.wav`，分别用于逐项金币轻响、翻倍提示和最终到账。均使用SFX总线，中途退出会停止本组件音效。

生成脚本：`scripts/tools/build_interest_arrival_audio.py`。旧结算界面引用的部分OGG文件并不存在，本演出使用独立的新素材。

## 实际录制

当前等待关闭行为见 `artifacts/reviews/ui/wave_pressure/interest_hold.gif`：结算后等待9秒仍显示，Esc关闭后返回银行。自动结束版录像及重复完整静帧已清理；小窗口多项加成明细样例合并到同一目录。

录制通过正式游戏场景与结算代码运行，测试夹具设置本金1000、起始利率8%、本波战斗收入120，装备分红支票、复利宝典和永续年金。固定测试随机种子让第一笔翻倍、第二笔不翻倍；正式游戏的20%触发概率未修改。

- `artifacts/reviews/ui/wave_pressure/receipt_small.png`：640×360窗口静帧；理智50，80基础利息、80翻倍增益、82额外结息、81整数折损，实际到账161；复利宝典累计成长+0.4%。

只保留当前手动关闭动图与上述小窗口样例。测试场景与组装脚本仍可重建录制，请将原始帧输出到系统临时目录。

当前动图由每隔1秒的实际视口截图组成，关闭画面额外停留2秒；用于核对弹窗等待行为。GIF不含声音，游戏内同时播放对应音效。
