# 钢甲骑士小 Boss：正式接入

更新：2026-10-04，已将完整动画替换为用户确认的 256px、16 色清理版。沿用 `enemy_elite_rusher` ID 与 `EliteRusher` 类，展示名为“钢甲骑士”。本轮素材与备份见[接入记录](art_refresh_plan/knight_256_installation_2026-10-04.md)。

## 资源与配置

正式资源位于 `assets/sprites/enemies/iron_knight/`，待机1、移动7、蓄力7、冲刺挥锤2、收招1。共17张唯一帧，每帧256×256，整组共用16色色板，硬透明PNG与深色描边。idle取移动第1帧，与已确认清理样例逐像素相同；移动10FPS。攻击原图第1–7帧用于蓄力、第8–9帧用于冲刺、第10帧用于收招，按实际技能持续时间播放。当前源图第3帧锤头左侧裁切已在审阅时说明；收招保持第10帧，再由现有状态机切回待机，没有合成返回姿势。死亡仍冻结当前图像并在0.2秒内淡出。

场景使用审阅版的0.56显示比例与半径33.6的身体碰撞体，按256px画布的 `(128,221)` 脚底参考锚点将 `Sprite2D` 偏移设为 `(0,-52.08)`。比例补偿贴图由128升级到256，保留审阅时的世界显示大小。移动和攻击共用尺寸、缩放与落脚基线；砸地帧的锤头可低于鞋底。技能动画按实际技能时钟映射到帧表，暂停和短控制同时暂停动作。

| 参数 | 当前值 |
| --- | --- |
| 起手距离 | 玩家中心距 ≤ `dash_distance`，当前 240 |
| 起手条件 | 存活、追赶状态、目标存活、冷却就绪，并保留多精英起手错峰 |
| 蓄力预警 | 1000 毫秒（2026-10-05 调整为原 400 毫秒的 2.5 倍）；起手后锁定方向 |
| 冲刺与挥锤 | 160 毫秒；240 距离对应 1500 单位/秒 |
| 收招 / 冷却 | 500 / 6000 毫秒 |
| 预警内部不透明度 | 12% |
| 两条长边不透明度 | 42%～55% 脉动 |
| 边缘方粒不透明度 | 48%～60% 脉动 |

预警是无箭头、无圆角的矩形，由实际冲刺距离与半宽生成；图层在角色下方绘制。透明度百分比与时间都读取 `enemies.json` 的 `elite_profile`。距离不够时继续追赶，不消耗冷却，也不原地停住。

冲刺伤害检测覆盖每次移动的整段范围，支持玩家实际胶囊碰撞体和圆形碰撞体，包括碰撞节点的偏移与旋转；每次冲刺只尝试命中一次。撞墙或撞人后停止位移，挥锤在剩余的 160 毫秒技能时间内完成，再进入收招。

生命、护甲、侵蚀加成、每波小 Boss 数量和前半波生成规则沿用现有配置。首个遗物选择奖励基础掉落 100%，落地即计入后续掉落衰减；近距离拾取与波末收取沿用现有奖励链路。

## 制作与验证入口

```text
python scripts/tools/build_iron_knight_review.py
python -B scripts/tools/install_iron_knight_assets.py
```

第一条从当前正式 Boss 图集生成临时逐帧对照图。第二条默认只校验五张正式贴图和 `SpriteFrames`；安装新素材需传入 `--source <目录>`。工具不依赖历史审阅包；本轮原图位置与审阅产物清理说明见接入记录。输入目录与使用方法见[素材安装工具说明](../../scripts/tools/ASSET_INSTALLERS.md)。

专项场景为 `scenes/tests/iron_knight_test.tscn`，检查距离边界、远处继续追赶、冷却、方向锁定、动画同步、160 毫秒位移、胶囊擦边命中与落空、低帧率扫掠、暂停/冻结和障碍阻挡。联动回归使用 `elite_relic_decay_test`、`elite_effect_revision_test`、`erosion_pressure_test`。测试与录像通过 `-- --transient-session` 避免写入正式营地存档。

实机录像使用 `scenes/tests/iron_knight_live_capture.tscn`，它启动正式 `GameRoot` 和战斗场景，通过现有 `WaveManager` 生成骑士。录制时固定刷怪环境并脚本控制玩家侧移、终结骑士；怪物 AI、动画、碰撞和奖励均使用正式实现，原始视口帧写入系统临时目录。
