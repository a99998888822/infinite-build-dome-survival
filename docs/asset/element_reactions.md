# 元素联动与像素反馈

2026-09-23，根据元素关系图修正。已接入正式战斗代码，图像和动图供审阅；未改动既有 PNG 素材。

## 本版规则

- 水与普通燃烧双向蒸发：消除参与反应的状态，额外造成原始元素基础伤害的 1.5 倍。暗炎遇水保留，但仍有蒸发伤害。
- 水与结霜双向冻结：消耗打湿和结霜减速，冻结 1 秒。图中冰冻返回打湿的箭头，本版解释为解冻后恢复 5 秒打湿；解冻水仍经过反应入口。普通非元素冻结不自动返湿。
- 光与燃烧双向形成圣焰：燃烧总伤害为普通燃烧的 2 倍，不再次叠乘感光。其他直接命中仍可受感光加倍，圣焰期间不消耗感光。
- 暗与燃烧双向形成 10 秒暗炎。火焰变体互斥，避免同时标记圣焰与暗炎。暗的停止移动行为保留本版之前的规则。
- 电击消耗打湿，并对同一目标补一次电击，不增加导电跳数。闪电、电火花采用同一口径。电击命中燃烧会引爆并清除燃烧，包括电火花首击致死的情况。
- 光暗双向抵消，抵消后不保留新的相反状态；播放收拢消散反馈。
- 冻结与感光共存时触发光反射。反应入口统一处理；同次冻结与感光的重复刷新不重复创建光束。
- 风传播水也经过反应入口，因此可以蒸发燃烧、冻结结霜目标并触发光冰反射。传播上限为 0 时不传播。
- 冰域持续存在，每名敌人在该冰域首次接触时受到一次伤害与冰状态；后来进入或被风扩大覆盖的目标也有效。同一冰域不反复伤害已命中目标。
- 风最多将冰域扩大至其初始半径的 2 倍，已有更大范围不会缩小。火池吸收新火种或再次被风影响时也不会意外缩小。
- 连锁主宰改为额外连接 1 个目标，伤害提高 **20%**。20% 是本版待审阅的平衡值。基础闪电命中 2 个目标，装备后命中 3 个；`chain_count` 表示初始目标之后的额外目标数，控制强度继续参与加成。

## 结算与参数

附魔基础参数及随机词条仅合并到其 `effect_ids` 所属效果；明确的通用修饰器仍跨效果生效。附魔排列不再通过同名参数意外覆盖水流、黑洞等其他效果。

水流在命中分发时立即结算，随后生成的冰域可看到打湿状态。光辉剑仅在落地时处理光状态；先结算剑的落地伤害，再为没有暗状态的幸存目标附加感光。黑洞也由自身范围效果附加暗，移除命中分发中的重复施加。

战斗延迟任务、闪电回声和麻痹视觉跟随战斗暂停。`EffectScheduler.schedule` 的第四个参数可供需要在暂停时继续运行的 UI 任务显式启用；默认任务暂停。反应爆炸使用独立上下文，不被武器上普通爆炸附魔的基础参数覆盖。

## 视觉

新增独立、仅负责绘制的 `element_reaction_visual.gd`：蒸发、冻结、解冻、圣焰转化、暗炎转化、光暗抵消、导电、水花传播、冰域扩展、电火爆炸。

经第一轮审阅后，进一步强化每种反应的代表性，数值与联动规则沿用上一版：

| 反应 | 视觉特征 |
|---|---|
| 蒸发 | 三股带有气旋的翻卷白汽，向上展开 |
| 冻结／解冻 | 透明棱面冰壳与冰刺；解冻时碎晶落下并出现水波 |
| 圣焰 | 向上升腾的金白火冠、转化星芒与持续白金火舌 |
| 暗炎 | 向内卷曲的黑紫火舌，转化瞬间短暂出现邪眼 |
| 光暗抵消 | 明暗双弧相向收拢，压成细缝后消散 |
| 导电 | 跳动的青蓝电网，脚边电流分叉 |
| 电火爆炸 | 锯齿橙焰与内部黄白电弧 |
| 风水传播 | 定向蓝色水带、白色浪花及落点水滴 |
| 风扩冰域 | 树枝状霜纹向外生长，边缘出现棱状冰晶 |
| 光冰反射 | 晶体折射起点、白芯光束及青紫金窄边 |

绘制共用 `reaction_pixel_shapes.gd` 中的冰棱、火舌、星芒与邪眼轮廓。状态图形按 12 fps 更新；状态发生变化时立即重绘，避免重复生成相同像素轮廓。密集反应降低装饰和透明度。冰壳中心保持透明，火焰主要布置在身体两侧。原有球体黑洞、光剑本体及横向裂缝、水流主体、风刃主体保持。

反应反馈单独限制为最多 96 个短时节点，相邻同类同时反馈合并，密集时减少装饰；状态图形独立绘制，不占公共粒子预算。公共粒子上限 900，火焰和弹道尾迹为命中反馈预留 180 个位置。任何视觉减量均不跳过伤害或状态计算。冰域、水流、光剑和爆炸查询不再固定截断到 64 个敌人。
