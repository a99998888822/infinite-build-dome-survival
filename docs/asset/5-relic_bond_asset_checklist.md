# 局内遗物与羁绊模块素材 Checklist

本文档用于记录“局内遗物与羁绊模块”在设计阶段需要准备的图片素材、提示词、目标规格、最终放置路径与当前状态。当前阶段只要求满足 MVP：遗物奖励界面能显示、羁绊面板能显示、遗物图标能识别。遗物奖励卡片不再单独制作卡底 PNG，统一复用第九模块的 `scenes/ui/rewards/reward_option.tscn` 节点 prefab。所有提示词均为中文单提示词，可直接复制到 Ludo.ai 或类似 AI 素材工具中使用。

## 1. 统一美术规范

| 项目 | 约定 |
|---|---|
| 画风 | 清新、干净、轻微可爱、克苏鲁轻幻想、像素风但不要低像素粗糙感 |
| 氛围 | 可以是黄昏、夜晚、昏暗穹顶氛围，但不要肮脏、噪点、腐烂、过度恐怖 |
| 遗物表现 | 每个遗物都要有明显轮廓和主题物件，小尺寸下可识别 |
| 羁绊表现 | 羁绊图标或徽记要简洁，便于在 UI 面板中展示层数 |
| 背景要求 | 图标类素材必须透明背景 |
| 文件格式 | PNG，优先透明背景，禁止 JPG 用于正式游戏素材 |

## 5. Godot 导入约定

1. 遗物图标统一使用 `128x128` 或 `256x256` PNG，透明背景。
2. 羁绊徽记统一使用 `128x128` PNG，便于在 UI 面板中缩放。
3. 遗物奖励卡面统一复用第九模块 `reward_option.tscn`，MVP 阶段不需要单独卡底图。
4. 当前 MVP 只要求遗物图标可用，羁绊徽记可暂空。

## 6. 状态字段说明

| 状态 | 含义 |
|---|---|
| 未存在 | 还没有生成或未放入目标路径 |
| 已存在 | 文件已放入目标路径，等待 Godot 导入验证 |
| 已接入 | 已在 Godot 场景或脚本中使用 |
| 可暂空 | 非 MVP 必需，可以后续补 |
| 需重出 | 已有图片但规格不适合工程使用，建议重新生成 |
