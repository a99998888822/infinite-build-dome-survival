# 局内武器模块素材生成 Checklist

本文档用于记录“局内武器模块”在设计阶段需要准备的图片素材、生成提示词、目标规格、放置路径与当前状态。当前阶段只要求满足 MVP：武器图标可显示、远程投射物可显示、近战/范围效果可用占位。所有提示词均为中文单提示词，可直接复制到 Ludo.ai 或类似 AI 素材工具中使用。

## 1. 统一美术规范

| 项目 | 约定 |
|---|---|
| 画风 | 清新、干净、轻微可爱、克苏鲁轻幻想、像素风但不要低像素粗糙感 |
| 氛围 | 可以有黄昏、夜晚、穹顶、虚空、星光元素，但不要肮脏、噪点、腐烂、血腥 |
| 武器造型 | 轮廓清晰、简单易读，不做过度复杂机械结构 |
| 像素精度 | 中高精度像素风，适合 Godot 2D 俯视/侧俯视表现 |
| 背景要求 | 游戏内精灵、投射物、特效必须透明背景；图标可透明背景 |
| 文件格式 | PNG，优先透明背景，禁止 JPG 用于正式游戏素材 |
| 朝向规则 | `icon` 可保持中性朝向；远程投射物统一按右向制作；近战挥砍特效统一按右向半圆/弧形制作；范围伤害特效统一按圆形制作 |
| 图标规格 | 建议 `128x128`，正方形，武器居中，边缘留白 |
| 投射物规格 | 建议 `64x64` 或 `128x128`，透明背景，朝右，后续由 Godot 旋转 |
| 特效规格 | 建议 `256x256`，透明背景，中心点居中，方便以玩家为中心播放 |

## 5. Godot 导入与裁剪约定

1. 图标统一使用 `128x128` PNG，透明背景。
2. 投射物默认朝右制作，在 Godot 中根据飞行方向旋转。
3. 近战和范围特效以画面中心为中心点，方便以玩家为中心播放。
4. 特效图可以先用单帧，后续如需动画再扩展为 spritesheet。
5. 多帧特效 spritesheet 必须等宽等高，不混放多个动作。
6. 当前 MVP 可以先只接图标和投射物，近战/范围特效可暂空。

## 6. 状态字段说明

| 状态 | 含义 |
|---|---|
| 未存在 | 还没有生成或未放入目标路径 |
| 已存在 | 文件已放入目标路径，等待 Godot 导入验证 |
| 已接入 | 已在 Godot 场景或脚本中使用 |
| 可暂空 | 非 MVP 必需，可以后续补 |
| 需重出 | 已有图片但规格不适合工程使用，建议重新生成 |
