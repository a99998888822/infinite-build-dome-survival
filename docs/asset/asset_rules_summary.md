# 当前素材规范

正式运行资源放在 `assets/`。编辑时以已确认素材、实际图集切分和场景显示契约为准，保持造型、帧序与动作时长。新图片使用项目的外部图片像素化流程；源图、可编辑网格和最终 PNG 分别保留来源关系。

## 图标

| 类型 | 当前源尺寸 | 显示规则 |
| --- | --- | --- |
| 武器 | 14 张主图和 1 张返程状态图，36×36 | Esc、商店、奖励、百科 72×72；工作台、选人、鼠标、伤害统计 36×36；战斗栏按可用宽度使用 72 或 36 并换行。 |
| 遗物 | 101 张，36×36，最多 14 色 | 奖励、Esc、百科 72×72；商店、选人 36×36；保留确认构图，主体最长边通常为 30～34px。 |
| 附魔 | 19 张，32×32 | Esc 物品栏 64×64；选人、背包、工作台槽位、掉落、拖拽、武器说明和出售返还 32×32。 |

以上均使用最近邻采样，正式 PNG 与同名 PXG、PAL 同步。逐件路径、当前尺寸、哈希及原图裁切信息见 [icon_manifest.json](icon_manifest.json)。

## 角色、敌人与特效

初心者使用 96×96 帧、共用 16 色，8 个动作配置共用 7 张图集、47 张独立帧。前后跳共用 6 帧，每帧 0.12 秒。动作偏移统一为 (0,3)，与基础偏移合计 (0,-3)。其他角色和敌人的原始尺寸、显示比例与碰撞见[精灵规范](combat_sprite_clarity.md)。

轮廓使用清晰的大色块和阶梯边缘，细碎颗粒只作辅助。武器与附魔效果沿用已确认的图集或代码绘制入口，见[特效说明](combat_effects.md)。素材显示比例与伤害几何分开配置，作用区遵守[命中规则](../main/weapon_contact_rules_2026-10-19.md)。

## 导入与维护

- 世界和 UI 以 1920×1080 为逻辑画布，位置对齐像素，运动及碰撞保留浮点精度。窗口适配见[HUD 坐标约定](../main/hud_native_1920.md)。
- 保留现有无损、最近邻和透明度约定；不要用旧版本生成器覆盖当前 PNG 或可编辑源。
- 图集调整必须同步 `.tres` 帧表、动画配置与场景挂点。播放时序和碰撞体不能仅凭图片画布大小推断。
- 音频维护于 `assets/audio/`，播放事件由正式音频配置和脚本决定，不套用旧规划中的缺失或停播清单。
- 素材检查、重建与安装入口见[安装工具](../../scripts/tools/ASSET_INSTALLERS.md)。自动实机验证使用私有桌面后台工具。

原图位于 `artifacts/sources/`、`artifacts/reference/`，最终画面位于 `assets/`；正式图标旁已有的网格和色板保留，不再额外归档分帧稿及处理目录。配置中迁出的图标描述、建筑定位和地表追溯资料见 [config_reference_metadata.json](config_reference_metadata.json)，素材审阅工具仍读取此文件。
