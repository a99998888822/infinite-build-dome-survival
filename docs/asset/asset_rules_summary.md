# 素材规则汇总

> 本文档汇总原分模块 asset checklist 中的美术规范、Godot 导入约定、复用规则和不制作决策。
> 具体素材条目、路径、尺寸和提示词以 `docs/asset/asset_checklist_summary.md` 为唯一来源。

## 玩家与角色模块素材生成 Checklist

### 1. 统一美术规范

| 项目 | 约定 |
|---|---|
| 画风 | 清新、干净、轻微可爱、克苏鲁轻幻想、像素风但不要低像素粗糙感 |
| 氛围 | 可以是黄昏、夜晚、昏暗穹顶氛围，但不要肮脏、噪点、腐烂、过度恐怖 |
| 角色比例 | 简单小人，头身比偏可爱，轮廓清晰，装备不要复杂 |
| 像素精度 | 中高精度像素风，建议单帧角色有效像素感接近 64x64 或更高 |
| 背景要求 | 精灵图必须透明背景；角色选择立绘可透明或纯净浅色背景 |
| 朝向规则 | 只制作向右；向左由 Godot 水平翻转；暂不制作向上、向下动画 |
| 动画规则 | 先生成向右单帧，再基于单帧生成向右行走帧表 |
| 裁剪规则 | 动画帧表必须等宽等高网格，建议 6 帧 x 1 行，每帧 256x256，整图 1536x256，透明背景 |
| 锚点规则 | 每帧角色脚底位置一致，角色居中略偏下，避免走路时上下跳动过大 |
| 文件格式 | PNG，优先透明背景，禁止 JPG 用于正式游戏素材 |

### 4. 已生成素材检查记录

| 文件 | 当前检查结果 | 建议 |
|---|---|---|
| `assets/sprites/player/player_void_hunter_right_base.png` | 已存在，尺寸 256x256，透明背景正常，风格可用 | 作为基础单帧可直接使用 |
| `assets/sprites/player/player_void_hunter_walk_right_spritesheet.png` | 已存在，尺寸 1024x256，透明背景，当前为 4 帧版本 | 可用，后续若要严格 6 帧可再重出 |

### 5. Godot 导入与裁剪约定

1. 正式动画帧表必须是透明 PNG。
2. 每个动画使用单独 spritesheet，不混放多个动作。
3. 行走动画使用 `6 帧 x 1 行`，每帧 `256x256`。
4. 待机动画使用 `4 帧 x 1 行`，每帧 `256x256`。
5. Godot 中使用 `AnimatedSprite2D` 或 `SpriteFrames` 时，按固定网格导入。
6. 玩家向左移动时不需要独立图片，直接对显示节点设置水平翻转。
7. 若后续缩小实际显示尺寸，应在 Godot 中统一缩放，不要让每张源图尺寸不同。

## 局内武器模块素材生成 Checklist

### 1. 统一美术规范

| 项目 | 约定 |
|---|---|
| 画风 | 清新、干净、轻微可爱、克苏鲁轻幻想、像素风但不要低像素粗糙感 |
| 氛围 | 可以有黄昏、夜晚、穹顶、虚空、星光元素，但不要肮脏、噪点、腐烂、血腥 |
| 武器造型 | 轮廓清晰、简单易读，不做过度复杂机械结构 |
| 像素精度 | 中高精度像素风，适合 Godot 2D 俯视/侧俯视表现 |
| 背景要求 | 游戏内精灵、投射物、特效必须透明背景；图标可透明背景 |
| 文件格式 | PNG，优先透明背景，禁止 JPG 用于正式游戏素材 |
| 朝向规则 | `icon` 可保持中性朝向；远程投射物统一按右向制作；近战挥砍特效统一按右向半圆/弧形制作；范围伤害特效统一按圆形制作 |
| 图标规格 | 建议 `128x128`，正方形，武器居中，边缘留白 |
| 投射物规格 | 建议 `64x64` 或 `128x128`，透明背景，朝右，后续由 Godot 旋转 |
| 特效规格 | 建议 `256x256`，透明背景，中心点居中，方便以玩家为中心播放 |

### 5. Godot 导入与裁剪约定

1. 图标统一使用 `128x128` PNG，透明背景。
2. 投射物默认朝右制作，在 Godot 中根据飞行方向旋转。
3. 近战和范围特效以画面中心为中心点，方便以玩家为中心播放。
4. 特效图可以先用单帧，后续如需动画再扩展为 spritesheet。
5. 多帧特效 spritesheet 必须等宽等高，不混放多个动作。
6. 当前 MVP 可以先只接图标和投射物，近战/范围特效可暂空。

## 局外营地与成长模块素材 Checklist

> 注：`camp_armory_workshop`、`camp_relic_archive`、`camp_dome_shelter` 等初始自带建筑不需要废墟图，只保留正式建筑素材；其余 5 个需要同时准备废墟图和正式建筑图。

### 1. 统一美术要求

| 项目 | 约定 |
|---|---|
| 画风 | 清新、像素风、像素精度中高、氛围偏黄昏/夜晚但不脏乱 |
| 场景 | 森林 + 篝火 + 河流，整体安静、温和、略带奇幻感 |
| 场景组织 | 营地场景采用分层素材拼装，不要求单张底图 |
| 背景 | 需要透明度或可叠加到场景图层，便于 Godot 组合 |
| 格式 | PNG，优先透明背景 |
| 命名 | 全部使用 snake_case，小写英文 |

### 4. Godot 导入约定

1. 场景底图由多层素材拼装，不依赖单张大底图。
2. 每个建筑素材保持独立 PNG，便于单独替换。
3. 未解锁与已解锁素材文件名必须一一对应，方便脚本按 ID 拼接路径。
4. 初始自带建筑只保留正式建筑素材，不需要废墟图。
5. 后续如果你再改建筑，只需要替换对应 PNG，不需要改这份清单结构。

## 音频与氛围表现模块素材 Checklist

### 1. 统一音频规范

| 项目 | 约定 |
|---|---|
| 整体风格 | 清新、克制、轻微神秘，不使用脏乱、刺耳或过度恐怖的声音 |
| BGM 格式 | OGG，立体声，支持无缝循环 |
| 命中音效格式 | OGG 或 WAV，短促干净，建议不超过 1 秒 |
| 采样率 | 建议 44.1kHz |
| 命名 | 小写英文、数字和下划线，不使用空格和中文 |
| 缺失处理 | 文件不存在时静默处理，不影响战斗 |

6. UI 确认、取消和错误音效。
7. 建筑升级、商店刷新和奖励获得音效。
8. 森林、河流、篝火、夜晚、低语等环境氛围音。
9. 白、绿、蓝、紫、橙、红稀有度提示音。
