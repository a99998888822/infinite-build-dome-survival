# UI 交互模块素材生成 Checklist

本文档用于记录“UI 交互模块”在设计阶段需要准备的图片素材、生成提示词、目标规格、放置路径与当前状态。当前阶段只要求满足 MVP：战斗 HUD、共享奖励/商店页、营地主界面、建筑详情面板、简单暂停菜单。升级免费奖励入口和波次结束商店入口共用同一套页面结构，结算标题直接用文本显示，不再单独制作横幅素材。大面板优先交给 Godot `Control` 节点、`Theme` 与 `StyleBoxFlat` 实现，不再单独生成底板 PNG。营地建筑本体素材沿用第七模块清单，不在此重复生成。

## 1. 统一美术规范

| 项目 | 约定 |
|---|---|
| 画风 | 清晰、干净、轻克苏鲁、像素风但不要粗糙糊边，整体偏克制，不做惊悚血腥 |
| UI 风格 | 偏功能性，轮廓清楚，小尺寸可读，适合 HUD、按钮、弹窗、卡片 |
| 背景要求 | 图标优先透明背景；大面板优先用 Godot `Theme` / `StyleBoxFlat` 绘制半透明底、边框和圆角 |
| 图标规格 | 建议 64x64 或 128x128，正方形，居中留白 |
| 面板规格 | MVP 阶段不要求面板 PNG；如后续补充美术底图，再按 512x512、768x512 或 1024x1024 制作九宫格素材 |
| 状态提示 | 锁定、选中、禁用、鼠标悬停态尽量独立处理，避免只靠文字区分 |
| 文件格式 | PNG，优先透明背景，禁止 JPG 用于正式游戏素材 |
| 命名规则 | 全部使用 snake_case，小写英文，方便 Godot 资源管理 |

## 5. Godot 导入与裁剪约定

1. 所有 UI 图标统一使用透明 PNG。
2. MVP 阶段通用面板优先由 Godot `PanelContainer` + `StyleBoxFlat` 绘制，不依赖底板 PNG。
3. HUD 图标与按钮图标应在 64x64 下仍可识别。
4. 弹窗底板优先做成可复用主题组件，不要为每个弹窗单独做一套完全不同的外框。
5. 建筑本体素材直接复用第七模块，不在 UI 模块里重复分叉命名。

## 6. 状态字段说明

| 状态 | 含义 |
|---|---|
| 未存在 | 还没有生成或未放入目标路径 |
| 已存在 | 文件已放入目标路径，等待 Godot 导入验证 |
| 已接入 | 已在 Godot 场景或脚本中使用 |
| 可暂空 | 非 MVP 必需，可以后续补 |
| 节点实现 | 不需要单独图片文件，直接用 Godot 节点、主题或脚本绘制 |
| 需重出 | 已有图片但规格不适合工程使用，建议重新生成 |
