## 尺寸与层次

64×64 是素材画布，不是游戏里的物体尺寸。`BattleSceneryCatalog` 使用 AtlasTexture 裁取可见内容，再按可见长边统一缩放，保持纵横比。本轮重新测量全部 PNG 的透明边界，并保持每项 `world_extent` 不变；地面锚点和远景入水边界沿用现有逻辑。

| 用途 | 近处可见长边，世界单位 |
| --- | --- |
| 普通苔藓 | 20 / 26 / 32 |
| 单砖 / 叠砖 / 碎砖 | 44 / 62 / 80 |
| 碎石与石堆 | 76—86 |
| 裂痕及覆苔裂痕 | 72—98 |
| 湿地斑 / 浅水洼 | 104 / 96 |
| 水纹动画 | 扩散至约 52，沿用原有物理尺度 |

地面尺寸有 0.90—1.08 倍的小幅个体差异。同一深度下，最大的普通苔藓仍小于最小的单砖。覆苔放射裂痕属于裂痕组合，按裂痕尺寸处理。

地面装饰从天际线附近的 0.60 倍平滑过渡至画面底部的 1.00 倍；仅影响装饰视觉，不缩放角色、弹道或碰撞。远景两层在原有 0.45 / 0.65 倍基础上统一放大 40%，等效 0.63 / 0.91 倍，保留视差和薄雾。墙、拱门、石柱、断柱各自有物理尺寸，并保留窄窗口高度限制、入水裁切和倒影；较高遗迹触及顶部 HUD 安全边界时会限制实际放大幅度。此调整仅改变远景尺寸，原有摆放数量与间距保持不变。

## 密度

- 网格大小仍为 192×192；每格仍尝试放置 1—3 个装饰，继续避开中央不透明石砖地面。
- 保留布局随机种子及其取样顺序。新素材样式由独立的确定性变体索引选择，素材增多不会增加实例数，也不会移动原装饰位置或影响战斗随机数。
- 9 个抽样槽位分配为断砖 2、裂痕 2、湿地斑/水洼 1、苔藓 2、碎石 2。水洼替换原裂痕槽位，不追加摆放。
- 远景仍为 810 / 690 的两层间距，每段维持原有的墙、柱数量，局部第三个断柱条件不变。
- 水纹仍使用 24 个 Sprite 池、1.35 秒寿命、64 单位脚步间隔及原环境滴水频率。
