# ABCDQ 主战斗场景组合审阅版

本轮只新增独立审阅入口、配置和绘制脚本。正式战斗场景、配置与已确认的 PNG 未替换，98 项相关文件的 SHA-256 与本轮开始时一致。先前删除的 A、P 及地块素材没有恢复。

## 本版摆放

- 草簇：沿正式地面的绿色区域生成；使用与地面相同的投影坐标读取植被适宜度。每处从附近候选位置选取更匹配的地表，再形成小群落；枯草比例低。四向巡览中，黑暗区域以下可见约 278–349 簇。
- B、Q：两种 B 与七种 Q 均参与中密度生成，位置加入随机偏移，避开 A 的主体范围；巡览中可见约 21–32 件。B 继续使用已确认的四倍分辨率图，按逻辑尺寸显示。
- A：仅使用 A01 圆石、A05 倒木。以 1850×1100 世界像素为间隔交错安排，两种物体错开，加入小幅固定随机偏移。标准 1280×720 视野内同类不会并排重复，四向录制逐帧检查通过。审阅中添加了与地面接触范围相符的小型碰撞区域。
- C：四种遗迹参与横向视差轮换，每侧至多一件；仅在屏幕两侧约 32% 的暗区渐显，中间留空。顶部稍亮、下部逐渐压暗并融入黑暗，保留 0.26 的视差速度；洞窟背景继续为 0.08。
- D：保留四角的原图版本及已确认的屏幕边缘定位；涵洞全景、黑暗带和主战斗地面沿用当前正式版。

## 性能与验证

草簇在运行时组成一个 128×32 图集，每个区块使用前后两份 MultiMesh，按人物脚底纵坐标切分可见实例，保持人物与草的前后关系。不再为每簇草创建独立节点。视野边缘保留 140 世界像素缓冲，区块离开范围后释放；重返原区域时根据固定种子恢复相同布局。

巡览加载 15–24 个区块，999–1676 个草实例由 30–48 个合批节点承载。未录图的独立实机测量中，场景更新的常规帧中位耗时约 0.265 ms，加载/回收区块的帧中位约 2.95 ms、最大约 9.68 ms。这些只统计场景脚本更新，不包含整场战斗、GPU 或录图耗时，不能作为战斗 FPS 结论。

Headless 与 GPU 审阅均无测试失败。GPU 录制含 2410 项保存及运行检查，确认视野回收、布局再生、素材覆盖、同类 A 间距、C 的位置范围和退出时资源释放。录制与性能测量均在私有 Windows 桌面运行，`foreground_samples=0`。

最终 Headless 的 42 项检查通过、退出码为 0；菜单初始化仍偶发已有的 dummy renderer `texture_2d_initialize: Parameter t is null`，堆栈指向 `character_select_view.gd`。GPU 录制及独立性能运行没有该错误，也没有脚本或着色器错误。

## 审阅文件

- `artifacts/analysis/cavern_population_review_20261013/index.html`：可播放视频和按方向跳转的审阅页。
- `battle_tour.gif`：1280×720、320 帧、32 秒。右、下、左、上依次各 8 秒，人物每段实际移动 960 世界像素；录像中没有传送。
- `battle_tour.mp4`：同一组实机帧的视频版，文件较小。
- `frames/overview.png`、`frames/log_area.png`：圆石区域和倒木区域原尺寸静帧。倒木补充静帧由独立定位拍摄，不拼入巡览。
- `summary.json`：文件校验、摆放统计、性能测量与验证结果。

本轮为了清楚检查环境摆放，录制时暂停刷怪。人物行走、镜头、地面投影、视差与 UI 都来自实际运行的战斗场景。

## 复现

入口：`res://scenes/tests/cavern_population_review.tscn`。脚本启动真实 GameRoot 后，仅在本次运行的内存中替换布景节点。编辑器手动运行此审阅入口会自动拍摄并退出。

GPU 自动审阅必须通过 `scripts/tools/run_godot_background.py`，传入 `--fixed-fps 30` 及 `--capture-dir=...`；`--quick` 只检查并拍静帧，`--profile-only` 运行完整路线但不读回截图。打包脚本为 `scripts/tools/build_cavern_population_review.py`。

## 追加微调：石后人形暗影与 B/Q 间距

本轮继续修改上述独立审阅入口，未修改正式场景、玩家脚本或 PNG。石头底部碰撞范围调整为贴合底座的椭圆，人物持续向前会受阻，可以沿边缘绕行。人物脚底位于石头后方时，石头材质根据人物当前动画帧、朝向和世界坐标，仅在实际遮挡的像素上显示深色人形；轮廓带少量灰色边线以维持可读性。人物到正面或离开遮挡后，该效果消失，不改变石头透明度。

B/Q 改为对全局放置网格分配九种不同形状，区块边界和负坐标使用同一规则，镜像、缩放不被算作新形状。保留中密度、固定种子和视野回收。289 个区块、1448 件小物件的检查覆盖全部九种资源，同形状实际最短距离约 307.06 世界像素，超过 290 的检查阈值。

新的 11.8 秒动图及原尺寸静帧位于 `artifacts/analysis/cavern_population_refine_20261013/`，审阅页为 `index.html`，动图为 `rock_walkthrough.gif`。人物连续执行背后接近、受阻、侧绕、正面接近、再次绕回石后的真实移动，录像中没有传送。额外的 `blocked_control.png` 只用于检查同一姿态下的遮挡对照，没有插入动图。

GPU 运行 178 项检查通过，私有桌面校验通过、`foreground_samples=0`。对照静帧确认新增的 1224 个变化像素集中在人物轮廓内。100 项正式配置、场景、脚本与素材 SHA-256 均未变化。可用 `--occlusion-review` 运行本轮路线；打包脚本为 `scripts/tools/build_cavern_occlusion_review.py`。

## 追加氛围：巨大露天地穴

审阅版将顶部水平暗带改为宽椭圆的一段弧线：中央暗边退远，左右两侧向战斗区域内包拢。在 1280×720 视野中，中央过渡结束约为 y=222，靠近两边为 y=291。底部只保留较浅的反向圆弧，人物周围形成一片宽阔的受光地面。增加轻微的顶部漫射光，不模糊纹理，不改变原素材像素。

C 遗迹在原审阅大小上放大 28%，底部上移约 12 屏幕像素，横向视差由 0.26 减慢为 0.18；顶部与整体石材略提亮，底部仍融入黑暗。背景涵洞保留 0.08 的视差速度。人物遮挡暗影、A 的碰撞、草簇合批与 B/Q 间距规则继续保留。

怪物离开黑暗区域的判断同步使用所在横坐标的弧形边界，避免两侧仍在黑暗中时按中央高度提前结束入场。光照只覆盖战斗世界，UI 和四角前景的既有层级不变。

新审阅页：`artifacts/analysis/cavern_open_pit_review_20261013/index.html`。`frames/overview.png` 为原尺寸实机静帧，`comparison.png` 为新旧对照；`pit_walkthrough.gif` / `.mp4` 为 16 秒连续四向移动，每段 4 秒、实际移动 480 世界像素。录制中没有传送，刷怪暂停便于观察场景。

GPU 运行 1342 项检查通过，无脚本、着色器或资源释放错误，私有桌面校验通过、`foreground_samples=0`。104 项正式场景、配置、脚本、着色器和图片的 SHA-256 均未变化。像素对照确认顶部两侧和底部变暗、中央地面略亮；未替换正式资源。

Headless 的 54 项氛围检查与 64 项含石后遮挡的回归检查均通过。快速退出时曾出现资源仍在使用的提示；带详细日志的 Headless 复核和两次 GPU 运行均未复现该提示，日志完整保留在本轮审阅目录中。

运行入口不变，增加 `--atmosphere-review` 参数；可与 `--quick` 或 `--occlusion-review` 合用。打包脚本为 `scripts/tools/build_cavern_pit_review.py`。

## 追加微调：草簇底座遮挡与五张洞窟动态展示

草簇改为与物件、人物共用按脚底纵坐标排序的容器：以附近物件底座划分合批区间，再按人物脚底切分区间。物件后方的草被遮住，前方的草覆盖底座接地边缘；相邻区块的物件也参与划分。此方案替代前文每区块固定两批的实现，仍使用 MultiMesh，不为每簇草创建节点。排序切分不变时跳过节点更新，离开视野缓冲区后释放整组节点。

A 的底座附近补两簇草，约 38% 的 B/Q 物件附近补一簇，位置保持零星。绿色地表优先选绿草，其他接地点使用枯草。实机同一位置的隐藏草簇对照中，石头上半部误覆盖为 0 像素，底座前方草簇正确覆盖 122 像素；559 次草与物件重叠排序检查无错误。

超远景使用现有五张处理后洞窟素材，继续保持涵洞上下对齐及稀疏间隔，通过连续滚动逐步展示。横向站定时缓移，人物横向行走时缓慢减弱自动滚动，保留超远景 0.08、遗迹 0.18 的分层视差。遗迹在接近洞窟主体范围时提前淡出，避免覆盖洞口；四种遗迹继续参与轮换。露天地穴的椭圆暗边、顶部光照、石后人形暗影与碰撞保持。

本轮审阅页为 `artifacts/analysis/cavern_depth_panorama_review_20261013/index.html`。`walkthrough.gif` / `.mp4` 是 18 秒连续实机录像：静止 2 秒，再右、下、左、上各移动 4 秒，每段 480 世界像素；录制中没有传送，刷怪暂停。`base_detail.png` 展示底座局部对照，`cave_bank.png` 展示五张已接入素材；另存五个背景位置的独立实机静帧，未拼入移动录像。

GPU 录制 1295 项检查通过；最后一次合批更新缓存优化后，独立无截图读回的 GPU 运行 1104 项检查通过，草簇排序与五素材覆盖检查仍通过。场景更新 CPU 中位约 0.723 ms、p95 约 1.063 ms，含区块加载峰值约 21.665 ms；这些不是整场战斗或 GPU 帧耗时。两次运行均验证私有桌面一致、`foreground_samples=0`、退出码为 0。含石后遮挡的 Headless 回归 71 项检查通过。104 项受保护正式文件的 SHA-256 与本轮开始一致，正式资源未替换。

运行入口增加 `--depth-panorama-review`，打包脚本为 `scripts/tools/build_cavern_depth_panorama_review.py`；`--reuse-media` 可复用已录制媒体，只更新对照图、审阅页和验证汇总。

## 纠正背景运动：只响应玩家横向移动

上一版自动缓移与用户期望不符，现已删除时间累加偏移及自动缓移权重。超远景涵洞仅由镜头横向位置计算偏移，系数为 0.08；远景遗迹继续使用 0.18。玩家静止或仅上下移动时，两层背景均保持固定；左右往返时背景回到对应位置，不产生累计漂移。五张素材仍全部保留，通过横向探索逐步展示。草簇底座排序、零星接地草、遗迹避让洞口和露天地穴光照继续保留。

新的审阅页位于 `artifacts/analysis/cavern_horizontal_parallax_review_20261013/index.html`，打包脚本输出也已切换到此目录。18 秒录像包含静止 2 秒及右、下、左、上各 4 秒，可通过上下移动段检查两层背景停止。五张素材的独立静帧改用实际横向世界位置采样，不再人为修改背景偏移。

Headless 完整路线的 2723 项检查通过，验证静止、上下移动及两层横向视差。方向切换时从第一帧已同步镜头的竖向样本开始比较固定位置，逐样本检查同时验证所有镜头横向位移的响应。正式资源继续保留原样。

GPU 实机录制 2914 项检查通过，私有桌面一致、`foreground_samples=0`、退出码为 0。对不含 HUD 的背景区域进行帧间像素比较，静止段、下移段、上移段的变化像素均为 0，右移段为 41624；确认停止的是实际画面。104 项受保护正式文件的 SHA-256 均未变化。
