# 掉落与奖励模块素材 Checklist

本文档用于记录“掉落与奖励模块”需要准备的图片素材、提示词、目标规格、最终放置路径与当前状态。当前阶段只要求满足 MVP：经验球、血包和基础 UI 图标可用。所有提示词均为中文单提示词，可直接复制到豆包、Ludo.ai 或类似 AI 素材工具中使用。

## 1. 统一美术规范

| 项目 | 约定 |
|---|---|
| 画风 | 清新、干净、轻微可爱、克苏鲁轻幻想、中高精度像素风 |
| 氛围 | 可带黄昏、夜晚、穹顶、虚空、星光元素，但不要肮脏、噪点、腐烂、血腥 |
| 掉落物设计 | 轮廓清楚、尺寸小、地面拾取可读性高 |
| 卡面信息可读性 | 图标、名称、描述、稀有度都要能在小尺寸下读清 |
| 背景要求 | 游戏内精灵必须透明背景 |
| 文件格式 | PNG，优先透明背景，禁止 JPG 用于正式游戏素材 |
| 图标规格 | 建议 64x64 或 128x128，正方形，居中，边缘留白 |
| 卡面规格 | MVP 阶段不要求独立卡底 PNG；如后续补充美术再按 4:5 或 1:1 预留图标、名称和数值区域 |

## 4. Godot 导入约定

1. 掉落物建议使用 `64x64` 或 `128x128` PNG，透明背景。
2. UI 图标建议使用 `128x128` PNG，正方形。
3. 当前 MVP 可以先只接经验球、血包和金币图标。

## 5. 状态字段说明

| 状态 | 含义 |
|---|---|
| 未存在 | 还没有生成或未放入目标路径 |
| 已存在 | 文件已放入目标路径，等待 Godot 导入验证 |
| 已接入 | 已在 Godot 场景或脚本中使用 |
| 可暂空 | 非 MVP 必需，可以后续补 |
| 需重出 | 已有图片但规格不适合工程使用，建议重新生成 |
