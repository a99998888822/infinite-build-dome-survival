# 战斗特效分层实施记录（2026-10-23）

已完成[分层方案](combat_effect_layer_proposal_20261023.md)，当前规则见[层级表](combat_effect_layers_20261023.md)。本轮修改渲染层、视觉节点归属与绘制分组，未调整伤害公式、命中范围、状态时长或输入/音量设置。

## 实现与画面复核

- 燃烧、圣焰、暗焰、冰壳、导电、霸体描边随所属角色排序；头顶图标分离至 +64。
- 冻结/解冻碎冰、命中爆点、快速弹道与光束进入对应前景层；地面水流、冰面、裂痕、落点和预警分别保留在身体下方。结霜外部椭圆框线保持移除。
- 黑洞与等离子球只移动视觉归属；喷火分为互补的背景体积与少量前景边缘。粒子仍共用一个模拟池与 900 总预算。
- GPU 像素测试确认火焰/冰壳覆盖所属身体、被前方角色遮住、交换前后位置时恢复可见。两种喷火前后区域重复覆盖像素为 0，前景确实有可见像素。
- 正式场景使用真实怪物素材、草簇和玩家脚底锚点复核；后台截图工具确认引擎位于私有桌面，`foreground_samples=0`。复核场景显式释放临时角色并清空音频流后正常退出。

## 额外检查发现的既有问题

扩展运行旧手雷和位移集成测试时未全绿，不能把本次验证描述为全项目测试通过：

- `grenade_weapon_test`：84 项中 34 项失败，并触发旧用例第 166 行数组越界及退出异常。用 HEAD 中原手雷脚本在独立测试进程内替换后，失败项逐条一致。多个用例仍断言基础伤害 16、旧爆炸范围、旧槽位/商店条件。
- `mobility_weapon_integration_test`：133 项中 16 项失败。将本次改动的位移图集与手炮喷焰脚本恢复为 HEAD 版本进行进程内对照，失败项逐条一致，主要涉及旧距离/范围与命中夹具。位移控制和伤害脚本未在本轮修改。

上述旧测试未为通过而放宽断言，也未据此修改当前战斗数值。相关日志保存在 `artifacts/previews/combat_layers_20261023/validation/`，后续可单独更新旧测试夹具。

冥狼受击测试中的缩放断言已按现有 192 像素图集修正为 1.0 / 1.5；当前图集已烘入放大比例，未修改怪物动画或碰撞。
