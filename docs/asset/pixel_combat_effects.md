# 四种附魔的像素战斗特效

2026-09-23：调整黑洞、光辉剑、水流、风刃的实战绘制。继续采用代码绘制，附魔图标、玩家和敌人的 PNG 不变。

## 表现

- 黑洞：根据反馈改为地面上方的圆形暗紫球体，用分层明暗、前后环绕轨道和独立地面投影表现体积；球体在角色上层，投影在下层，吸附中心仍保持原地面坐标。最后 24% 生命周期收拢消失。
- 光辉剑：以冷灰蓝、象牙白和少量纯白分出剑身结构；落点标记、落地碎光与逐段碎解。落地后用 0.09 秒连续入地。裂纹收敛为左右各一条短横向细缝，不再分叉或放射，也移除了落地环形短线，碎光只保留左右少量颗粒。
- 水流（2026-09-26）：已用审阅草稿替换为单圈向外扩散的蓝白水浪，外围带不规则卷曲泡沫，内部只有淡回流波纹；移除旧 S 形内浪和上层飞溅水滴。普通卷轴最大半径为 `132×0.7×0.85=78.54`，时长0.85秒；范围伤害与打湿在生成时一次结算，之后的扩散是余波动画。主体位于角色下方。
- 风刃：根据反馈完整恢复像素改造前的浅青色弧形版本，包括原有线条、旋转、尺寸变化和淡出；保留原来的抗锯齿，不继续使用新增的像素刃口和短拖尾。

## 绘制边界

结霜与电浆炮的贴地调整（2026-09-26）：

- 结霜沿地面纵向投影为 0.55 倍，保留六向雪花与周边小冰晶；使用淡冰蓝色，晶体透明度乘 0.58。基础半径由 64 缩至 51.2，完整地面足迹的半轴为 51.2×28.16；碰撞查询使用相同椭圆，伤害范围加成与风吹扩散同步缩放两轴。敌人脚下结霜、扩散前沿沿用同一投影和配色。
- 电浆炮球心到地面投影中心的间距为 22.5 像素，暗影半轴为 11.25×3.3，电弧落点同步跟随高度。球体本身的 12 像素半径与接触伤害判定保持一致。
- 实机对比图见 `artifacts/reviews/effects/grounding/`，来自正式场景、相同位置与固定特效时刻的受控渲染。元素反应回归 63 项、电浆炮接触回归 28 项检查通过，覆盖椭圆两轴内外、范围加成、风吹扩散、伤害去重、移动接触、暂停和附魔结算。Godot 编辑器校验及主场景启动完成；反应测试既有的 `combat_audio_impact` 元数据报错、场景退出资源释放警告仍存在，修改前日志也有相同记录。

`scripts/effects/pixel_effect_draw.gd` 为黑洞、光辉剑和水流提供 2 像素网格绘制。这三种特效的主体不用抗锯齿或模糊；风刃采用恢复后的原有绘制方式。不改变世界视口分辨率、角色贴图尺寸或浮点运动。

黑洞、光辉剑和水流的同类型效果在 160 世界单位内叠加时，前两个使用完整装饰，第三、四个减少装饰，第五个起保留主体；场上效果较多时也降低装饰档位。档位在生成时确定，只控制绘制，不跳过节点、伤害、吸附、状态或击退，也不是对逻辑节点数量的硬上限。风刃已退出这套装饰分档。

水流最大范围较旧版缩小15%，显示与伤害使用同一最大半径，仍受伤害范围属性加成；伤害倍率55%、目标去重和元素反应沿用现有规则。水流仍即时结算范围伤害；光辉剑仍在等待和下落完成后结算范围伤害。

正式水流实录见 `artifacts/reviews/effects/water.gif`；复现入口为 `scenes/tests/water_effect_live_capture.tscn -- --transient-session --variant=water --capture-dir=<绝对路径>`。已被正式实现替代的原草稿和旧版水流组合录制已清理，绘制实现保留在 `scripts/effects/water_wave_effect.gd`。
