# 四种附魔的像素战斗特效

2026-09-23：调整黑洞、光辉剑、水流、风刃的实战绘制。继续采用代码绘制，附魔图标、玩家和敌人的 PNG 不变。

## 表现

- 黑洞：根据反馈改为地面上方的圆形暗紫球体，用分层明暗、前后环绕轨道和独立地面投影表现体积；球体在角色上层，投影在下层，吸附中心仍保持原地面坐标。最后 24% 生命周期收拢消失。
- 光辉剑：以冷灰蓝、象牙白和少量纯白分出剑身结构；落点标记、落地碎光与逐段碎解。落地后用 0.09 秒连续入地。裂纹收敛为左右各一条短横向细缝，不再分叉或放射，也移除了落地环形短线，碎光只保留左右少量颗粒。
- 水流：基础半径仍为配置中的 132；细化蓝色浪头，增加断续泡沫和少量水滴。生成瞬间以低亮度范围短线对应即时伤害，后续扩散作为余波。水纹在角色下方，水滴在上方。
- 风刃：根据反馈完整恢复像素改造前的浅青色弧形版本，包括原有线条、旋转、尺寸变化和淡出；保留原来的抗锯齿，不继续使用新增的像素刃口和短拖尾。

## 绘制边界

`scripts/effects/pixel_effect_draw.gd` 为黑洞、光辉剑和水流提供 2 像素网格绘制。这三种特效的主体不用抗锯齿或模糊；风刃采用恢复后的原有绘制方式。不改变世界视口分辨率、角色贴图尺寸、浮点运动或物理查询。

黑洞、光辉剑和水流的同类型效果在 160 世界单位内叠加时，前两个使用完整装饰，第三、四个减少装饰，第五个起保留主体；场上效果较多时也降低装饰档位。档位在生成时确定，只控制绘制，不跳过节点、伤害、吸附、状态或击退，也不是对逻辑节点数量的硬上限。风刃已退出这套装饰分档。

原有半径计算、伤害倍率、命中目标去重、元素反应与计时保持不变。水流仍即时结算范围伤害；光辉剑仍在等待和下落完成后结算范围伤害。
