# 理财·购买·附魔

2026-09-22：付费商店合并到波次间的理财准备页。免费升级奖励继续使用原场景和原触发时机。

## 交互规则

- 每波只能成功存款或取款一次，失败不消耗机会。操作完成后银行显示回执，购买、刷新、出售及附魔仍可使用。
- 金额输入实时校验：超出金币余额或本金时禁用确认并标红，回车提交同样拦截。交易系统继续按真实余额核验，防止过期界面余额或重复提交增加金币。余额栏统一显示“金币”。
- 只有“开始下一波”会进入下一波战斗。波次开始类遗物在此时触发，准备期间新买的遗物参与触发；准备期间的存款计入当波存款契约。
- 桌面使用修订版哥布林，角色相对初稿缩放为 0.7，桌子维持原比例。存少量微笑、存大量开心、取少量沮丧、取大量伤心，1.4 秒后恢复待机。
- 哥布林按参考图重绘：采用光头、横向宽尖耳、低眉骨、黄绿色眼睛、突出的钝鼻与宽嘴，恢复明确的哥布林特征；以不对称视线和歪笑表现狡黠。五种表情同步调整，服装、手势、0.7 倍显示大小与位置保持不变。
- 大额标准为 `金额 >= max(50, ceil(操作前来源余额 × 25%))`，取款以本金为来源余额。成功操作播放短金币音效，沿用 SFX 音量设置。
- 购买区采用固定尺寸卡片和纵向滚动。默认至少 3 件，属性加成无代码上限。商品种类不足时补充可无限叠加的遗物，同一货架上的新武器及升级不会重复；每件商品具有独立的货架编号。
- 购买卡片高度 132，标准购买区每行 3 张；极窄区域自适应减少列数。遗物图标背后显示对应稀有度的柔和辉光，卡片边框和稀有度文本同步着色。
- 已购商品保留原位置并标记。购买、银行操作及页签切换保留滚动位置；刷新重新生成货架并回到顶部。仅创建可见行及少量预载行。
- 附魔页先选武器，再选具体附魔实例，可装备、卸下或转移，也支持拖入目标武器或空槽。ESC 页面只允许查看。
- 出售武器自动归还附魔，不允许卖掉最后一把武器。出售附魔要求先卸下，只出售选中的实例。金币进入随身余额，不改变银行操作次数。
- 出售前显示报价和返还附魔，确认时重新核验。重复提交、过时报价和替换后的同类武器不会被误处理；入账失败恢复原物品及归属。

## 布局

标准窗口采用左侧银行、右侧购买／附魔页签，右边保留玩家属性抽屉。已持遗物数量可能很多，理财页不再重复展示，统一通过 Esc 打开遗物与附魔列表。再次按 Esc 或点击列表返回按钮，恢复原理财页，保留货架、已购状态、滚动位置、附魔选择、输入金额和本波存取款状态，战斗仍保持暂停。出售确认打开时，Esc 先取消出售；悬浮信息不会阻挡打开列表。

主面板不足 700 逻辑像素时，银行也收进页签。窗口宽度小于 1000 时属性抽屉默认收起；打开抽屉时暂时隐藏准备面板，关闭后恢复原页面。

哥布林按原位图 0.7 倍独立显示，不再乘柜台自适应放大系数，柜台尺寸保持不变。武器选择按钮和出售确认均显示对应图标。购买／附魔页签采用金色选中背景和深色未选中背景。

附魔槽从 136×82 缩为 68×41，显示图标和名称，移除槽位编号及“已装备”文本，以箭头标示排列；选择后使用金色边框高亮。已装备附魔仅保留在武器槽中，可拖到同武器另一槽位调整顺序，或通过“前移／后移”按钮操作。新附魔接到当前排列末尾；卸下后剩余附魔按顺序前移。不额外承诺所有战斗效果按该顺序触发。

附魔背包只显示未装备实例，卡片最小尺寸 112×28，标准窗口每行 4 张，占用面积约为旧版的 30%。每张卡片仅显示图标、名称和右侧放大镜，只有悬停放大镜才展示该实例的详细属性；选中、拖拽及出售操作继续可用。

高度不足 480 时，压缩标题间距并将刷新与开波按钮放在底部同一行。附魔操作在高度不足时允许整区滚动，避免按钮超出画面。

## 回收价与后续称号

回收比例配置位于 `data_config/inventory_trade_rules.json`，武器基础价、升级价和附魔参考价默认按 50% 回收、向下取整。付费武器及升级记录实际购买价，回收基数不高于实际支出。免费／初始装备采用对应稀有度的参考价。

`WeaponInstance` 增加实例编号、购买价记录、升级价记录及 `battle_title` 字段。报价可展示称号名称及 `sale_bonus`，但尚未实现战斗伤害、次数、元素等统计与动态授予称号；本次不会凭空授予测试称号。
