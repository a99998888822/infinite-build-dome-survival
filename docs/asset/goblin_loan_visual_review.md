# 哥布林贷款 · 视觉审阅

状态：**已接入正式理财流程、动态报价、贷款结算与银行日志**。保留实机截图、图标与贷款栏状态总览；重复原型截图和动图已清理。

## 已确认规则

- 理财期间后台累计三次点击因金币不足而禁用的购买按钮，触发贷款交易。购买按钮仍真正禁用，不额外提示贷款入口，也不显示点击计数。
- 哥布林台词严格为「钱不够？先拿去，后面再还！」。
- 基础三档：借 100，下波还 140；借 200，下波还 260；借 500，下波还 600。
- 下一波全部结息完成后，用钱包总余额判断是否足够还款。足够则整笔自动偿还；不足则不扣金币、不扣本金，欠款整笔按合同利率计算下一期复利。
- 贷款后允许按原有银行规则存款；报价已考虑现有遗物带来的贷款新增利息收益，并在必要时提高贷款利息。首次展示后，三档条款固定，重新打开或后来获得遗物均不改价。
- 一次理财最多自动弹出一次。关闭后在银行最底部保留小入口；接受后在同一处显示「已贷款：xxx 金币」，后接小型「还清」按钮。
- 允许主动还清当前应还金额。
- **死亡／通关时不追缴剩余债务，不抵扣营地币，正常结算。**

## 视觉方案

沿用银行暗绿背景、旧金边框、像素字体与既有哥布林。贷款图标为当前模型使用 Pillow 绘制的透明像素素材，没有调用图片生成服务。

弹窗在屏幕中心出现，哥布林在标题下左侧，右侧气泡逐字显示台词；三档金额、应还金额、利息与按钮从弹出起完整显示。大档使用稍亮的旧金边，表示诱惑，不增加「推荐」「免费」等未确认承诺。

每档按「立即获得 → 金币金额 → 下波归还 → 每波利息 → 借款按钮」排列。共同条款置于底部：

> 下一波结束，全部结息后自动还款。
> 余额不足不扣款，欠款计复利。

关闭按钮与「暂时不用」均收起弹窗。关闭／拒绝后，入口放在银行边框内最底部；日志和开始下一波保留在其上方。原有银行内容缩短可滚动区域，为贷款栏让出空间，不覆盖商品或按钮。

贷款栏状态：

| 状态 | 主文本与操作 | 右侧／次行 |
| --- | --- | --- |
| 关闭或拒绝后 | 哥布林贷款 · 查看条款 | 无额外宣传文本 |
| 已贷款 | 已贷款：500 金币 · 还清 | 应还 600 金币 · 下波结束结算 |
| 已计复利 | 已贷款：500 金币 · 还清 | 应还 720 金币 · 已计复利 |
| 钱包足够 | 主文本不变，「还清」点亮 | 当前应还金额照常显示 |
| 主动还清后 | 贷款已还清 | 本次理财不再弹出新贷款 |

640×360 保持三档并排，缩小人物与留白；窄屏弹窗使用三行条款。字号与像素边框使用原项目风格。

## 正式实现

- `data_config/goblin_loans.json`：开关、触发次数、台词、三档金额与利率、报价调整步长与余量。
- `scripts/rewards/goblin_loan_system.gd`：本局报价与欠款状态、固定条款、借款、自动／主动还款、复利与重复提交保护。
- `scripts/ui/goblin_loan_presentation.gd`：正式弹窗、逐字台词及音效、银行底部状态栏；显示后台数据，不自行修改金币。
- `scripts/core/main_flow_coordinator.gd`、`scripts/ui/finance_popup.gd`：真实禁用按钮的点击观察、有效商品与资金不足原因复核、界面互斥及布局。
- `scripts/waves/wave_manager.gd`：全部波末利息 → 还款／复利 → 全额存入挑战；死亡和最终营地币结算不额外追缴。
- `scripts/rewards/battle_finance_system.gd`：独立副本中的收益预测、钱包操作及日志。
- `scripts/ui/interest_arrival_report.gd`：已有结息演出末尾显示自动还清或复利结果，不改变利息总收益数字。没有结息演出时，结果仍显示在日志及底部栏。

每次理财最多自动弹一次，同一时间只保留一笔欠款；手动还清后本次不再贷款，后续理财可重新触发。打开与关闭弹窗不取消入口交易，接受贷款时才取消尚未接受的入口交易。已接受交易施加的银行限制不会被贷款解除。关闭后再接受只计一次接受建议；离开理财仍未接受才计一次拒绝。

### 报价计算

三档基础单期利率分别为 40%、30%、20%。在首次弹窗时，用隔离副本预测下一波全部结息，比较借款后存入／持有现金两种可执行情况与不借款时的利息差额，取较大值。已经用完银行操作机会或银行被关闭时，不预测无法执行的存款收益。

预测包含理智折损、额外结息、周期结息、分红概率的期望收益、逐次结息加息、存款达标加息与波初本金赠予；不会推进真实随机数、修改金币、本金或遗物。玩家原有本金产生的正常收益不算成贷款收益，但贷款存款达标而额外带来的原本金收益会计入。

仅当预计新增利息高于基础融资成本时上调：新单期利率 = 向上取整到 5 个百分点（预计新增收益率 + 10 个百分点）。例如借 500 预计多赚 150，则由 20% 调至 40%，显示应还 700。利率、应还金额在选择前直接显示，悬停按钮可查看调整说明。概率分红按期望收益估算，后续新遗物、挑战和实际随机结果不会追溯改价。

欠款按合同固定利率整笔复利，结果向上取整到金币。例如 500 → 600，首次到期不足则变为 720，再次不足为 864。每次不足都不扣部分金币，不动用本金。自动或主动还清都支付当前全部应还金额，营地币的金币收入统计不计入借款。
