## 两个审阅点

- 高清审阅：造型、比例、姿势、视角、主体完整性、材质和缩略识别。此时还不是像素成品。
- 最终审阅：像素原尺寸＋4倍最近邻＋亮暗底＋真实项目临时预览；动画附循环预览。确认后才进入正式覆盖。

每一轮使用新修订目录 `r01/r02/...`，保留已确认输入和成品，不把算法检查通过当作审美批准。当前 Picxel 标准入口只支持32/64/128方形网格；角色优先按07迁移，矩形素材仍按05、06处理，不存在通用的 `--width/--height` 转换开关。
