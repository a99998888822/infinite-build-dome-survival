# 遗物：逐项豆包提示词

前三批24件已安装，当前执行[第四批12件精简配方](batches/relics_sheet_04/README.md)，仅画风参考与文字，一次生成图集再逐件拆分。下列逐项历史配方可辅助核对物件含义；失败项单独补做时也只保留画风参考，不上传旧图标。

当前生成规则已调整：仅上传画风参考，用文字描述物件身份与识别重点，从零设计造型。请使用[新版示例](batches/relics_sheet_02/from_scratch_r02/README.md)。下列历史配方中的“附件2”“沿用原轮廓”及具体旧配饰位置不再是重设计要求；其中名称、配置ID和资源路径仍用于交付映射，执行其他条目前也应按新版规则改写提示词。

高清文件按条目文件名保存。生成后先由用户审阅，再执行 [Picxel 步骤](05_picxel_commands.md)。本文件不表示这些资产已获准替换。

- 高清文件：`relic_piggy_bank.png`（1024×1024）
- 旧造型参考：[打开旧图](../../../assets/ui/icons/relics/relic_piggy_bank.png)；配置 ID：`relic_piggy_bank`
- Picxel 首轮：`--sizes 32`；计划 UI 图标档位：32 / 64 整数倍。

> 请生成一张用于暗色幻想生存游戏的高清物品原画，1024×1024，单件物品居中，完整轮廓，四边适当留白。附件1只参考轮廓、硬边阴影和材质概括；附件2只参考该物件的身份、主要结构和朝向，不沿用其旧画风。统一为清楚的大色块、深色轮廓、每种材质约3档明暗、少量形状明确的高光，光从左上方照射。以青灰、炭黑、旧金、暗棕和骨白为基础，功能点缀色克制。不要像素化、马赛克、景深、柔焦、复杂场景、密集排线、织物噪点、密集金属反光；不绘制名称、数值、水印或商标。优先真实透明背景；若无法输出真实透明，使用纯白背景且不画投影，不绘制棋盘格。陶制猪形存钱罐，圆腹、小耳朵、猪鼻和背部投币口清晰，少量旧金细节；采用灰陶/暗赭色与深色轮廓，不做粉红表情贴纸。这是32×32的遗物小图标，主体最长边约占画布80%～88%，避免细小文字和仅依赖颜色的区别。
