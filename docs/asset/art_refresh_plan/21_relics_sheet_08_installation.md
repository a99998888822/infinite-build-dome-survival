# 第八批：12件遗物按64×64正式接入

用户提供2364×1773白底原图，授权像素化后直接替换。长焦目镜、扩散喷口、定距脚架、余震沙漏、黄金测距仪、深海回声螺、折叠星图、地平线星仪、传单广告、并购重组、神性融合、哥布林金币铸造机均已接入。累计84／90件遗物使用64×64正式资源。

逐件在原图尺度裁切和抠底，显式处理星仪轨道、沙漏两侧、圆规铰链与铸造机内部空隙；保留玻璃、细杆、短链与海藻。底部平台角标位于白边，未遮挡物件。

经项目Picxel转换、逐件对照检查并完成select／finish，每件13～16色、无抖色、硬透明，至少1px透明边界。局部恢复星图六颗星标与连线，修正目镜黄铜旋钮的红色误匹配，并清除星仪黑色星核中的单枚金色误匹配像素。其他九件保持已检查底稿；没有调用生图模型。详细步骤见[处理目录](../../../artifacts/previews/art_refresh_v1/relics_sheet_08/r01/README.md)。

保留正式PNG路径、配置ID、导入UID和设置，安装同名PXG；旧PNG和导入文件已备份。本批加入原生64px遗物名单，沿用最近邻、居中显示及既有槽位。

Godot无界面导入、两组无界面与独立Windows桌面GPU回归均通过，12件文件哈希与导出一致，84项实际界面像素比对通过，前台窗口采样为0。覆盖1024×576和1152×648下的遗物列表、商店滚动、图鉴、奖励卡、结算行高／末行滚动及旧武器布局恢复；遗物列表和商店截图已检查。
