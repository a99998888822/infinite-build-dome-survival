# 第七批：12件遗物按64×64正式接入

用户提供2364×1773白底原图，授权像素化后直接替换。轮回业火之烛、守心铜鉴、无眠账簿、狂热分红、镀金扳机、失控增幅器、清醒誓言、金币心脏、囤积者戒指、黄金棺椁、旧铜望远镜、裂纹铜铃均已接入。累计72／90件遗物使用64×64正式资源。

逐件在原图尺度裁切和抠底，显式处理悬挂环、戒指和增幅器的内部空隙。仅移除蜡烛外部浅色光晕，保留火焰的浅黄内芯。底部平台角标已被白边隔开，未遮挡本批物件。

使用项目Picxel转换、逐件对照审阅并完成select／finish。每件15～16色、无抖色、硬透明，至少保留1px透明边界。局部恢复被缩图弱化的金棺眼形浮雕、账簿眼形铜扣和钱袋裂纹；没有调用模型重绘。详细步骤见[处理目录](../../../artifacts/previews/art_refresh_v1/relics_sheet_07/r01/README.md)。

保留正式PNG路径、配置ID、导入UID和导入设置，安装同名PXG；旧PNG及导入文件已备份。本批加入原生64px遗物名单，沿用最近邻、居中显示及已适配槽位。

Godot无界面导入、两组无界面与后台GPU界面回归均通过，12件文件哈希与导出一致，84项界面像素比对通过，前台窗口采样为0。检查范围包含1024×576和1152×648下的遗物列表、商店滚动、逐件图鉴、奖励卡、结算行高／末行滚动，以及旧武器布局恢复；遗物列表和商店截图已检查。
