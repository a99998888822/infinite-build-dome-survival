# 84件遗物128px正式接入（2026-10-05）

按用户确认的四张原图、128×128处理效果和B／D选择，替换 `assets/ui/icons/relics/` 下84张正式PNG，并同步84份同名PXG和PAL。PNG与确认稿逐字节一致，不再重新像素化。用户列表名“狂乱分红”对应游戏的“狂热分红”（`relic_frenzied_dividend`），采用B；“破裂青铜铃”对应“裂纹铜铃”（`relic_cracked_bronze_bell`），采用D。A、C、E不接入。

其他6件遗物维持原64×64资源：定距脚架、余震沙漏、黄金测距仪、深海回声螺、折叠星图、地平线星仪。配置ID、显示名称、效果数值、图标路径和所有`.png.import`的UID及设置保持一致。

## 显示适配

旧界面按纹理尺寸乘比例计算图标和容器大小。新源图改为128px后，`FinanceUIStyle.relic_icon_size()` 将显示基准固定为64px，再应用各界面的比例：

| 位置 | 显示尺寸 | 采样 |
|---|---|---|
| ESC遗物列表、商店 | 32×32 | 最近邻 |
| 百科、收款明细 | 64×64 | 最近邻 |
| 奖励卡 | 48×48 | 最近邻 |

同步使用显示尺寸计算遗物列表单元、商店虚拟行、奖励卡留白，避免源图增大导致卡片撑开。复用卡片从遗物切换至武器、再切回遗物时，恢复原有布局。

## 验证结果

- 84张PNG均为128×128、alpha仅0／255、最多16色；与确认稿哈希一致，与正式PXG渲染逐像素一致。
- Godot 4.7.2 headless编辑器导入完成，无Parse／Compile／SCRIPT ERROR。
- 现有 `relic_art_install_test` 覆盖全部90件遗物，包括84张新128px和6张旧64px，`failures=0`。检查真实战斗、遗物列表、百科、商店滚动与卡片复用、收款及奖励卡。
- GPU实机抽查7件，覆盖四张源图、B／D及旧64px资源，在1152×648与1024×576下通过界面检查，`failures=0`。人工检查商店、百科、奖励卡与列表截图，图标位置和留白正常。
- 截图运行在已核对名称的私有Windows桌面；`foreground_samples=0`，没有切换输入桌面或覆盖用户浏览器。
- 测试使用临时游戏会话，没有修改存档或显示设置。
