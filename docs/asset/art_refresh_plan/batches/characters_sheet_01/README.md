## 豆包操作

新开对话，只上传这两张画风参考，再粘贴[精简提示词](doubao_prompt.txt)：

- [01 群像画风](01_character_ink_style.png)：改用reference中的另一张《暗黑地牢》群像裁图，参考轮廓、硬阴影和服装大块面。
- [02 有机体画风](02_organic_block_style.png)：克苏鲁插画裁图，只参考有机体明暗块面；不要照搬多眼与卷曲触手造型。

不上传当前游戏角色、不上传此前遗物／武器／附魔生成图。旧图的身份要素已转成文字，本批允许重设计比例、衣服剪裁、甲片和轮廓。只做裁图作为参考，没有调用生图或像素化工具；来源、裁切区域与哈希见[manifest.json](manifest.json)。

一次生成2列×2行、白底、4096×4096或最高可用分辨率的高清图，位置如下：

| | 左 | 右 |
|---|---|---|
| 上 | 初心者 | 资本家 |
| 下 | 天外幼体 | 钢甲骑士 |

下载原始图片发回，建议名为 `characters_sheet_01_source.png`。若豆包只能稳定生成较低分辨率，可使用同一公共风格提示，分别生成四张1024×1024以上的完整单体，不把低清四格图放大冒充高清。

## 回传后的步骤

1. 检查造型、手脚、盾锤、触手之间的空隙和同一镜头视角，裁切为四张透明高清母稿。
2. 沿用项目Picxel外部图片流程，先出玩家与幼体64×64、骑士128×128的候选静态稿；这是角色规格，不跟随本轮附魔的32×32。
3. 审阅通过的母稿固定身份、色板、脚底和握点，再准备现有动作的逐帧提示与姿势约束。动画阶段使用已确认的新角色母稿维持身份，而不是回头上传旧角色造型。
4. 完成整套动作后，再对齐画布、逐帧尺度、图集、Godot偏移和显示大小，后台验证后替换。静态稿不直接覆盖正在使用的行走／冲刺帧。

当前动作数量核对：初心者待机1＋行走8；资本家待机1＋行走4；幼体待机1＋移动7；骑士待机1＋移动11＋蓄力7＋冲刺2＋收招2。保持动作与攻击节奏；世界中的角色体型需要另按确认稿适配，不能把骑士128px画布直接当成128px显示高度。
