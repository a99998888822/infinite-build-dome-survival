## 豆包操作

新开对话，依次上传下面两张画风参考，粘贴 [doubao_prompt.txt](doubao_prompt.txt)。不上传旧图标、已生成道具表或此前的遗物参考。物件身份由文字给出，自由设计新造型。

1. [01_steel_ink_reference.png](01_steel_ink_reference.png)：主要参考，来自另一张《暗黑地牢》铁甲图，借用金属块面与硬边明暗。
2. [02_arcane_color_reference.png](02_arcane_color_reference.png)：辅助参考，只取紫青／旧金配色与秘术装饰，不借人物、法杖、光环和构图。强发光、细线和密集纹理不沿用。

两张都从项目 `artifacts/reference/` 中选取并裁去文字或签名区域，未经模型重绘。来源、裁切坐标与哈希见 [reference_manifest.json](reference_manifest.json)。与此前反复使用的 `U01_darkest_style_no_text.png` 是不同原图。

## 后续参考图选择

之前固定同一张图是为保持画风，但不应把同一张原图当成所有类别的唯一参考。以后按批次换图：器械看铁器明暗，法术看符号和能量色，生物看有机轮廓，场景看空间和大块面。每次明确一张主参考，按需加一张辅助；固定深轮廓、硬阴影、有限明暗和低噪点，不固定人物、构图或所有物件的颜色。
