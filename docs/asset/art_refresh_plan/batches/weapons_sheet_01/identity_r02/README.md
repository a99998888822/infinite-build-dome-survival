# 武器图标修订r02：保留原设计，更新画法

**本版已停用。** 用户反馈生成结果几乎完全复刻原图造型，只提升了清晰度。当前改用[要素重设计r03](../elements_r03/README.md)，不上传原图造型表，只保留文字识别要素并开放轮廓、比例与组合设计。以下内容仅作历史记录。

上一轮高清稿已被用户否决，原因是与正式武器图标的造型偏差过大。r01的“自由设计”和部分未经原图核对的描述放开了结构，秘术配色参考也干扰了原有色彩。本轮只准备豆包重绘材料，不像素化或安装被否决的图片。

## 操作

新开豆包对话，按顺序上传：

1. [01_weapon_identity.png](01_weapon_identity.png)：11张正式图标的原像素等比放大排表，仅约束造型、朝向、部件比例、主色与关键装饰。它是原图对照表，不是新生成稿。
2. [02_drawing_style.png](02_drawing_style.png)：沿用上一轮新选的铁甲画法裁图，只借深轮廓、硬阴影与材质大块面。撤去紫青秘术配色参考，避免所有物品被统一染色。

粘贴 [完整修订提示词](doubao_prompt.txt)。本轮用户要求接近原图，因此对武器明确采用造型参考；此前遗物“画风＋文字、自由设计”的流程不直接套用。请不要同时上传被否决的豆包图或旧两张画风参考包。

生成一张4列×3行的白底高清图集，11件顺序不变，第12格为空。下载原始文件，建议命名 `weapons_sheet_01_identity_r02_source.png`，发回先核对造型，再进入64×64像素化与审阅。

仅靠提示词不能保证模型准确保留全部结构。如果个别格仍偏离，后续只针对这些格，用单件原图与相同画法参考重绘，无需推倒已通过的部分。

## 对照发现与本次约束

| 武器 | 被否决高清稿的偏差 | 本次保留的原设计 |
|---|---|---|
| 木质弓箭 | 弓身在左侧弯曲，朝向和原图不一致 | 右侧弓身、左侧竖弦、向右横箭；朴素小箭头 |
| 电浆炮 | 被画成长导轨筒状炮，失去原来的短枪轮廓 | 中央圆能量核、下方握把、右上张开的双叉炮口 |
| 铸铁榴弹炮 | 枪托与小握把被简化成一根后柄 | 灰绿粗短炮身、木枪托、下方小握把、铜箍 |
| 坤舆秘仪书 | 斜方厚书变成竖长书，封印变成罗盘星 | 近方形书、菱形透视、套叠几何封印、浅页边 |
| 食利者钱袋 | 方扣横带与正面徽章消失 | 三枚金币、方扣横带、正面六边形金徽章 |
| 赤铜炉灯 | 大提手消失，侧喷嘴变侧把，造型接近茶壶 | 顶部拱形提手、竖直灯身、右侧喷嘴、宽底座 |
| 异化触手 | 紫色钩形改成青灰圆环，吸盘颜色反转 | 紫色、单根粗细递变、内卷细端、浅粉吸盘 |
| 裂地战锤 | 铜包箍消失，小裂纹扩大成熔岩带 | 灰绿锤头、两端铜箍、窄橙裂纹、缠柄 |
| 营地短刀 | 直短刀变成长弯刃，装饰护手过大 | 朴素直短尖刃、短横护手、棕柄 |
| 守夜长枪 | 青绿缠带、枪头绑带与尾帽被弱化 | 灰银枪头、青黑杆、青绿缠带、短绑带和尾帽 |
| 流星摆锤 | 带刺球变成无刺多面体，链条构图改变 | 左上短柄、弯链、右下青灰尖刺球、铜环带 |

整体画法也需减少颗粒、细划痕与柔和连续渐变。这些细节在64×64下容易变成噪点；像素化本身无法修复错误的武器结构。
