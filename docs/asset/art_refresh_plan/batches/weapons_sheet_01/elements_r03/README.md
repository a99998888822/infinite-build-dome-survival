# 武器r03：提取识别要素，重新设计造型

**进度：11件64×64像素稿已获确认并安装。** 见[处理、审阅与接入记录](../../../../../../artifacts/previews/art_refresh_v1/weapons_sheet_01/pixel_r01/README.md)。以下生成配方保留备查。

本轮按用户最新反馈修订：保留原武器的关键要素，同时让轮廓、比例与部件组合重新设计。r01丢失了识别特征，r02又锁定了整个造型；r03不继续沿用这两种约束方式。

## 直接操作

新开豆包对话，仅上传 [01_drawing_style.png](01_drawing_style.png)，粘贴 [doubao_prompt.txt](doubao_prompt.txt)。本包只有一张画法参考，不含旧图标或之前生成的武器图。原图由Codex用于提取文字要素，不再作为豆包的图片输入。

这张参考继续使用铁甲画法裁图，让本次调整集中在造型约束；只借用深轮廓、硬阴影和大块面，不借人物、装备或构图。后续换品类仍按材质选参考。

画一张11件武器的4列×3行白底图集，顺序与前两版相同，第12格空白。下载原始高清文件，建议命名 `weapons_sheet_01_elements_r03_source.png`，发回审阅后再进行64×64像素化。

## 保留什么，放开什么

| 物品 | 保留的识别要素 | 允许重新设计 |
|---|---|---|
| 木质弓箭 | 木弓、弓弦、铁头箭 | 弓曲线、握位、箭头与摆放 |
| 电浆炮 | 青蓝能量核、分叉发射口、可握持短炮 | 核心外形、炮壳、部件比例与视角 |
| 铸铁榴弹炮 | 粗炮管、木枪托、铜箍 | 炮管外壳、枪托形状、机械组合 |
| 坤舆秘仪书 | 暗青古书、厚页、几何秘术封印 | 书形、装订、封印图案与视角 |
| 食利者钱袋 | 棕皮、金币、金属财富徽章 | 袋型、束口、徽章形状与位置 |
| 赤铜炉灯 | 铜质可提握灯身、火芯、短喷嘴 | 提握结构、灯体轮廓、喷嘴位置 |
| 异化触手 | 紫色、浅粉吸盘、粗细变化 | 曲线、姿态与吸盘排布 |
| 裂地战锤 | 厚金属锤头、铜加固、少量橙裂纹 | 锤头轮廓、柄比例、加固位置 |
| 营地短刀 | 短刀、灰银刀刃、皮缠柄 | 刀身曲线、护手、握柄轮廓 |
| 守夜长枪 | 金属枪尖、深色长杆、青绿布带 | 枪尖造型、缠带方式、装饰与视角 |
| 流星摆锤 | 带刺金属球、粗链短柄、铜加固 | 球面分区、尖刺排布、链姿与手柄 |

不锁定旧图的朝向、包围框比例、部件坐标、精确数量或装饰形状。每件的设计由上述少数识别要素引导，允许出现与原版不同但仍能认出身份的轮廓。

## 审阅依据

先判断新稿能否凭关键要素识别为对应武器，再判断轮廓和组合是否有新设计。变换角度或放大旧图本身不算完成重设计；也不要求改动那些构成武器基本功能的连接关系。最终还需检查白底可拆分、主体完整、大块明暗及64px缩略可读性。

r02的问题来自用户文字反馈，本轮没有收到或检查新的r02生成图。此处记录的是约束修订，不声称已经生成或验证r03成品；本轮不启动Picxel，不修改正式资源。
