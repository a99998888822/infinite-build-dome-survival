小怪参考来自克苏鲁插画的有机体局部，只借鉴线条和明暗块面；青灰／苔绿配色、卵形身体、4条粗短触手由文字指定。Boss参考来自另一张《暗黑地牢》铁甲插画，裁去标题与标识，只看金属画法。主体结构仍由文字指定：封闭铁盔、重甲、画面右盾左锤；其盾形、甲片和头盔允许新设计。

两张分别生成2048×2048纯白底高清单体；模型不支持时选择最高原生分辨率，不先把低清图放大。明显深色轮廓、大色块、硬阴影有利于后续像素化；不要让豆包直接画像素格，也不需要在高清稿中机械规定1px线宽。

参考图与提示词只会降低造型复制倾向，不能保证模型完全忽略参考构图。若结果仍照搬，换新对话，仅保留对应局部画风参考与本页文字，不上传旧结果。

## 高清图回来以后

1. 两张原图发回，先核对完整轮廓、朝向、触手数量、盾锤握持及白底空隙；下载原始文件，避免浏览器缩略截图。
2. 母稿确认后，用各自新的母稿做视频身份参考，固定镜头、体型、光源和背景。小怪先做原地向右爬行，骑士先做原地向右行走；不要用旧游戏精灵驱动造型。
3. 骑士还需要蓄力、冲刺挥锤、收招三个阶段，动作应另做清楚的完整序列，不能只靠走路帧替代攻击。
4. 提供按顺序命名的完整一轮截图，最好附视频或时间戳。我再抠图、统一尺度与脚底、像素化、描边，并用同一帧做idle。若第一帧不是稳定待机姿势，会先标明，避免生硬停步。
5. 像素稿确认后再适配工程。当前小怪86px、骑士160px暂不迁移；后续以确认的64／128稿对齐。Boss蓄力0.8秒、冲刺0.16秒、收招0.5秒的游戏节奏保留，按实际新帧数映射播放，不强迫视频恰好输出旧帧数。
