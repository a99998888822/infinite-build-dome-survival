# battle_ground_01 · r04审阅标准

## 高清阶段

| 类别 | 可接受 | 需要修正 |
|---|---|---|
| G01/G03纯地面 | 平面色块、全图均匀、满幅不透明 | 草叶、石头、相机风景、近大远小、隆起土块、长投影 |
| G04/G05铺砖 | 平齐小砖、同尺度，G05缺砖处填泥土 | 巨型板块、四格分区、台阶、独立石堆、场景透视 |
| G06–G08灌木 | 三件完整分离，白底或真实透明 | 土台、盆景、外部投影、相连、裁断轮廓 |
| G09–G12草簇 | 四件独立草本，顶部／前侧可见、视角一致 | 带土块石头、针状噪点、根部截断、一远一近 |
| 色彩与明暗 | 暗绿／灰棕／冷灰，宽色块、少量明暗档 | 光束、暗角、亮斑、全幅渐变、写实砂粒 |
| 文件 | 最高原生尺寸、真实格式、无额外排版 | 截图冒充高清、只改后缀、插值放大、标识留在交付区域 |

地面不再以“看得到草叶侧面”验收。草簇视角独立看，再与角色组合判断。原图重复检查不等于已执行Picxel。平台标识登记后处理，提示词未必能消除平台自动标识。

## 像素与小样

- G01/G03/G04/G05为128px不透明母纹理，从G01本地派生G02。记录源文件、参数、网格、色板、修整，不抠除地表底色。
- 灌木128px、草簇64px，真实透明；检查亮暗底白边、断叶、漏抠、根部、留白与0／255硬边Alpha。
- 查看原尺寸、最近邻放大、地面2×2和3×3重复。循环偏移检查水平／垂直接缝及四块交点，不用模糊和全幅渐变掩盖。
- G01/G02共享边缘约束，检查不同邻接组合；只改变内部低对比色块，不加草簇、独立石块。G02尚未实际派生。
- G04/G05砖网格与比例一致，不随意旋转有方向的砖列或精灵。
- 检查暗绿地表→泥、暗绿地表→砖、泥→砖、G04→G05的直边、内外角、窄条、三材质交点；遮罩隐藏处露出连续底面。
- G05泥土默认保留，需要独立残砖时再画轮廓遮罩，不全局抠除暗部。
- 先组合G01＋G09–G12＋现有玩家，比较疏密两档，再按实际轮廓确定根部锚点和世界大小；64px画布不等于64世界单位的大草团。
- 草簇保留自身根部暗色，必要时在独立场景层加微弱接触阴影，不烘焙成长投影。

## 候选实机

- 中央与外围地貌完整，草簇成群且有留白；地面母纹理无草石主角、近大远小和重复条带。
- 草簇适度搭在砖沿泥边，灌木控制高度密度，不遮挡角色、Boss、预警或掉落。
- 世界坐标与独立种子保证正／负坐标跨区块连续、中央广场唯一、返回一致；不扰动刷怪和掉落随机序列。
- 仅加载附近区块，远处回收。密草可用合批／批量绘制，实测帧耗时与节点数，不预先声称性能已通过。
- 草／土／砖／水查询与画面一致，湿脚步和水纹只在适用区域出现，不按贴图透明度判断水域。
- 黄昏／夜晚、1280×720与640×360检查像素和战斗信息；暂停恢复、退出、回收稳定。
- 运行逻辑修改后先headless；GPU独立Windows桌面核对foreground_samples=0。旧audit报告不是新场景验收证据。

本页列出后续要求。r04的G01已由助手初审为可进入后处理小样的候选，尚无像素成品或候选实机；用户未批准最终交付。
