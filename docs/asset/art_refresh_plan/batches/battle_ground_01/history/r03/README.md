## 三类素材，三种透明规则

| 类别 | 生成时 | 后处理／游戏使用 |

**PNG是文件格式，不等于透明。** G01没有Alpha通道完全正确；G05缺砖处也先画泥土，不能生成透明窟窿。纹理平铺接缝和透明抠图是两个问题，抠掉底色不能解决重复或斜光。

## 所有地表共同的硬要求

- **均匀漫射照明**：四角与中央总体明度相近。允许叶团、砖缝内的短小硬边明暗，不烘焙场景斜光、外部投影、暗角、亮斑或全幅渐变。旧版“左上弱光”对G01–G05停用；灌木仍可有左上局部体积光。
- **无视觉中心**：没有中央石堆、大坑、巨大叶团或特别醒目的单个标记。材质内部有局部变化，整体密度均衡，不沿斜线集中排列。
- **固定斜视，而非正上方顶视**：草叶／崩角露顶部与少量前侧，地面前后方向缩短；采用平行投影，整图没有近大远小。当前引擎不会把顶视纹理自动转换为斜视，详见 [CAMERA_CONTRACT.md](CAMERA_CONTRACT.md)。
- **连续地表**：无地平线、无地块外侧立面、无四周框线；形状可延伸出边界。不画四格展示、巨型方石板、十字分区，也不把方形画布画成菱形独立地块。
- **适合缩为128px**：宽短块面、两至三档明暗、少量结构，无假像素网格、密集草针或砂粒噪点。草地与泥土不预埋可复用的独立石头。

豆包“可平铺”并不保证真正无缝。局部接缝可由我修整；全幅照明渐变、明显石堆主角和错误视角应在高清阶段退回，不能指望抠图或像素化自动解决。完整标准见 [REVIEW_CHECKLIST.md](REVIEW_CHECKLIST.md)。

## 后续怎么拼成可延伸战场

G01不透明连续打底 → G02／G03／G04／G05按世界坐标分区覆盖 → 像素遮罩与草叶／残砖过渡 → 透明小装饰与灌木 → 战斗预警、角色和攻击效果。水域使用独立类型，不能再用“非石盘即湿地”判断。

母纹理保持不透明。叠加时由遮罩决定某处显示石砖还是露出草地；G05已经画出的泥土可以保留，不按颜色全局抠掉所有暗部。需单独残砖时再绘制局部轮廓遮罩。底层始终有地表，避免黑洞。制作说明与对话指令见 [NEXT_STEPS.md](NEXT_STEPS.md)。

128×128是纹理尺寸，256–512世界单位是建议地貌区域尺度，都不是地图上限。中央广场只在出生区保留一次，外围持续生成不同草地、泥地、石路和小遗址；世界坐标、固定种子和共用边界保证跨区块连续、返回时布局一致。仅加载附近区块。黄昏／夜晚共用材质，场景照明在组装阶段处理。
