## 透明与视角

- G01/G02/G03是完全不透明的平面色片，没有立体物体，不再写俯拍、斜拍、镜头高度或景深。
- G04/G05只画平齐地面的砖面图案。候选可见砖比例约3:1、约8列24行，所有位置同尺度；这是2D画面设计，不是要求模型拍摄砖地。
- 草簇和灌木独立斜视，可见顶部与前侧。默认可靠纯白底，后续抠成真实透明；直接提供真实RGBA也可用，不接受棋盘格伪透明。
- 地面材质边界用独立像素遮罩；草叶搭在砖沿、泥地旁的效果由透明草簇补充，不烘焙回母纹理。

纯地面没有草簇是正确结果。地面色片保证连续底层，小物件提供高度、轮廓和生态密度，接地效果在两层组合后判断。详见[视角与分层](CAMERA_CONTRACT.md)。

## 拼接与无限延伸

G01/G02连续底面 → G03/G04/G05材质区域与过渡遮罩 → 草簇、苔藓、碎石、灌木 → 预警、角色、攻击效果。

密草通过独立草簇的种类、组团和密度形成，使用固定种子、少量尺寸档和统一根部锚点，保留战斗留白，不全屏均匀撒点。不随意旋转精灵破坏视角／光源，也不把草簇按整张地面远近缩小。微弱接地暗部由物件自身或独立场景层处理，不烘焙长投影到地面。

地貌按世界坐标跨区块延伸，中央广场仅出现一次，附近加载、远处回收，返回时布局一致。128px不是地图边界。地表查询与区域遮罩共用，草／土／砖／水类型控制水纹和湿脚步。平铺、四块交点、过渡和不同变体组合仍需检查。
