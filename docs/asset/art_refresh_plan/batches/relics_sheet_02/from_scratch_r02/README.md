# 第二批重设计：只用画风参考与文字

本配方的新造型与[r02像素稿](../../../../../../artifacts/previews/art_refresh_v1/relics_sheet_02/r02/README.md)已获用户确认，6件已正式安装。以下生成步骤保留作配方记录；当前操作转到[第三批12件](../../relics_sheet_03/README.md)。此前未通过的r01独立保留。

## 保留的生成步骤

1. 在豆包新开一个对话，减少上一轮图集与修改要求的上下文影响。
2. 只上传 [01_style_reference.png](01_style_reference.png)。这是项目reference中《暗黑地牢》插画的无标题裁切，只借鉴轮廓、硬阴影与块面。
3. 复制 [doubao_prompt.txt](doubao_prompt.txt) 全文，要求从零设计6件物品。
4. 下载生成的原始高清图，发回当前对话，先检查造型与块面设计，再决定是否像素化。

本轮只使用本目录这一张附件。不上传旧图标拼图、上轮豆包图、像素稿或第一批道具图；本目录的ZIP也只包含一张画风参考，避免混用历史附件。

## 这次提示词的变化

不再规定旧图的圆章位置、纸张朝向、U形触手、帽子和配饰布局。提示词描述的是身份、概念和识别重点，具体造型由豆包设计。三类纸质物件要求通过外轮廓与结构区分；哥布林以头脸为主体，防止大帽子占用小图标的有效面积。

风格参考仍可能带来人物或构图借用，提示词不能保证完全隔离它的影响。若新稿继续抄附件主体，下一轮可在全新对话只保留文字画风描述，不附图；先看当前一张结果，无需反复给同一张图追加“不要照抄”。

## 高清审阅标准

- 六件是否有新的、彼此可区分的外轮廓，是否符合各自物件含义。
- 暗部与亮部是否是清楚的大块面，是否仍有大量写实颗粒、排线与细碎高光。
- 缩略查看时是否仍可辨认；高清图精致不代表转成32px后仍有足够细节。
- 数量、顺序、完整性、白底与无文字是否正确。

不要因为“与旧图不同”就直接通过，也不应为了匹配旧图把新设计逐项改回去。造型通过后仍按“拆件抠图 → Picxel32px稿 → 用户像素审阅 → 正式接入”执行。本批各阶段均已完成。

画风参考来源与SHA256、原始裁切坐标、位置到配置ID的映射见 `manifest.json`。图片原文件由现有参考复制，没有调用生图服务。
