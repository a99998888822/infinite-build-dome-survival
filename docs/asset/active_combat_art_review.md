图形由 Godot 几何绘制，实机和导出使用同一节点；未使用生图模型。动图来自按时间顺序采样的真实 GPU 画面，没有生成或插值游戏帧。普通小怪仍使用现有素材。

## 本轮改动

- 全部指示器：移除符文、交织纹、刻线、装饰粒子及呼吸动画，仅保留范围轮廓和半透明填充。
- 木质弓箭、电浆炮、异化触手、裂地战锤、守夜长枪保留圆润粗箭头。箭头宽度是方向提示美术，未因此放大这些武器的实际伤害宽度。
- 所有指示器在玩家真实碰撞体外留空；Shader 也裁去近距离投弹标记覆盖玩家的部分。
- 铸铁榴弹炮：射程椭圆与投弹椭圆；鼠标超距时，整个落点椭圆限制在射程椭圆内。真实主动投弹使用同样的落点与椭圆爆炸。
- 坤舆秘仪书：按数字键立即生成固定法阵，总点名数为 `3 + max(投射物总数 - 1, 0)`；逐次点名 1 个存活敌人，可重复点名。空阵保留未完成次数，全部点名及收尾结束后才冷却。
- 秘仪书实际法阵已恢复原本的星形符阵和浮动边界粒子，点名时仍用原指纹状爆纹。其范围示意图与实际施放效果分开绘制，视觉回退不改变上述施放规则。
- 赤铜炉灯：基础 60°，实际火焰与伤害一致；继续随移动转向，静止记忆方向。
- 流星摆锤：130° 扇形，链条扫过的扇面内部也会命中，近端基础伤害、外侧伤害加成仍区分。

炉灯与摆锤已修改共享武器运行时。主动输入、新 HUD、秘仪书新调度和椭圆投弹仍通过审阅场景体验；主玩法数值与清剿尚未接入。

## 交互审阅

在 Godot 中打开 `scenes/tests/active_combat_art_review.tscn`，运行当前场景。场景载入正式战场、角色与武器运行时，使用静止高生命目标，展示全部 11 把武器。测试敌人、整套装备和冷却是审阅配置，正式主场景、数值平衡与清剿阶段尚未迁移。

| 操作 | 行为 |
|---|---|
| 右键地面 | 取消瞄准并移动到目的地，播放用户提供的动画 |
| 1～9、0 | 选择前 10 把武器；冷却中也可查看不可释放的范围 |
| Tab，然后 1 | 在审阅入口访问第 11 把流星摆锤 |
| 左键 | 释放已瞄准武器，随后退出瞄准 |
| 赤铜提灯对应键 | 立即喷射，随移动方向更新，静止沿用最后方向 |
| 坤舆秘仪书对应键 | 立即布阵，逐次点名；没有敌人时等待，完成后冷却 |
| 移动模式按钮 | 在鼠标移动与方向键／WASD 之间切换 |
| Esc | 优先取消瞄准，其次打开原 Esc 界面 |

战斗栏不显示鼠标悬停详情。编号在左上，冷却秒数在右上，灰色扇形区域按剩余比例缩小。施放中暂显示“施放中”，动作结束后才开始试用冷却。不同武器可以并行释放。

## 资源规格

- 目的地原图：用户 `move_indictor.png`，2560×320，横排 8 帧，真实透明背景。
- 接入图集：`assets/ui/combat/move_destination.png`，512×64，8 个 64×64 帧，原图是该图集的精确 5 倍最近邻放大。
- 指示器导出规格：11 张 768×768 透明 PNG，中心原点位于 `(384,384)`，范围按当前基础武器配置导出；历史导出已清理，需要时重新生成。
- 运行时应使用 `WeaponAttackIndicator` 的参数化图形；静态 PNG 用于美术交付、查看和其他工具导入，不能用一张固定 PNG 代替所有属性组合。
- 导出时对透明视口图执行反预乘，以保留浅蓝白色和正确透明度；这些渲染图属于可再生成输出，不是绘制源。
- 原始验证结论保留在下文，逐帧报告和临时配置随审阅产物清理。

- Headless 美术审阅：55 项通过。

- 新范围与秘仪书规则专项：23 项通过，包含各方向多投射物椭圆边界、真实范围内外伤害、空阵等待、进出法阵、重复点名、暂停与死亡清理。
- 上一轮摆锤回归 45 项、原秘仪书／钱袋入口回归 91 项、原武器三件套回归 124 项通过；本轮未修改其伤害规则。
- 实际引擎桌面与私有桌面一致，`foreground_samples=0`，退出码 0。

自动审阅使用 `--fixed-fps 60`，使按帧采样与武器秒数一致；headless 校验使用 `--audio-driver Dummy`。当时 GPU 日志没有脚本错误或资源退出告警。Headless 的55项逻辑检查通过，但退出时出现音频播放资源未释放告警；GPU实机退出正常。逐帧报告和日志已随R07审阅产物清理，此处保留验证结论。
