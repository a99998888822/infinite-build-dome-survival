# 初心者正式 96 像素动作

采用用户选定的 96×96 预览素材：8 组动作、61 帧，逐帧像素保持一致，只拼装横向图集。没有在安装时重新缩放或补绘，没有采用 64 像素试稿。

`animations.json` 保留原有帧序、帧率和逐帧时长。`approved_frames.json` 记录每个 96 像素帧的 RGBA 像素哈希、图集文件哈希和原 128 像素图集哈希，便于核对。原素材保留在相邻 `novice_128/` 目录。

正式入口由 `data_config/characters.json` 引用，选人页与战斗共用。战斗按 1 倍绘制，偏移为 (0,-6)；碰撞、地面投影、光晕和武器挂点按旧体型的 75% 配置。武器特效、攻击范围及动作时长保持原值。
