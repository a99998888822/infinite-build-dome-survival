# 水波与冻结碎冰 PNG 图集

2026-10-06 审阅通过后接入正式项目，素材由已有 Godot 像素绘制代码离线烘焙。

- `water_wave`：112×112 像素单帧，8 列，52 帧，4 个相位、3 个细节档。动画默认 0.85 秒；默认附魔半径 45.696px，视觉和碰撞均为原来的 0.8 倍，范围与时长加成继续生效。
- `ice_shards`：112×112 像素单帧，8 列，60fps。冻结 39 帧、0.62 秒；解冻 45 帧、0.72 秒。细节档 1、2 共用图集，细节档 0 使用独立图集。
- 全部采用无损导入、无 mipmap、运行时最近邻采样。碎冰必须保留 `process/fix_alpha_border=false`，避免导入器改动低透明度像素颜色；水波保留审阅版的导入设置。
- 纹理由正式特效脚本预加载并共享；正式代码不依赖审阅目录、实验配置或性能统计脚本。

审阅动图、原始绘制参考和实测数据保留在 `artifacts/performance/water_png_20261006` 和 `artifacts/performance/freeze_png_20261006`。临时工程、重复素材及试验脚本已清理；此目录中的 JSON 保留图集布局、透明度处理和来源校验值。
