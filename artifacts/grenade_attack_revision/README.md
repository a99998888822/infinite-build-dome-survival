# 榴弹炮像素爆炸与分裂方案审阅

状态更新：用户已确认本方案，分裂已接入正式武器逻辑。本文保留审阅时的录制条件；最新实现与验证见 `../grenade_split_implementation/README.md`。

## 已修改的正式效果

- 删除玩家身上的白黄色发射闪光。
- 删除原生爆炸的连续黄色圆环和半透明大圆面，换为对齐两像素网格的方形火星、碎屑、火光与灰黑烟尘；落点也改为四颗收拢的方形像素。
- 爆炸仍按圆形半径结算伤害，粒子随半径缩放；0.52 秒烟尘动画不追加伤害。
- 每枚榴弹命中 N 个敌人，会在各自位置派发 N 组命中附魔。爆炸前先快照全部接触位置，防止死亡或位移改变此次接触列表。
- 爆裂附魔等范围效果可以相互重叠；这种增强是逐目标触发规则的实际结果。衍生伤害不会递归生成榴弹命中事件。

## 分裂审阅方案（尚未开放正式装填）

当前正式配置仍拒绝榴弹炮装填分裂。专用录制场景仅为本次运行实例开放分裂，并创建预览用子榴弹；不修改正式卷轴或武器配置。

| 项目 | 本次预览 |
|---|---|
| 触发方式 | 每个被主榴弹原生爆炸命中的目标分裂一次 |
| 数量 | 每目标 2 枚，命中 4 只产生 8 枚；正式卷轴已有数量浮动，预览固定为 2 |
| 子榴弹伤害 | 主榴弹的 60%；一级 16 × 0.6，按现有取整为 10 |
| 子榴弹半径 | 主爆炸半径的 50%；一级为 32，覆盖面积为主爆炸的 25% |
| 子榴弹飞行 | 0.32 秒、抛物线高度 32，发出后固定落点 |
| 落点 | 优先附近尚未被主爆炸命中的敌人，同一轮尽量分配不同目标；无目标时向前散开 |
| 重复命中 | 不伤害主爆炸已经命中的敌人；不同子榴弹对外围敌人的范围伤害可以重叠 |
| 递归 | 只分裂一代，子榴弹不再分裂 |
| 其他附魔 | 子榴弹仍对每个受击目标触发其他附魔，按各附魔原有参数计算 |

这是集束榴弹的方向：主爆炸处理中心怪群，子榴弹扩散到外围。高密度场景中，数量按 `主命中数 × 分裂数量` 增长；命中 10 只时，基础分裂就有 20 枚。再叠加爆裂等范围附魔时，重叠伤害增长更明显。建议保留一代限制、较小半径与较低子弹伤害，正式启用前补充高侵蚀密集战斗压测。预览没有偷偷限制主爆炸的受击目标数。

## 录制与验证

- Godot 实际运行、30 帧采集。一级，无暴击，固定玩家和敌人，敌人生命为 1000；原生版无附魔，火焰版装填火焰，分裂版仅装填预览分裂。
- `grenade_pixel_blast.gif`：正常速度、三次攻击、5.40 秒。
- `grenade_fire_all_targets.gif`：正常速度、火焰逐目标触发、3.60 秒。
- `grenade_split_preview.gif`：正常速度、两轮分裂、3.60 秒。
- `grenade_split_half_speed.gif`：0.5 倍速度、首轮分裂、3.60 秒。
- 专项测试覆盖逐目标附魔、各自接触坐标、原生范围外的附魔溅射、致死命中不吞附魔、每枚只命中一次以及现有武器规则。
- 分裂录制额外检查三次主爆炸产生 24 枚子榴弹，全部各命中一个外围目标；中心四只分别只受三次原生伤害，外围八只分别受三次子榴弹伤害，没有递归分裂。
- `*_capture.log` 与 `*_capture.json` 保存实际事件；退出时既有的资源清理提示不影响录制。
