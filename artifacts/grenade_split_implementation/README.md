# 榴弹炮集束分裂正式实现

用户已确认集束分裂方案，现已接入正式战斗、附魔装填和武器详情。原预览脚本已移除；录制场景只装备真实分裂卷轴并固定演示目标，不再替换武器配置或生成预览子弹。

## 生效规则

- 每个主爆炸命中目标生成子榴弹。普通分裂卷轴每目标 2 枚；掉落卷轴的分裂数量词条和修正正常生效，两张卷轴分别结算。
- 子榴弹继承主榴弹暴击结果，伤害为其 60%，一级非暴击取整为 10；半径减半，一级为 32、五级为 40，伤害范围加成不重复计算。
- 子榴弹飞行 0.32 秒、弧高 32，优先分配主爆炸未命中的附近敌人，无可分配目标时按卷轴角度散开。确定落点后不追踪。
- 主爆炸击杀目标仍可在命中快照位置分裂。子榴弹排除主爆炸已命中目标的原生伤害与接触附魔，外围敌人可被多个子榴弹重叠命中。
- 子榴弹继续逐目标触发其他附魔，但不再分裂；附魔自身的范围溅射仍按原规则生效。
- 全部主／子榴弹共用暂停和战斗实体清理逻辑；穿透仍不可装填。
- 保留已确认的方形像素爆炸和小榴弹外观，玩家身上无白黄色发射闪光。

## 验证

- `test.log`：87 项专项检查通过，覆盖逐目标附魔、分裂数量、独立词条、重叠伤害、致死命中、固定落点、范围加成、暴击继承、暂停、清场及理财装填／卸下／跨武器转移。
- 密集目标检查：80 个主爆炸目标实际生成 160 枚子榴弹，无隐性数量截断，无递归分裂。这是逻辑压力检查，不是帧率基准。
- `capture.log` / `capture.json`：正式攻击循环，三次主爆炸共生成 24 枚子榴弹。中心四只生命各为 952，外围八只生命各为 970。
- `grenade_split_live.gif`：正式版本运行录制，正常速度，两轮攻击，3.60 秒。
- `main_editor.log`、`bootstrap.log`、`finance.log`：编辑器、启动和理财回归记录。
- 退出时可能出现项目既有的资源清理提示；检查脚本错误、配置验证和测试结果与这些提示分别记录。

