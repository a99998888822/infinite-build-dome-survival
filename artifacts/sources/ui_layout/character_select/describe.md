整体采用地下室背景上的左、中、右三分区布局：
- 左侧约 20%：角色名册。 竖向排列紧凑的小框，每行放头像和角色名称，一屏约展示六位角色，更多角色可滚动查看。
- 中间约 42%：人物展示区。 选中角色站在石台上，背后是拱门和向上的楼梯，旁边由紫色吊灯照明。角色上方显示名字和简短介绍。
- 右侧约 38%：角色详情区。 使用金属夹固定的旧纸张作为底图，依次展示开局属性、初始武器和角色特性。
- 底部：操作区。 左下角是“◀ 返回主界面”，中间是难度选择，右下角是“继续 ▶”，两个操作按钮使用克制的小边框。
背景通过低矮顶梁、裸露管道、高位铁窗、木桶木箱和排水沟体现地下室氛围，装饰集中在边缘，突出中央人物。
