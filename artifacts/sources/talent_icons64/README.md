# 天赋图标 · 64px

按用户要求，34 个建筑与升级图标已从原始高清图表重新进行 64×64 像素化，安装至 `assets/ui/talents/`。没有使用 32px 图放大，也没有调用图片生成模型。沿用原配色与造型，通过项目 Picxel 本地流程分两批各 17 张制作、逐张对照检查与局部修整。

- `reference/`：保留原始图标表与用户提供的名称说明 `telant_icon.txt`；`manifest.json` 记录裁切位置、源图哈希、选定网格、正式 PNG 哈希与检查说明。
- `editable/`：最终选定的 PXG、PAL、每张图的检查 anchor。
- 正式 PNG 统一存放于 `assets/ui/talents/`，本目录不再重复保存。
- `ui/reference/`：三张已确认的 UI 背景原图；`ui/manifest.json` 记录裁切范围和哈希。`ui/export_ui.py` 可从这些源图重建背景及 16×17 升级箭头，必须通过 `--output` 指定输出目录，需要 Pillow。

每张图最多 16 色，本批共用九色板，alpha 只有 0/255，不使用抖色。弓弦、三箭箭杆、尺线、屋顶和庇护所接缝已补成连续笔画；木箱和石块合并杂色，保留主体结构。小型铆钉、闪光与明确的装饰点保留。

天赋页最近邻显示，建筑图标为 64 逻辑像素，升级图标为 52；节点底图分别为 104 和 84，图标主体落在底图内圈，源文件保持 64×64。最新 UI 修订将间距倍率从 1.9 调整为 1.3，并按新链路重新排布；等级放在图标下边缘，留出节点标题和购买箭头空间。缩放范围 0.3～1.8。最新布局与验证见 `docs/asset/talent_tree_review.md`。

2026-10-18 清理了已淘汰的 32px 版本、转换中间稿、重复 PNG 和依赖旧目录的安装脚本。34 张可编辑网格已逐像素核对正式 PNG。最终验收截图与日志保存在 `artifacts/validation/talent_tree/`。
