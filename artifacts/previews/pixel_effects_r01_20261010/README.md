## 制作与文件

这批候选采用本地代码绘制像素，没有调用图像模型或图片 API。所有候选图集为 RGBA PNG，基础网格 2 像素，透明度只含 0／255，每组 4–6 个可见颜色。动画由明确的逐帧形状变化构成，未使用模糊缩放或抗锯齿。

- `candidate/`：9 组候选透明图集。
- `baseline/`：替换前 7 组正式 PNG 的只读基线副本；风刃和摆锤基线由替换前绘制代码采样。
- `candidate_flail.gd`：审阅专用绘制覆盖，继承正式锤头轨迹，只替换扇面拖影绘制。
- `capture.gd`、`launch.gd`：独立 Godot 审阅夹具，直接加载候选路径；不修改正式场景的资源引用。
- `godot_frames/`、`renders/`：实际 GPU 帧及浏览器播放图集。
- `build_candidates.py`、`package_review.py`：原绘制和打包脚本，保留作制作依据。
- `manifest.json`：尺寸、色数、透明度、锚点、帧率和源文件校验值。
- `overview.png`、`dash_comparison.gif`：静态总览与突进斩击慢放对照。

存档约定：不要在本目录重跑制作、GPU 捕获或打包脚本。它们依赖制作当时的正式代码，重跑可能覆盖替换前基线与画面；后续版本请另建目录。静态图和 GIF 内的“当前版本／候选”文字保留制作时含义，分别指替换前版本与已采用 R01。

## 审阅边界

画面使用正式 GameRoot 地面和角色，按原帧率控制取样。为了看清图形，位移、闪现与风刃采用定点检视；原位星印放在角色旁边。此页没有模拟完整施放、敌人命中、附魔连锁或多特效混战。返回效果只作定位提示，未添加伤害结算。

七组已有 PNG 保持原图集尺寸、帧数和锚点，突进斩击保留已确认的椭圆比例与时长。此页中的风刃与摆锤是原试作采样，摆锤仅展示向右、正向一次。正式接入已适配动态方向、范围加成、附魔染色及分裂，并另外验证；这里保留原审阅内容。
