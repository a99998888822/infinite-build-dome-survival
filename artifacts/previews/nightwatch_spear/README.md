# 守夜长枪（动作原型）

尚未加入正式武器、商店和奖励池。正式图标与枪身素材已在 `assets/`，原型逻辑和录制入口保存在 `scripts/tests/`、`scenes/tests/`。

原型基础伤害 14 + 近战伤害 × 1.0，间隔 1.10 秒，前方长度 220、全宽 28；前摇 0.10 秒锁定方向，刺出 0.12 秒，收枪 0.16 秒。刺出期间矩形判定随枪尖推进，每目标每次原生刺击最多命中一次，可边走边刺，待机隐藏枪身。

- [边走边刺](kite.mp4)：完整实录视口。

分裂提案为每个主刺受击目标生成两枚短矛，伤害继承 60%，前方索敌距离 220、速度 420；排除主刺已命中目标，只分裂一代。附魔兼容与平衡仍需正式接入时确认。
