本轮保留参考图例的修长尖顶面甲、层叠肩甲、收腰胸甲、尖底巨盾和分叉战裙，并按最新意见调整待机姿态：双腿从髋部向外展开，双脚间距由 16 像素扩大至 40 像素，形成撑稳重甲的宽站姿。持锤右臂贴近身侧自然垂下，锤头稍上提，露出脚踝与落脚位置。收招最终回到新站姿。

行走改为八帧、840 毫秒循环：落脚承重、重心前移、抬膝、迈出依次交替。大腿和小腿采用两段等长关节绘制，胯甲跟随大腿方向，胸甲、盾牌和持锤手随身体重心起伏。支撑脚保持在地面，摆动脚离地抬起，避免仅在膝盖以下摆动的效果。

胸甲、盾牌与战裙使用分段排列的青色几何符文，以直线、折角和短刻痕形成独立字形。深蓝黑钢面以银灰棱线区分甲片，少量暗金仅用于金属装饰；保持原有青色系、原生像素画法和 160×160 分辨率。

## 冲刺预警与已接入规则

- 保留无箭头、无圆角的直角矩形。预览贴图为 288×48，包含冲刺距离两端的范围余量；正式接入时应由技能实际扫掠范围生成尺寸。
- 内部不透明度由旧版 30% 降至约 **12%**，也就是约 88% 透明。
- 两条长边不透明度在 **42%～55%** 间脉动，辅以 **48%～60%** 不透明度的少量红色方粒。边缘比内部明显，两端不添加箭头或粗封口。
- 正式逻辑已在进入蓄力时检查：玩家处于配置的实际冲刺距离内，且技能冷却就绪。当前距离为 240。
- 距离过远时继续追赶；进入范围才举盾抬锤。蓄力起手后锁定冲刺方向，玩家可以侧移躲开。
- 本目录动图仅演示动作与视觉意图；正式伤害判定、距离门槛及实机验证见 [接入说明](../../../docs/asset/iron_knight_integration.md)。

## 重建与检查

在项目根目录执行：

```text
python scripts/tools/build_iron_knight_review.py
```

依赖 Pillow 与 Windows 微软雅黑字体。构建器检查 32 帧的尺寸、透明通道、边界留白、动作内帧唯一性、行走关节可达性，以及三份动图的总时长。逐帧时长、图集尺寸、步态和速度参数保存在 [manifest.json](manifest.json)。
