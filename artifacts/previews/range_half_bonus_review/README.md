# 攻击距离 / 伤害范围：加成收益减半预览

本目录保存独立审阅阶段的报告与动图。审阅阶段未改动正式资源，`production_verification.json` 记录当时1912个既有文件的SHA-256比对结果。用户确认后，50%加成效率已接入正式战斗，正式验收记录位于相邻的 `range_half_bonus_install/`。2026-10-07 已清理一次性对比适配器与录制脚本，保留最终媒体和测量数据。

## 查看动图

- `range_review.gif`：守夜长枪，只改变攻击距离属性。
- `area_review.gif`：榴弹炮，只改变伤害范围属性，攻击距离属性为 0，落点始终固定。
- `combined_review.gif`：赤铜炉灯，两项属性同时取相同数值，展示叠加后的效果。

每张动图左侧为当前规则，右侧为预览规则；依次播放 0、+50、+100、+200 四档，每档 3 秒。上方显示原始属性值和实际尺寸，下方显示真实伤害事件命中的目标数。同一武器的镜头、缩放、目标位置和施放时刻固定。

## 预览规则

当前：`实际距离或半径 = 基础值 × (1 + 属性 / 100)`。

预览：`实际距离或半径 = 基础值 × (1 + 属性 / 200)`。

这是属性加成收益减半。0 属性时的基础效果保持一致，伤害数值、施放时长和冷却未改变。炉灯先将两项属性相加，再按上述效率计算喷射距离。

| 属性档位 | 长枪距离：当前 → 预览 | 榴弹半径：当前 → 预览 | 炉灯距离：当前 → 预览（两项均为该档） |
| --- | --- | --- | --- |
| 0 | 220 → 220 | 64 → 64 | 120 → 120 |
| +50 | 330 → 275 | 96 → 80 | 240 → 180 |
| +100 | 440 → 330 | 128 → 96 | 360 → 240 |
| +200 | 660 → 440 | 192 → 128 | 600 → 360 |

表中单位为游戏世界像素，不是缩放后的截图像素。榴弹使用正式的椭圆判定，表中半径为水平半轴，垂直半轴同比例变化。

## 实录方法与验证

使用真实 `GameRoot`、`ActiveWeaponCasting`、武器动画、碰撞、伤害与飘字。固定高血量敌人作为测试目标，取消自动追击和普通受击位移，关闭随机刷怪。预览目标未改写伤害处理。

当时使用的 `preview_weapon.gd` 保留原始装备属性，在生成施放快照时按当时的正式公式换算出100%或50%加成效率；瞄准提示读取相同的几何快照。该适配器仅用于审阅对照，已随中间产物清理；正式战斗使用统一属性换算入口。

实际运行验证了：

- 原始属性值不变，瞄准尺寸与原生施放快照一致。
- 附魔参数得到一次折半后的范围倍率。
- 固定目标的真实命中与范围边界相符；长枪每次命中 26，榴弹每次命中 36，两个方案相同。
- 0 属性时，两侧尺寸、命中目标和伤害一致。
- 两侧的物理帧及施放帧一致。
- 24 个实机场景均无脚本错误或审阅失败。

GPU 实录通过项目的 `run_godot_background.py` 在私有 Windows 桌面运行。六次完整录制均确认 `verified_desktop == private_desktop`、`foreground_samples == 0`、退出码 0。

60 Hz 固定模拟，每 3 帧采集一张真实 GPU 图像，动图以 20 fps、原速播放。后期仅裁切、缩放、左右拼接、加说明文字及 GIF 调色板压缩；没有补画战斗、伪造命中或改变动画速度。每张动图 240 帧、12 秒。

`captures/` 保留各组 JSON 验证报告，不再保存原始截图序列。三张 `*_review.gif`、各档位的 `*_contact_sheet.png`、代表画面和 `*_comparison.json` 统计均保留。
