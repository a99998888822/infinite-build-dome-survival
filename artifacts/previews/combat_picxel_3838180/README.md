## 当前游戏格式

- 初心者：`delivery/beginner/combat/` 提供同名 54×54 待机、216×54 四帧行走，以及完整 432×54 八帧行走。四帧取原图 1→3→5→7，保持 3.5 FPS；完整八帧建议 7 FPS，循环时长一致。待机暂选原图第 1 帧。
- Boss：`delivery/boss/combat/` 提供 1760×160 移动图集和完整攻击图集。攻击已分成蓄力 1–7 帧（0.8 秒）、挥击 8–9 帧（0.16 秒）、收招 10–11 帧（0.5 秒），对应现有技能阶段；`SpriteFrames` 已按新帧序重建。移动使用 11 FPS。
- 小怪：`delivery/enemy/combat/` 提供 86×86 待机、258×86 三帧兼容行走，以及完整 602×86 七帧行走。兼容版取原图 1→3→6，沿用每帧 0.14 秒；完整七帧预览为 8 FPS，接入完整版本时需改掉控制器固定三帧的配置。
- 初心者脚底在 y=52，小怪在 y=60，Boss 移动在 y=128。Boss 攻击保留动作本身的上下变化和超出鞋底的火花；脚底与光效不混作同一个对齐边界。

原图没有单独的 Boss 死亡动画，也没有攻击结束后回到待机的过渡帧。本包没有生成额外姿势；四组总览中攻击收招后直接切回移动第 1 帧，单独攻击 GIF 按原始帧序循环。蓝色挥击弧与火花已包含在攻击 PNG 内。
