实测结果：

- 长焦目镜：榴弹炮射程420 → 567，同一目标距玩家500，由不开火变为命中，HP1000 → 980。
- 扩散喷口：爆炸半径64 → 83.2；距爆心80的目标由不受伤变为HP982，距爆心110的目标仍为HP1000。主目标伤害16 → 18，也体现伤害加成。
- 脚架：静止1秒后攻击距离115 → 155、伤害加成77 → 97，星仪联动使伤害范围185 → 205；输入移动当帧全部回到原值，永久攻速部分保留。
- 本金1000取出901：攻击距离145 → 115、伤害范围200 → 185、伤害加成107 → 77；预览与实际一致。
- 全部10件真实购买成功，扣款与价格一致，预览与获得后的属性一致。

`range_relic_test` 119项通过；另通过遗物一致性152项（含180组预览）、遗物平衡67项、本金遗物76项及理财界面回归。Godot编辑器导入及主场景120帧验证完成，无新增解析或脚本错误；编辑器仍报告本机Android build-tools缺失，主场景与部分旧测试退出时仍有既有Canvas/ObjectDB资源释放警告。
