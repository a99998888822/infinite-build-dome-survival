# 新柜台与放大哥布林

使用用户确认的 128×64、16 色透明柜台，正式文件为 `assets/ui/finance/bank_counter_desk_picxel.png`，与审阅稿逐字节一致。旧柜台 PNG、导入文件和白底参考图已删除，理财、结算与审阅生成器均已更新引用。

哥布林按柜台缩放系数的 0.60 倍显示，相对上一版 0.86 倍缩小约 30%；人物区上限为 200，小窗口按可用高度统一适配。先绘制柜台，再一次绘制完整哥布林；不裁切手部，呼吸时袖口、掌根与手指同步微动。角色图集保持原样。

后续替换同规格图集（每帧 128×128，五帧横排）无需重新标注手部；构图或留白变化时，只需调整人物整体位置和缩放。

- `bank_before_all.png`：实际理财界面，1920×1080 截图。
- `banker_closeup.png`：从上述截图裁出的哥布林与柜台细节，未重绘或缩放。
- `banker_states.png`：实际绘制组件的五种表情，上两行为静止与呼吸，下行为紧凑尺寸，用于检查完整双手。
- `bank_after_deposit.png`：存款后的表情与回执。
- `bank_small_window_bank.png`、`bank_small_window_shop.png`、`bank_small_window_enchant.png`：640×360 小窗口的三个页签。

本次移除手部裁切后，重新通过 Godot 4.7.2 编辑器无头导入、主场景 120 帧启动和理财实机回归 76 项，无解析或编译错误；五种表情、标准窗口和 640×360 三页签截图均已更新并检查。素材初次接入时还通过了结算 68 项及下一波挑战 71 项回归。测试使用 `--transient-session` 避免经济进度写入存档，实机截图使用 `opengl3_angle` 驱动。
