正式行为：

- 利息动画结束后停留在最终到账金额，点击或Esc关闭；兼容原空格、回车操作。Esc优先关闭账单，不会同次打开遗物清单；关闭不重复结算、不取消现有交易。
- 三档基础数量倍率0.30 / 0.45 / 0.65，所有波次在属性加成取整后再乘2，确保每批数量相对上一版准确翻倍。刷新间隔倍率仍为1.35 / 1.20 / 1.05，同屏上限同步提高到240 / 360 / 480。单怪属性与精英配额保持不变，难度2、3仍分别加强怪物属性20%、30%，难度3精英更频繁。
- 每波生命乘1.24；数量增幅每波增加6个百分点、刷新频率增幅每波增加2.5个百分点，并叠加波次表的组数和间隔变化。基础攻击每波只增加1.5个百分点，20波普通怪基础接触伤害取整后为1–2点；区域、侵蚀和精英倍率另算。
- 附魔空状态关闭自动换行，使用灰色字体与“暂无附魔”文案。

截图来自临时隔离会话中的正式场景，不改变玩家存档。怪群截图固定相同随机种子，实际执行每波前8秒刷怪，无击杀；敌人位置固定、镜头缩小，以便比较数量。数量、普通怪血量和伤害标签是根据运行数据添加的审阅标注。利息GIF由每隔1秒的实际视口截图组成，最后的关闭画面额外停留2秒。

验证：

- `wave_pressure_test.tscn`：241项通过，覆盖全部60组难度与波次、实际刷怪计时、逐波血量和密度、跨难度数量差异及基础伤害增长。三档第1、5、10、15、20波共15个检查点的20秒实际刷怪数均为上一版两倍。
- `difficulty_balance_test.tscn`：120项通过；选择卡片传参、实际敌人属性、翻倍后的首批数量、同屏数量上限与精英频率正确。
- 8秒实机截图核对：第1波28 / 42 / 58只，第10波84 / 124 / 196只，第20波172 / 260 / 424只，九组均为上一版两倍。
- `interest_arrival_test.tscn`：40项通过；包含等待保持、Esc优先级、点击不穿透、结息一次性和重开。
- `finance_preparation_test.tscn`通过，包含常规、小窗口的单行灰色空状态；`erosion_pressure_test.tscn`64项通过。

数量翻倍后未重新评估无天赋通关率；上述验证确认刷怪数和规则生效，实际平衡仍需结合玩家操作和构筑评估。

Godot编辑器与主场景验证无新增解析/脚本错误；编辑器仍提示本机Android build-tools缺失，部分场景退出仍有既有Canvas/ObjectDB资源释放提示。原始帧、截图脚本与日志位于系统临时目录，本目录只保留上述成品。
