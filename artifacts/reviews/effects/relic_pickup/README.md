# 遗物奖励掉落实机效果

- [并排动图](game.gif)：实际 Godot 战斗视口录制，3秒、30帧/秒；统一最近邻放大两倍，底部尺寸说明为审阅标注。
- [立方体局部放大](detail.png)：同一实机帧裁切后最近邻放大6倍，用于检查三个面的比例。

从左到右为经验球、血包、电火花附魔、遗物选择小箱子。箱子主体绘制在24×24像素范围内，是长、宽、高相等的立方体。统一等轴投影生成箱盖及两个等宽侧面，包边、锁扣和3处小符文也投影到各自表面。血包、附魔为16×16；经验球资源也是16×16，但当前场景缩放为0.5，因此实际显示8×8。

箱子带约44像素覆盖范围的柔和金色加法辉光、1像素幅度的悬浮、4颗错开周期上浮的方形粒子，以及轻微箱沿闪光。特效跟随战斗暂停，不依赖渲染器的全屏辉光设置。

录制使用正式 GameRoot、战斗场景和 DropRewardSystem；为方便比较，关闭自动刷怪和攻击，临时把拾取吸引范围设为0，并排生成四类掉落物。未改变正式场景的拾取半径、掉落概率、奖励选择与波末收取逻辑。

验证：24像素版通过Godot无界面编辑器导入、主场景120帧启动和实机录制，无脚本解析或编译错误。奖励逻辑沿用前版已通过的71项回归结果，本轮仅调整绘制。主场景仍有退出时Canvas、ObjectDB或资源未释放提示，编辑器提示本机Android build-tools目录不可用。

重现录制：运行 `scenes/tests/relic_pickup_live_capture.tscn`，使用 `--rendering-driver opengl3_angle --fixed-fps 60 --resolution 1152x648 -- --transient-session --capture-dir=<系统临时目录>`。180张原始帧按视口矩形 `(340,195,460,210)` 裁切，统一两倍放大，加尺寸标注并转成GIF。原始帧与处理中间文件只保存在系统临时目录。
