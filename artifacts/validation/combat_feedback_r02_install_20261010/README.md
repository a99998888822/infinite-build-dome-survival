# R02 正式启用记录

2026-10-10，用户确认采用后，已将获批 R02 反馈在正常战斗中默认启用：短刀轻击、战锤重击与地裂亮边、秘仪逐次点名与武器栏回弹／短音、炉灯持续接触限频。

## 启用方式与保留内容

五处入口统一读取 `scripts/effects/combat_feedback_settings.gd`。未设置任何运行时覆盖值时即生效；对照工具可临时设置 `combat_feedback_r02_enabled = false`，清除覆盖后恢复正式模式，无需写入存档。

启用前的 14 个实现与测试文件均与审阅清单散列一致，秘仪短音与获批素材字节一致。受击精灵、接触爆点和图标的绘制方法与获批版本完全一致。R01 的 9 张正式图集、浅青灰指示器与突进椭圆投影继续保留。

正式回归中发现接触爆点缺少武器运行时组要求的 `weapon` 属性与 `cancel()` 方法，导致移除武器／切换波次时出错。已将纯装饰移入独立清理流程，并补齐取消接口；波次清理会立即隐藏并释放装饰。此修复不改变获批外观与伤害逻辑。

| 后台 GPU | 完整推进六组动作，保存 40 张正式模式关键帧；失败 0，进程退出 0，实际私有桌面匹配，`foreground_samples=0` |
