# 元素反应飘字 R04 · 正式启用

用户确认采用“从命中点向上飘”的版本后，已默认启用两种反应名称，正常战斗无需审阅参数。

| 反应 | 文字与颜色 | 触发次数 |
| --- | --- | --- |
| 雷击引爆燃烧 | 雷火爆燃，橙黄色 `#FFC365` | 每个落雷或电链实例最多一次，多目标与雷光回响不重复 |
| 湿润触发追加电击 | 导电，蓝白色 `#C5EAFF` | 每次真实导电一次，连续触发不限频 |

保留获批的 14 像素中文字体、深色描边、0.82 秒时长与 40 像素上浮距离。两种文字都以实际命中点为中心出现，沿竖直方向上浮并淡出。伤害、碰撞、反应结算、随机数和原有特效保持原样；暂停冻结文字，目标死亡不截断已生成的文字，波次清理移除文字。

启用前核对获批记录中的 9 个文件，全部散列一致。正式运行代码仅修改默认开关与说明注释，绘制、颜色、动画和触发入口保持获批实现。`validation/approved_sources.json` 与 `validation/runtime_integrity.json` 保存核对结果。

`scripts/effects/element_reaction_text.gd` 中的 `element_reaction_text_r04_enabled` 现在默认 `true`。对照工具可临时设为 `false` 查看旧版，清除覆盖后即恢复正式模式；正式关键帧使用清除覆盖后的默认行为。
