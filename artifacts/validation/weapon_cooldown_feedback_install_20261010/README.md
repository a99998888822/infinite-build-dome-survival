# 武器栏冷却完成动效 · 正式安装

本轮仅采用冷却完成的像素角边亮起、阶梯外扩与淡出，时长 0.38 秒，颜色与绘制代码保持获批版本。正常游戏直接启用，不再需要 R03 审阅开关。

真实冷却结束按武器实例触发一次；初次装备、换位重建、隐藏后显示与移星返回不会制造提示。暂停冻结动画，隐藏或重新施放会清除提示。保留 50 毫秒合并窗口，自动武器刚就绪便立即施放时取消亮边；不限制实际攻击频率。

已删除本轮施放回弹、图标缩放容器、施放限频、临时开关、额外秘仪点名转发，以及原 R03 审阅包与服务器。清理范围不包含此前采用的 R01／R02。`validation/cleanup.json` 记录删除数量；只保留获批冷却参考画面及本次正式验证素材。

实现位于 `scripts/ui/weapon_cooldown_feedback.gd`；武器栏直接挂载该控件，只绘制边框，不修改图标姿态。`WeaponInstance.cooldown_ready_changed` 仅传递冷却就绪／消耗状态，独立于施放动效。

`approved/` 保存获批冷却参考；`frames/` 保存正式 GPU 采样；`validation/` 保存无界面检查、图像比较与后台桌面证明。运行 `validate.py` 执行串行无界面检查；GPU 检查使用项目 `scripts/tools/run_godot_background.py`，场景为 `scenes/tests/weapon_cooldown_feedback_test.tscn`，需要传入 `--transient-session`。

验证：冷却专项 29 项、主动战斗集成 146 项、R02 反馈 24 项通过，共 199 项。编辑器和 GameRoot 运行检查退出 0，无脚本／编译错误。GPU 完成 60 帧正式采样和三格各触发一次的检查，退出 0、私有桌面匹配，`foreground_samples=0`。

冷却绘制代码与获批版本的 SHA-256 一致；4 张完全亮起的关键帧中，全部边框像素位置与颜色逐一相同。半透明卡片下的地面着色器随实机时间变化，因此没有把整张背景图的相等作为验收条件。正式效果见 [冷却完成动图](cooldown_installed.gif)。
